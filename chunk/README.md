# chunk/ — 청크브레인 (의미단위 끊어읽기) 코드 디렉터리

유치(5~7세)부터 고등까지 **의미 단위로 끊어 읽는 힘**을 배우고(배우기) · 연습하고(연습) · 간격을 두고 되풀이하며(복습) ·
종이로도 익히는(출력 → PDF) 학생 앱. 라이브 `/chunk/` · 교재 `/chunk/print.html`.
근거 문헌과 설계 판단은 `docs/의미단위-끊어읽기-앱-연구노트-v1.md`, 끊는 규칙의 정본은 `docs/의미단위-끊어읽기-규격.md` 3장이다.

## 설계 요점 (연구노트에서 옮김)

- **밴드 6개.** 규격서의 L1~L4(3.3/3.7/4.1/4.5어절, 상한 8)를 유치(1~2어절, 문장 하나씩)와 초1~2(2~3어절)로 아래로 펼쳤다.
  유치·초1~2 는 문단이 아니라 **문장 하나씩** 찍고, 표시는 ∕ 대신 **밑줄 곡선(스쿱)** 이 기본이다(K–1 은 스쿱, 2학년부터 슬래시 — 문헌).
- **연습 한 편 = 10분, 3단계.** 표시본 따라 읽기(모델링·반복 읽기) → 표시 없는 본에 직접 표시(전이) → 표시 없이 읽고 문제(이해 확인).
  「표시된 글에만 익숙해진다」는 문헌의 경고 때문에 복습은 ②부터 시작한다(fading).
- **채점은 규격서 9장 그대로.** 잘게 끊는 것은 절반만 벌점. 쉼표 뒤에 찍은 것은 중립(틀렸다고 하지 않는다).
  점수는 모범과의 일치로만 나오고, 「왜」 문구·태그는 설명과 복습 연결에만 쓴다 — 규칙 판정이 조금 틀려도 점수는 안 변한다.
- **이미 잘 읽는 아이에게는 효과가 없다**(문헌) — 졸업과 단계 올리기 제안이 있는 이유.
- **읽기 속도는 남과 비교하지 않는다.** 묵독 어절/분은 지난번의 나와만 견준다(국내 규준이 없다).
