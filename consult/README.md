# WB 컨설팅 플래너

기존 `/consult/` 안에서 학생 상담, 인강·학습 관리와 통합 학습 플래너를 함께 운영한다. 별도 새 앱이 아니라 현재 URL과 학생 원장을 유지한 모듈형 확장이다.

## 주요 기능

- 강좌 상세 중심 검색과 후기·교재 제외
- 외부 강좌 403 시 오류 대신 목차 직접 붙여넣기
- 스터디포스·클래스카드·메타수학·NELT 및 미래 provider 등록
- CSV/JSON 미리보기·검증·행 선택·사람 승인 후 반영
- TodoMate형 오늘/주간 플래너와 학생 완료요청→선생님 검증
- NELT 3개월, 메타수학 주간·월말 평가
- 교재 오답 참조→메타수학 쌍둥이 문제→사람 숙달 판정
- 중·고등 학교시험 대비
- 초등은 학교 정기시험을 기본 생성하지 않고 경시/KMT/NELT/영재원/입학/레벨/custom만 선택 연결

## 저장·권한

- 원장 저장 키: `wb_consult_v2_admin`
- 개인 링크 저장 키: `wb_consult_v2_person_<studentId>`
- 구형 `wb_consult_v1`은 원장 화면에서만 1회 이전한다.
- PIN은 PBKDF2-SHA256으로 저장하고 secret·PIN은 URL/백업에 넣지 않는다.
- 개인 링크에는 24시간 유효한 1회용 `#c=` code만 들어간다. code는 즉시 주소에서 제거되고 교환 성공 뒤 bearer는 개인 scoped 저장소에만 보관하며, 서버에는 `sha256:<digest>`만 저장한다.
- bearer는 90일 유효하고 새 code 교환 시 회전한다. 관리자는 학생별 링크·세션을 즉시 해지할 수 있다.
- 학생은 자기 `lpclaim` 완료요청만 쓸 수 있다. 프로그램·평가·캠페인·오답·숙달 원장은 관리자/manager 승인 경로만 수정한다.

현재 운영 저장소는 Worker의 `staff/tasks/checks` bridge다. 프로그램 이력은 provider별 최근 20건·8KB, 개별 snapshot 4KB까지만 보존하고, 전체 브라우저 상태 4MB를 넘기기 전에 저장을 거부한다. D1 `lp_*` v2는 principal/session bootstrap과 데이터 대조가 끝날 때까지 `LEARNING_V2_ENABLED=false`인 비활성 foundation으로 유지한다.

## 운영 원칙

외부 프로그램 결과는 `가져오기 → 미리보기 → 검증 → 행 선택 → 사람 승인 → 반영 → 이력` 순서다. 비밀번호·토큰·쿠키·문제 원문·정답·해설은 저장하지 않는다. 메타수학 쌍둥이 문제의 실제 생성은 라이선스가 있는 메타수학에서 수행하고 앱에는 문제세트/배정/결과 참조만 기록한다.

설계·릴리스·복구 기준은 `../docs/learning-platform-v2/`를 참고한다. Worker 배포는 `../sync/deploy-safe.ps1`만 사용한다.
