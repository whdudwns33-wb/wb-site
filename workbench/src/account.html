비밀번호 변경

새 비밀번호는 기존과 다르게 12~128자로 정해 주세요.

관리자 계정

다른 관리자가 비밀번호를 잊었을 때 초기화할 수 있습니다. 본인 계정은 위의 비밀번호 변경을 사용하세요.

    관리자 비밀번호 초기화

    대상 계정의 기존 로그인과 API·MCP 연결 키가 해제됩니다. 다음 로그인에서 임시비밀번호를 변경해야 상담 자료를 열 수 있습니다. 상담 기록과 백업은 유지됩니다.

    API · MCP 연결

    API: /api · MCP: /mcp
    연결 키는 발급한 관리자의 상담 자료 조회·수정 권한으로 작동하며 30일 후 만료됩니다. 비밀번호를 바꾸면 기존 연결 키도 해제됩니다.

    이 키는 지금 한 번만 표시됩니다. 채팅에 보내지 말고 개인 도구의 환경변수에 등록하세요.
