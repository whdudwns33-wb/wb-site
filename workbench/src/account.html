비밀번호 변경

새 비밀번호는 기존과 다르게 12~128자로 정해 주세요.

강사·관리자 계정

등록한 강사와 관리자는 동일한 관리자 권한을 갖습니다. 전체 학생의 상담 자료 조회·수정, 계정 등록·비밀번호 초기화, API·MCP 키 발급이 가능합니다.

새 계정 등록

첫 로그인에서 임시비밀번호를 변경해야 상담 자료를 열 수 있습니다. 기존 계정과 상담 기록은 유지됩니다.

이름을 입력하면 wb이름 형식으로 제안합니다. 문자·숫자·밑줄·점·하이픈 2~40자로 수정할 수 있습니다.

다른 계정의 비밀번호를 잊었을 때는 아래에서 초기화하세요. 본인 계정은 위의 비밀번호 변경을 사용하세요.

    관리자 비밀번호 초기화

    대상 계정의 기존 로그인과 API·MCP 연결 키가 해제됩니다. 다음 로그인에서 임시비밀번호를 변경해야 상담 자료를 열 수 있습니다. 상담 기록과 백업은 유지됩니다.

    API · MCP 연결

    API: /api · MCP: /mcp
    연결 키는 발급한 관리자의 상담 자료 조회·수정 권한으로 작동하며 30일 후 만료됩니다. 비밀번호를 바꾸면 기존 연결 키도 해제됩니다.

    이 키는 지금 한 번만 표시됩니다. 채팅에 보내지 말고 개인 도구의 환경변수에 등록하세요.
