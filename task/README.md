# WB 업무지시서 (Work Order & Check)

직원에게 업무지시서를 보내고, **지시한 항목이 실제로 체크되는지 계속 확인**하는 도구입니다.
학생 플래너처럼 오늘 할 일 / 주간 달성률 / 연속 달성일이 한눈에 보입니다.

- 주소: `https://<사이트주소>/task/`
- 설치·가입·앱 다운로드 없음. 링크만 있으면 폰에서 바로 씁니다.
- 파일 3개로 끝: `index.html`(앱), `apps-script.gs`(선택-동기화), `README.md`(이 문서)

---

## 1. 어떻게 쓰나

### 원장님 (관리자)

| 화면 | 하는 일 |
|---|---|
| **직원 관리** | 직원 이름 등록 → **개인 링크** 생성 |
| **지시서 작성** | 업무 내용·상세지시·시간·중요도·반복(한 번/매일/평일/요일지정)을 담아 **발행** |
| **오늘 / 주간 플래너** | 직원별 체크 상태를 그대로 확인 |
| **직원 현황** | 전체 수행률, 직원별 미완료 목록, 직원이 남긴 사유 메모, 연속 달성일 |

### 직원

원장님이 카카오톡으로 보내준 **개인 링크**를 열면 끝입니다.
비밀번호 없이 **본인 할 일만** 보이고, 체크는 누르는 즉시 저장됩니다.
못 한 항목에는 사유를 메모로 남길 수 있고, `오늘 수행 보고 문자 만들기` 버튼으로
보고 문구를 복사해 카카오톡에 붙여넣을 수 있습니다.

> 폰 브라우저에서 **홈 화면에 추가**해두면 앱처럼 열립니다.

---

## 2. 처음 시작 (2분)

1. `https://<사이트주소>/task/` 접속
2. 관리 비밀번호를 정합니다 (원장님만 아는 4자리 이상)
3. **직원 관리**에서 직원 이름을 등록
4. **개인 링크 복사** → 해당 직원에게 카카오톡으로 전송
5. **지시서 작성**에서 업무를 담고 → **지시서 발행하기**
6. 발행 직후 뜨는 카카오톡용 지시서 문구를 복사해 함께 보내면 됩니다

---

## 3. 저장 방식 — 꼭 읽어주세요

기본 상태에서는 데이터가 **각자의 브라우저 안에만** 저장됩니다.
즉 원장님 폰과 직원 폰이 서로 연결되어 있지 않아서, **직원이 체크한 결과가 원장님 화면에 나타나지 않습니다.**
(직원은 자기 체크를, 원장님은 자기가 만든 지시서를 각자 보게 됩니다.)

선택지는 두 가지입니다.

### A. 그대로 쓰기 — 회신형

직원이 `오늘 수행 보고 문자 만들기`로 만든 보고 문구를 카카오톡으로 보내주는 방식입니다.
연결 작업이 전혀 없고, 확인은 카카오톡으로 받습니다.

### B. 구글 스프레드시트 연결 — 실시간 확인형 (권장)

직원이 체크하는 즉시 원장님 화면과 구글 시트에 반영됩니다. 무료이고, 아래 5단계면 끝납니다.

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다 (이름: 예 `WB 업무지시서`)
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 편집기 내용을 모두 지우고 `task/apps-script.gs` 파일 내용을 **전부 붙여넣기**
4. 맨 위 `var SECRET = 'wb-2026';` 의 값을 원하는 비밀키로 바꾸고 저장
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인 → 나오는 **웹 앱 URL**(`.../exec`)을 복사

그다음 앱의 **설정** 화면에서
- `Apps Script 웹앱 주소` = 복사한 URL
- `비밀키` = 4번에서 정한 값

을 넣고 **저장**하면 됩니다.
직원에게는 **설정을 끝낸 뒤** 개인 링크를 보내주세요. 링크에 주소가 함께 담기지는 않으므로,
직원 기기에서도 한 번은 설정을 맞춰줘야 합니다.

> **직원 폰에서 설정을 대신 맞추는 가장 쉬운 방법**
> 직원 폰으로 링크를 연 뒤 주소창에서 `?u=...` 부분을 지우고 접속 → 원장 비밀번호로 들어가 설정 입력 → 저장 →
> 다시 개인 링크로 접속. 한 번만 하면 됩니다.

연결 후 스프레드시트에는
- `체크현황` 시트: 날짜·직원·업무·완료여부·완료시각·메모가 표로 쌓입니다 (원장님이 시트에서 바로 확인)
- `_data` 시트: 앱 원본 데이터 (직접 수정하지 마세요)

## 4. 알아두실 점

- **관리 비밀번호는 간단한 잠금장치입니다.** 사이트 방문자가 실수로 원장 화면에 들어오는 것을 막는 수준이며,
  기술적으로 뚫으려는 사람을 막지는 못합니다. 개인 링크(`?u=...`)도 마찬가지로 아는 사람만 여는 방식입니다.
- 그래서 **학생 이름·생년월일·검사 결과 같은 민감정보는 지시서 본문에 쓰지 마세요.**
  `3시 김OO 학생`처럼 가려 쓰는 것을 권합니다.
- 지시를 **중단**해도 지난 체크 기록은 남습니다 (직원 관리 → 지시 목록 관리).
- **설정 → 내보내기**로 전체 데이터를 파일로 백업할 수 있습니다. 시트를 연결하지 않았다면
  브라우저 데이터를 지울 때 기록이 사라지므로, 가끔 백업해 두시길 권합니다.
- 검색엔진에는 노출되지 않도록 `noindex` 처리되어 있습니다.
