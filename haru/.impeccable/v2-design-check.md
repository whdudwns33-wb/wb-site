# 공개 v2 기존 디자인 세계 확인

2026-10-11 · impeccable documenter · ponytail full

판정: Read 모드의 기존 준비 안내 확장이다. 따뜻한 바탕·초록 강조·한국어 시스템 글꼴·운영체제 라이트/다크·그림자 없는 구분을 유지한다. 새 시각세계, 시안, 폰트, 이미지 또는 정본 토큰 변경은 필요하지 않다. 표시 이름은 세 v2 HTML 모두 **삼육중 및 영재원 대비**다.

## 비교 근거

읽은 자료: `PRODUCT.md`, `DESIGN.md`, `.impeccable/design.json`, `.impeccable/surfaces/haru-v2-index-html.md`, `guide.html` CSS, `v2/style.css`, v2 홈·삼육중·광주 영재교육 전용 HTML. `reference/document.md`의 기존 구현 추출 원칙을 적용하되, 이번 승인 범위에 따라 정본 재생성 없이 이 기록만 추가했다.

| 항목 | 기존 안내와 비교한 v2 |

| 색·테마 | `guide.html`의 9개 라이트 변수와 9개 다크 값이 동일하다. `color-scheme:light dark`와 `prefers-color-scheme:dark`를 재사용한다. 버튼은 패널 바탕·초록 글자의 보조 링크이며 학생 화면의 다크 버튼 바탕 역할을 바꾸지 않는다. |

## 사전 차이와 이번 변화

`DESIGN.md`와 `.impeccable/design.json`의 동기화 차이는 인수받은 사전 상태다. 이번 v2의 크기·배치 차이와 구분하며 두 파일을 수정·덮어쓰기·동기화하지 않았다. 점검 당시 두 파일의 `git diff`는 없었다. v2를 기존 정본의 모든 수치와 동일하다고 주장하지 않으며, 이번 표면의 차이는 위 표와 surface brief에만 기록한다.

## 확인 범위와 완료 경계

직접 확인한 정상 캡처는 `.impeccable/review/v2/home-desktop-top.jpg`와 `home-390-top.jpg`다. 다크 배색, 제목 위계, 두 진입과 줄바꿈이 코드·surface brief와 일치한다. 전체 9개 및 상세 캡처의 최종 시각 판정은 독립 finish reviewer가 담당한다. 296/296 통과는 주 작업 세션이 전달한 결과이며 이 문서 작업에서 재실행하지 않았다.

전달받은 detector 1회 결과에서 두꺼운 상단선은 1px로 수정되었고 현재 CSS도 1px이다. `sans kr 미선언`은 기존과 동일한 Noto Sans KR 스택의 부분 파싱 결과다. h1 clamp·1.1875rem·1.5rem·18px 타입 크기 권고는 실제 확장 차이로 기록했으며 별도 세계 선택이나 토큰 변경으로 확대하지 않았다.

이번 작성 범위는 이 파일 하나다. 코드·시각 정본·기존 보고서·캡처를 보존했다. 브라우저, 추가 detector, 새 캡처, push, 운영 배포는 실행하지 않았다. 라이트 실화면·운영 환경·기관 원문의 최신 사실 여부는 이 documenter 점검에서 확인하지 않았으며, 완료 범위는 로컬 읽기 안내다.
