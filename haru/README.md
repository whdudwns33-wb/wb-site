# haru/ — 삼육중 및 영재원 대비 코드 디렉터리

**핵심 안내 PR-1A 보완·PR-2 검수(2026-10-13)**: 삼육 6전형·공식 범위·서류·등록 시각, 광주 5기관 명부·추천/증빙·추가 공지를 보완했다. [핵심 안내 검토](../docs/하루-v2-핵심안내-PR1A-PR2-검토.md)에 12개 출처 버전·미확인·302/302 순차 검사·화면 검수·PR-3 승인 경계가 있다. 두 핵심은 미확인 표시를 갖춘 읽기 안내로 배포 검토 가능하며 전수 요강 확인은 미완료다. 수업 운영값 전부 미정, push·운영 배포·발송·자동 수집·학생 데이터 변경 없음.

**미확인 요강 후속(2026-10-12)**: 장흥·진도·백산중·전주예술고·장수 5기관의 새 공식 공고와 기존 13기관 추천/증빙 조건을 보완했다. 전남 나머지 17지원청의 최신 자체 게시판 첫 페이지는 2027 요강 미확인으로 표시한다. GED 재조회는 전남5건·전북18건, KAIST 새 지역별13건은2026자료다. [미확인 요강 후속 검토](../docs/하루-v2-미확인요강-추천증빙-후속검토.md)에 기관별 근거·상충·남은 검수가 있다. 안내68개·과정후보21개 유지, 수업 운영값 전부 미정·로컬 검토만 진행.

**기관명부·추천증빙 후속(2026-10-12)**: GED 2025 등록 전남 26개·전북 30개 전 페이지와 2026 교육청 계획 전남 24원·전북 27기관 표를 대조해 누락 26개(등록 24+사이버 2)를 보완했다. 다른 학교·지역 안내는 68개이며 지역 전체 모집기관 수가 아니다. 부안 상세·장수 학교 전달 안내와 기존 8기관 추천/증빙 조건을 보완했다. 전년도 자료와 2027 자격·일정을 구분하고 미확인 조건을 남겼다. [기관명부·추천증빙 검토](../docs/하루-v2-기관명부-추천증빙-검토.md)에 56행 연결표·계획표·조건별 한계가 있다. 2027 전수 검수는 미완료, 수업 운영값 전부 미정, 로컬 검토만 진행한다.

**GED 밖 공식 정보 후속(2026-10-12)**: 군산대 2027 수시·정읍/김제 자체 공고, 켄텍 설립·목포대 정보보호와 목포/여수/나주 지원청 전년도 참고를 추가했다. 다른 학교·지역 안내 총 42개이며 광주 예술 학년의 이전 상충 표시는 분야별 행 연결 오류로 정정했다. [GED 밖 공식 정보 검토](../docs/하루-v2-GED밖-공식정보-검토.md)에 원문·범위·검증·남은 확인을 기록한다. 수업 운영값 전부 미정·로컬 검토 전용이다.

**v2 공개 안내 · 로컬 검토판(2026-10-11)**: `/haru/v2/` 홈에서 `/haru/v2/samyook/`와 `/haru/v2/gwangju-gifted/`로 각각 이동한다. 기존 `/haru/`는 학습실로 유지한다. 과정 필터·기관별 원문/확인일/검수 상태·독립 상담 진입이 있으며 학습·저장·접수 기능을 추가하지 않는다. `node haru/v2/build.mjs`로 `catalog.json`과 기존 `facts.json`의 공개 항목만 읽어 HTML 3개를 생성한다. 원본·생성물 불일치는 `v2/public.test.cjs`가 막는다. 이번 작업은 push·배포 없이 로컬 검토까지이며 상세 경계·출처·롤백·후속은 [1차 구현 검토](../docs/하루-v2-1차-구현-검토.md)에 있다.

**공식 정보 후속 보완(2026-10-11)**: 광주 추가 기관·예술 후보와 다른 학교·지역 안내를 추가했다. 전수 명부·첨부 상세는 미완료이며 수업 운영값은 미정이다. [공식 정보 보완 검토](../docs/하루-v2-공식정보-보완-검토.md)에서 확인 범위와 다음 일을 본다.

**대학부설 첨부 후속(2026-10-11)**: 순천대·목포대·전북대 PDF에서 전형별 자격·접수·추천·등록을 보완하고 목포대 특별전형을 분리했다. [첨부 요강 검토](../docs/하루-v2-대학부설-첨부요강-검토.md)의 지역명 상충·미확인 범위를 읽는다. 수업 운영값 미정·로컬 검토 전용·T2/T3 및 사람 전용 작업 조건 유지.

**광주 첨부·지역 공고 후속(2026-10-11)**: 광주 기관별 HWP와 GED 2027 전남 4건·전북 17건의 공고/첨부를 요약했다. 지역 안내 총 34개이며 전체 운영기관 명부는 미완료다. [광주 첨부·지역 공고 검토](../docs/하루-v2-광주첨부-지역공고-검토.md)에서 일정 수정·상충·기관별 원문을 본다. 수업 운영값 전부 미정·로컬 검토 전용이다.

**초4 과정 검토**: `/haru/guide.html#course`에서 두 선택 경로의 4주 활동·시간·교사 확인·가정 역할을 펼쳐 본다. 상세 근거와 세 관점 보완은 [삼육중·영재원 4주 수업안](../docs/초4-삼육중-영재원-4주-수업안-v0.md)에 있다.
자료와 발문은 [교사용 검토팩](../docs/초4-준비과정-교사용-검토팩-v0.md)(A 20일·B 4회·빈 메모·가상 피드백), 원장 결정과 사람 전용 운영 절차·실행 목표는 수업안 §7·§10에서 본다.
원장이 먼저 답할 운영값 양식과 이후 담당 교사의 확인 순서는 [수업안 §7](../docs/초4-삼육중-영재원-4주-수업안-v0.md#7-원장-검토-후-정할-것)에 모았다. 실제 값·학생 자료는 원장의 비공개 보관본에 두며, 미정이면 검토 자료 준비까지만 진행한다.
[학생용 검토자료](../docs/초4-준비과정-학생용-검토자료-v0.md)는 정답·교사용 근거를 제외한 A 화~금 16일·B 4회 후보다. 교사가 배운 범위 한 종류만 골라 날짜별 한 장으로 검수하며 전체 후보를 가정에 배부하지 않는다. 실제 인원·담당·시간·배부·기록 조건은 미정이다.
자체 창작 예시를 담은 문서 제안이며 실제 수업·앱 배정·영재원 기능·새 기록 수집이 시작됐다는 뜻은 아니다.

기획·명세는 `docs/삼육중-*.md`가 정본이다 — 상품은 `삼육중-대비-학습웹앱-기획서-v1.md`, 기술은 `삼육중-대비-앱-설계안-v1.md`.
여기 있는 것은 학생·부모 화면, 순수 로직, 그리고 **커밋해도 되는 유일한 콘텐츠 계층(원자 목록 `atoms.json`, 문항 0)**뿐이다.
팩·종이 대응표·코호트 플랜·시험지는 KV(관리 웹 업로드)에만 산다. 서버 쪽은 `reading-server/haru-api.mjs`·`haru-score.mjs`, 관리 웹은 `reading-server/public/haru-admin.html`.

**샘플 검토**: `/haru/?preview=1` → 학생 홈·학습·좌표·답안지·회고, `/haru/parent.html?preview=1` → 보호자 화면.
자체 창작 예시만 사용하며 로그인·운영 API·기기 기록을 읽거나 쓰지 않는다. 새로고침하면 초기화된다.
표시 이름은 원장 요청으로 바꿨다. 경로·KV 키·기존 인증은 유지하고, 영재원 기능은 D-2·D-8 승인 대기다.

**준비 안내**: `/haru/guide.html` → 삼육중 지원·준비, 광주·전남 영재원 기관별 안내, 초3~초6 로드맵, 가정·학원 역할, 공식 출처.
`#gift-apply`에서 학교 안내 → 지원서·체크리스트/기관별 접수 완료 → GED 정정·추천 확인 → 평가·등록 순서를 본다. 광주교대의 납부·사진·과정 선택·등록 조건과 전남대의 10/15 요강 공지 예정·10/17 설명회를 보완했다. 전남대 상세 자격·접수 기간은 미확인이다.
로그인 없이 읽는 정적 문서다. 공식 사실과 WB 준비 제안을 구분하고, 개인정보·API·저장소·영재원 학습 기능은 쓰지 않는다.
공식 일정은 갱신이 필요하므로 루트·haru SW가 안내 주소를 캐시하거나 학생 홈으로 대체하지 않는다.
