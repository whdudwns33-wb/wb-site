# 피드백 V4·V5 적용 (2026-09-15)

SOLAPI 채널에서 V4·V5 모두 발송 가능 상태와 원문을 확인했다.

| 과제 | 안내사항 | 템플릿 |
|---|---|---|
| 있음 | 없음 | V2 (기존) |
| 있음 | 있음 | V3 (기존) |
| 없음 | 없음 | V4 |
| 없음 | 있음 | V5 |

빈칸·공백·보이지 않는 형식 제어문자만 있는 과제는 미입력이다. '없음'을 자동 입력하지 않는다.
직접 입력한 '없음'은 입력값이므로 임의 삭제하거나 과거 기록을 변환하지 않는다.
최종 편집창에서 과제/안내사항을 입력하거나 지우면 미리보기와 템플릿도 즉시 변경된다.
과제 미입력 안내는 선생님 화면에만 표시한다.

V4/V5 마지막 인사말 앞은 빈 줄 두 개(개행 세 개)이며 나머지 항목 사이는 빈 줄 한 개다.
V2/V3의 승인된 고정 본문 및 기존 발송 이력/해시는 그대로 유지한다.
AI 다듬기의 모델, 일일 사용 제한, 개인정보 보호는 변경하지 않는다.
V4/V5에서는 과제 없이도 AI 다듬기가 가능하며 안내사항은 AI에 전송하지 않는다.
900자 전체 제한, 600자 코멘트 제한, studentId/담당자 검증, 중복 발송 방지는 유지한다.

DB 마이그레이션은 필요 없다. Worker 배포 후 Pages 배포.
이 작업에서 실수신자 대상 시험 발송이나 기존 요청 재발송을 실행하지 않는다.
