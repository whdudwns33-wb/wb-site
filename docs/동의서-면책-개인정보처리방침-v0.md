## A. 서비스 이용 동의서 (업로드 마법사 4단계에 삽입)

### A-1. 서비스 성격 고지 (읽음 확인)
> 본 서비스는 아동의 그림 및 응답을 바탕으로 심리적 특성을 **추정해 보는 참고용 평가 서비스**입니다. 의료기관이 아니며, 정신질환의 **진단이나 치료, 의학적 처치에 해당하지 않습니다.** AI가 생성한 해석 초안은 **자격을 갖춘 전문 심리사가 최종 검토·수정한 후에만** 제공됩니다.

### A-2. 동의 항목 (체크박스)
- ☑ **[필수]** 만 14세 미만 아동의 그림 해석을 위해, **법정대리인(보호자)으로서** 아동의 개인정보 수집·이용에 동의합니다.
- ☑ **[필수]** **민감정보(심리검사 결과·정신건강 관련 정보)**의 처리에 동의합니다.
  - 목적: 검사 실시·해석·상담 연계 / 항목: 그림 이미지·응답, 아동 별명·연령·성별·상황 / 보유: 검사일로부터 **○년** 후 파기 / 접근: 전문 심리사 등 최소 인원
- ☑ **[필수]** 전문가 확정 전까지 결과가 공개되지 않으며, 결과가 **진단이 아님**을 확인했습니다.
- ☐ **[선택]** 서비스 품질 개선을 위한 **비식별 데이터 활용**에 동의합니다. *(미동의해도 서비스 이용 가능)*

### A-3. 비밀보장 예외 고지 (필수 안내)
> 검사 과정에서 **자해·타해 위험** 또는 **아동학대 의심 정황**이 발견될 경우, 아동의 안전을 위해 보호자 및 관계기관(**112·119** 등)에 알릴 수 있으며, 이는 비밀보장의 예외에 해당합니다.

### A-4. 보호자 동의 확인 절차 (시스템)
- 만 14세 미만: **법정대리인 동의 필수** — 휴대폰 본인인증 등으로 보호자 확인.
- 동의 거부·5일 내 미확인 시 관련 개인정보 **파기**.

## B. 면책 문구 (모든 결과·리포트·PDF 하단 고정)

> **본 해석은 참고용이며 의학적·심리학적 진단이 아닙니다.** 정확한 평가는 전문가 대면 검사가 필요합니다. 검사 시점·환경·기분에 따라 결과가 달라질 수 있으며, 아동의 성격·능력·진로를 확정하거나 낙인찍는 근거로 사용될 수 없습니다. 본 서비스 제공자는 결과를 의료행위·법적 판단·입시·채용 등 중대한 결정의 **단독 근거**로 사용하여 발생하는 불이익에 책임지지 않습니다.

### 표현 규칙 (결과지 작성 시)
- ❌ "우울증/ADHD이다", "장애", "진단", "확진", "치료" → **금지**
- ✅ "우울 정서 경향성이 관찰되며 추가 전문가 평가가 필요합니다" → **권장(추정·권고 수준)**
- 심각 정황 시: "정신건강의학과 또는 공인 심리상담센터와의 직접 상담을 권고합니다" 명시.

## C. 개인정보 처리방침 (요약 초안)

> 정식 처리방침은 개인정보보호법 표준 양식에 맞춰 별도 작성. 아래는 핵심 골격.

| 항목 | 내용 |
|------|------|
| **수집 항목** | (필수) 아동 별명·연령·성별·상황, 그림 이미지·응답, 보호자 연락처·동의기록 / (선택) 개선용 비식별 데이터 |
| **수집 목적** | 그림검사 해석 초안 생성, 전문가 검수·확정, 학부모 리포트 제공, 상담 연계 |
| **민감정보** | 심리검사 결과·정신건강 정보 — 별도·명시적 동의, 강화된 보호(암호화·접근 최소화) |
| **보유·파기** | 목적 달성 시 지체 없이 **복구 불가능하게 파기**(백업 포함). 검사 원자료 보유 ○년. 법령상 보존의무 시 그 기간 보관 |
| **접근 권한** | 전문 심리사 및 필수 기술 인력으로 **최소화**, 접근 로그 기록 |
| **제3자 제공** | 원칙적 미제공. 상담기관·의료기관 연계 시 별도 동의. 법령상 신고 예외 |
| **처리 위탁** | AI 처리 인프라 위탁 시 수탁자 명시·감독. **일반 공개 AI(오픈 챗봇 등)에 검사자료 업로드 금지** |
| **정보주체 권리** | 보호자의 열람·정정·삭제·처리정지 요구권. 탈퇴 시 의무보존 제외하고 지체 없이 파기 |
| **안전조치** | 암호화 저장·전송, 만료·인증되는 리포트 링크, 접근통제, 감사 로그 |
| **아동 보호 원칙** | 아동 최선의 이익, 데이터 최소 수집, 투명성(청소년 개인정보보호 가이드라인) |

## D. 검사 보안 (내부 운영 규정)

- 검사 자극물·채점기준·원자료는 **전문가 통제 자료** — 비전문가 노출 금지, 인터넷 공개 금지.
- AI 모델·테스트 데이터는 별도 서버·권한 통제, 외부 유출 방지.
- 원자료(그림·응답·해석 로그)는 전문 심리사·필수 인력만 접근.

## E. 위기 대응 프로토콜 (내부)

1. **탐지**: 반복 폭력·자해 표현, 극단적 절망, 학대 의심 정황(반복 상처·특정 보호자 공포·성적/폭력 그림).
2. **조치**:
   - 급박한 생명·신체 위험 → **119**·응급의료기관 안내(보호자 통보; 단 보호자가 학대 의심 대상이면 예외 처리).
   - 아동학대 의심 → 신고의무자로서 **112** 또는 관할 아동보호전문기관 즉시 신고.
3. **비밀보장 예외 적용** + 보호자·기관 통보.
4. **기록·교육**: 경위·조치·신고 일시 내부 기록, 직원·심리사 정기 교육(학대 징후·신고 절차·자해 위험 평가).
