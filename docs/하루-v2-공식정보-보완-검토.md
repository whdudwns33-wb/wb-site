## 파일과 검사

- `catalog.json`: 기관·과정·지역 안내·출처 추가.

- `build.mjs`: 기존 펼침 UI에 지역 안내 출력, 빈 일정 안내.
- `index.html`, `gwangju-gifted/index.html`: 생성 화면.
- `public.test.cjs`: 잘못된 출처·URL·일정 및 미확인 기관의 가짜 필터/일정 방지.
- README·AGENTS·이 보고서: 상태·검토 방법·남은 확인 인계.

학생 화면·채점·API·인증·권한·KV·기록 수집·기존 정본 후보 상태는 변경하지 않았다.

`node scripts/check.mjs` 최종 **297/297 통과(38.9초)**. 초기 296/297에서 가족 자동 연결의 디스크 저장 assertion 1개가 실패했으나 해당 소스 수정 없이 단독 재검사와 최종 전체 검사가 통과했다. 원인은 확정하지 않았다.

공개 화면 세부 검사 **6개 통과**. `node reading-server/build-dist.mjs`, `git diff --check` 통과. 원본·생성물 일치 및 보호 대상 소스 무변경을 확인했다.

실제 브라우저에서 초1·인문 빈 안내, 전체 복귀·새로고침 후 21개, 예술 과정→기관 안내 이동을 확인했다. 320·390·1280px에서 긴 기관명 펼침과 광주 안내의 가로 넘침 없음, 오류 로그 없음. 실제 모바일 기기·운영 주소는 미검증이다. 캡처는 커밋하지 않는다. 모바일 예술 캡처 `art-390.jpg`는 캡처 렌더링 이상으로 증거에서 제외하며 정상인 지역 모바일·예술 데스크톱 캡처를 사용한다.
