### ② description 다이어트 (51개 스킬)

- **기계적 절단 (34개)**: `절대 하지 않는 것 …` 이후를 통째로 본문 `## 금지 사항`으로 이동.
  금지 규칙은 스킬이 실제 실행될 때 본문에서 읽히면 되는데, 안 쓰는 세션에서도 로드되고 있었다.
- **수동 재작성 (17개)**: 380자 초과분을 트리거 중심 250자 이하로 재작성.
  잘려나간 원본 트리거 목록은 본문 `## 호출 트리거 (원본 보존)`에 그대로 남겼다.

`description`에 남긴 것 — 한 줄 정의 / 호출 트리거 / 헷갈리는 스킬과의 경계선.
본문으로 내린 것 — 금지 규칙 / 산출물 상세 / 승계 이력 / 원장 파일 경로.

### ③ 라우터 계층 5겹 → 2개

`control-tower`(라우팅만) · `agent-pmo`(추적만) · `agent-ops`(감시만) 3개는

### ③-2 HR 계층 2개 → 1개

`agent-hr-cho`와 `agent-hr`은 **본문 0~12장이 바이트 단위로 완전히 동일한 복제**였다(273줄, 10,498바이트).
호출 트리거도 "강사 채용", "이력서 검토", "KK점수" 등 대부분 겹쳐 라우팅이 흔들리고 있었다.

`agent-hr` 하나로 통합했다. 산하 3종(`hr-recruiter`·`hr-onboarding`·`hr-retention`)은
각각 51KB·39KB·43KB의 서로 다른 실무 매뉴얼이라 그대로 유지한다.
이들이 이미 상위를 `CHO(agent-hr)`로 부르고 있어 참조 수정도 필요 없었다.

병합본 구성 — CHO 팀 구성·오케스트레이션 원칙(구 hr-cho) + 공통 본문 0~12장 + 보고 형식 원칙(구 agent-hr).
양쪽 원본 호출 트리거는 본문 `## 호출 트리거 (원본 보존)`에 모두 남겼다.

### ③-3 비서 계층 → agent-google 통합

`agent-secretary`는 Google Calendar 생성·수정·삭제의 **유일한 주체**이면서
Gmail·Drive의 주 사용처였고, 13개 스킬이 의존하고 있었다.
`agent-google`이 이미 Google 생태계 전담이면서 제외목록에 "Calendar·Gmail 관리는 agent-secretary"라고
적어둔 상태였으므로, 비서를 폐지하면서 그 권한을 agent-google로 옮겼다.

`agent-google`에 **Step 0. Google Workspace 운영** 섹션을 신설해 시간대별 루틴, 아침·야간 브리핑,
캘린더 관리(캘린더 ID 포함), Gmail 초안, Drive, 외부 모드, 영준님 할일 프로토콜,
직원 업무 라우팅을 전부 이관했다. 역할 경계와 생태계 현황 블록도 함께 갱신했다.

**`agent-make` 삭제** — Make × n8n 병행 실험을 종료하고 자동화 담당을 `agent-cto`로 일원화했다.

확인해 보니 이 스킬의 기준 자료 우선순위 2번이 **스터디포스 구독 엑셀**이고,

최신 엑셀 대신 이 표를 믿을 위험). 표를 통째로 지우고 **판정 규칙만** 남겼다 —

기능상 필요해 유지했다 — 다만 스킬 본문에 실명이 있다는 사실 자체는 인지하고 계셔야 한다.

**description 추가 절감은 하지 않았다** — 300자 기준으로 맞춰도 701자(~470토큰),
전체의 2.7%에 불과하고 라우팅 정확도가 떨어질 위험이 절감분보다 크다.

## 적용 방법

스킬은 **claude.ai 계정에서 동기화**된다 (`~/.claude/skills/synced/manifest.json`의 `skillId`).
로컬에서 지워도 다음 세션에 복구되므로, 아래 순서로 claude.ai에 반영해야 한다.

1. **선행 조건 하나만 먼저** — n8n 워크플로우 `WF-SUMMARYBUILD01`의 호출 대상을
   `agent-consultation-summary-builder` → `agent-consult`로 변경.
   `control-tower`를 호출하는 n8n 트리거가 있다면 `agent-coo`로 변경.
2. **삭제** — [`DELETE-LIST.md`](./DELETE-LIST.md)의 27개를 claude.ai 스킬 설정에서 제거.
3. **교체** — 전달된 zip의 `skills-modified/` 47개 `SKILL.md`로 기존 스킬 내용 교체.
4. **확인** — 새 세션을 열어 `agent-coo`, `agent-consult`, `agent-booking`이 정상 호출되는지 점검.

되돌려야 하면 zip의 `_archive/`에 제거된 27개 원본이 그대로 있다.
