## 기술 실측 (① 어디가)
- JSP 서버렌더링 + HTML조각 AJAX. 로그인 없이 curl로 학과별 50/70%컷·경쟁률·충원·모집요강 PDF까지 수신 확인.
- 핵심 엔드포인트: criteriaAndResultItemNewAjax.do(전년도 입결), classUnivAdmssPopupAjax.do(학과별 상세), fileDown.do(요강 PDF).
- 병목은 접근이 아니라 파싱(대학마다 제각각 에디터산 표)과 CSRF/세션 처리.

## 법적 판단 (핵심)
- adiga.kr 저작권정책: 전 자료 대교협 소유, **영리 이용·수익 목적은 사전 협의(02-6919-3975) + 출처 명시 의무**.
- robots.txt: `User-agent: * → Disallow: /` (봇 전면 차단). 약관 제15조: 정보 재제공 금지.
- **사실정보(등급컷·경쟁률 등 수치) 개별 인용은 저작권 침해 아님** — 보호 대상은 화면·DB의 '상당한 부분' 복제.
- 안전선: 직원이 브라우저로 조회 → 수치를 자체 양식에 옮기고 출처 표시. (앱 설계가 이 선.)
- 위험선: 프로그램 대량 크롤링으로 DB화 / 유료 상품에 화면·PDF 통째 재가공.

## 앱 반영 (3건)
1. 수집 프롬프트 → "소량 조회·수치인용·출처표시" 원칙 명문화 (copyAdigaCollect/Bulk)
2. 공공 API 프롬프트 → "등급컷 없음, 정량 전용" 실측 반영 + 실제 데이터셋 ID (copyAdigaApi)
3. 노하우 랩 → "입시 데이터 배포 캘린더" 신설 (4월말 시행계획 / 5월말 입결 갱신 등)
