# 진로독서 웹앱 기획서 — WB 리딩커리어 (가칭)

> WB 독해력학원 · 웩슬러브레인센터 | 초·중·고 진로 맞춤 비문학 독서 웹앱
> 문서 버전 v1.0 · 작성일 2026-08-25
> 최신 비문학 자료 기반 → 진로 맞춤 읽기 → (선택) 문제 풀이 → 탐구보고서 작성까지 한 흐름으로 잇는다.

---

## 0. 한 줄 요약

**학생이 자기 진로 관심사를 고르면, 최신 비문학 자료(뉴스·과학·정책·기술)를 학년 수준에 맞게 다듬은 지문이 매일 추천되고 → 읽은 뒤 원하면 문제를 풀어 이해도를 확인하고 → 읽은 글들이 쌓이면 이를 재료로 탐구보고서를 단계별로 완성하는 웹앱.**

핵심 원칙 세 가지:
1. **읽기가 먼저, 문제는 선택.** 문제 풀이를 강제하지 않는다. "읽고 끝"도 완결된 경험이다.
2. **진로가 큐레이션의 축.** 같은 최신 자료도 의약 계열 학생과 공학 계열 학생에게 다른 지문으로 다듬어 준다.
3. **AI는 코치, 학생이 저자.** 탐구보고서에서 AI는 질문으로 유도하고 출처를 정리해 줄 뿐, 문장을 대신 써 주지 않는다.

## 1. 배경 & 문제 정의

### 1.1 왜 이 서비스인가

| 대상 | Pain Point | 이 서비스가 주는 것 |
|------|-----------|-------------------|
| **학생** | 교과서·문제집 비문학은 낡고 재미없다. 진로와 무관한 글을 억지로 읽는다 | 내 진로 관심사에 맞는 "지금 세상 이야기"를 내 수준으로 읽는다 |
| **고등학생** | 세특·탐구활동 소재가 없다. 탐구보고서를 어떻게 시작할지 모른다 | 읽어 온 글이 그대로 탐구 소재가 되고, 보고서가 단계별로 완성된다 |
| **학부모** | 아이가 뭘 읽는지, 독해력이 느는지 보이지 않는다 | 독서 이력·레벨 변화·진로 독서 포트폴리오가 리포트로 보인다 |
| **WB 학원** | 독해 수업 교재가 고정 지문 중심. 원생 외 접점이 없다 | 최신 지문이 자동 수급되는 수업 보조 도구 + 외부 학생 유입 채널 |

### 1.2 왜 WB인가
- WB 독해력학원은 이미 **레벨 5단계 독해 커리큘럼**과 강사 검수 체계를 운영 중 → 지문 레벨링·검수 게이트를 얹을 조직적 기반이 있다.
- 그림검사 AI 해석 웹에서 검증한 **"AI 초안 → 전문가 확정 게이트 → 소비자용 쉬운 출력"** 파이프라인 패턴을 그대로 재사용한다.
- 원내 태블릿 학습존(§9.4)이 있어 **원내 수행 → 가정 연계**의 이중 배포가 즉시 가능하다.

## 2. 목표 & 성공 지표(KPI)

### 2.1 목표
1. 원생의 **주간 비문학 독서량 3편 이상** 습관화.
2. 고등 원생 **탐구보고서 학기당 1편 이상** 완성 (세특 대비).
3. 외부 학생 유입 → 레벨 진단 → 상담 예약 전환 리드 창출.

### 2.2 KPI
- **North Star**: 주간 "완독" 수 (읽기 완료로 기록된 지문 수).
- 습관 지표: 주간 활성 학생 비율(WAU/재원생), 연속 읽기 일수 중앙값.
- 학습 지표: 문제 풀이 선택률, 정답률 추이, 레벨 승급 수.
- 산출 지표: 탐구보고서 완성 수, 보고서당 인용 지문 수.
- 전환 지표: 외부 방문 → 레벨 진단 완료율 → 상담 예약 전환율.

## 4. 핵심 사용자 플로우

```
[온보딩]                [매일 루프]                    [마일스톤]
학년 선택            →  오늘의 추천 지문 (진로 3 + 교양 1) →  읽은 글이 5편 쌓이면
진로 관심사 선택     →  읽기 (어휘 도움·읽기 타이머)      →  "탐구 주제 제안" 활성화
레벨 진단 (지문 2편) →  (선택) 문제 풀이 → 즉시 채점·해설  →  탐구보고서 위저드
                     →  한 줄 소감 / 스크랩              →  완성 → PDF/DOCX 내보내기
                                                        →  학부모·교사 공유
```

### 4.1 온보딩 (첫 방문, 5분)
1. **학년 선택**: 초3~고3.
2. **진로 관심사 선택**: 학년대별로 다른 UI.
   - 초등: 그림 카드 12장 중 3개 (동물·우주·로봇·음식·스포츠·그림·이야기·자연·숫자·만들기·사람 돕기·무대).
   - 중등: 계열 카드 (공학·IT·의약·바이오·경영·경제·미디어·콘텐츠·법·행정·교육·예술·디자인·과학연구·환경·스포츠).
   - 고등: 계열 → 세부 학과/직업 검색 (커리어넷 분류 연동, §7.3).
3. **레벨 진단**: 짧은 지문 2편 + 문항 6개 → 시작 레벨 배정 (WB 레벨 5단계와 매핑).
4. 결과 화면: "너의 시작 레벨은 L3. ○○ 계열 글을 매일 3편 추천할게."

### 4.2 매일 읽기 루프 (10~20분)
1. **오늘의 피드**: 진로 맞춤 3편 + 시야 확장용 교양 1편 (진로 편식 방지). 각 카드에 분야·레벨·예상 읽기 시간·"왜 추천?" 한 줄.
2. **읽기 화면**:
   - 지문 본문 (원내 태블릿 가독성 기준: 큰 글자, 좁은 열폭).
   - 밑줄·형광펜, 모르는 단어 탭 → 쉬운 풀이 (어휘장 자동 적립).
   - 읽기 시간 자동 측정 (WPM은 내부 지표로만, 학생에겐 비노출 — 속독 유도 방지).
   - 하단 3택 자기 평가: "잘 이해했어 / 어려웠어 / 다시 읽을래".
3. **읽기 완료 = 완독 기록**. 여기서 끝내도 된다. 이어서 두 갈래 선택지:
   - **"문제 풀어보기"** (선택) → §4.3.
   - **"스크랩"** → 탐구보고서 재료함에 저장 + 한 줄 소감.

### 4.3 문제 풀이 (선택, 5분)
- 지문당 4~6문항, 유형 고정: ① 핵심 내용 확인 ② 세부 정보 ③ 어휘(문맥 추론) ④ 추론·적용 ⑤ (고등) 비판·강화약화.
- 즉시 채점 + 문항별 해설 ("지문 몇째 문단에 근거"). 오답은 지문 해당 문단 하이라이트로 되돌아가기.
- 결과는 레벨 조정 신호로 사용: 최근 10회 정답률 85%↑ → 승급 제안, 60%↓ → 하향 제안 (강사 승인 게이트).

### 4.4 탐구보고서 위저드 (마일스톤, 학기 단위)
스크랩 5편↑ 또는 학생이 원할 때 시작. **단계별 작성 + AI 코칭**:

| 단계 | 학생이 하는 일 | AI가 하는 일 (코치 역할만) |
|------|--------------|--------------------------|
| ① 주제 잡기 | 스크랩한 글 목록에서 관심 글 선택 | 선택한 글들의 공통 주제 후보 3개 제안 + "왜 궁금한지" 질문 |
| ② 탐구 동기 | 자기 언어로 동기 작성 | 막히면 유도 질문 ("이 글에서 가장 놀란 부분은?") |
| ③ 알게 된 내용 | 읽은 지문 요약·정리 | 학생 요약과 원문 대조해 빠진 핵심·잘못 이해한 부분 지적 |
| ④ 더 알아보기 | 추가 지문 1~2편 읽기 | 주제 관련 추가 지문 추천 |
| ⑤ 결론·느낀 점 | 결론 작성 | 논리 점검 질문 ("근거가 결론을 지지하나?") |
| ⑥ 완성 | 제목 정하고 제출 | 출처 목록 자동 생성 (지문 원 출처 표기), 맞춤법 점검 |

- **대필 방지 원칙**: AI는 문장을 생성해 주지 않는다. 질문·지적·출처 정리만. 학생 입력 최소 글자수 게이트. 작성 과정(단계별 타임스탬프·수정 이력)이 보고서 메타로 남아 "직접 썼음"의 근거가 된다.
- 산출물: 학년대별 템플릿 (초등: 그림+3문단 / 중등: 5문단 / 고등: 표준 탐구보고서 구조). PDF·DOCX 내보내기, 학부모 공유 링크.
- 고등은 완성 후 **강사 피드백 요청** 버튼 → 세특 연계 코멘트 (§6 교사 도구).

### 4.5 리포트 (주간·학기)
- **학생**: 연속 읽기 일수, 완독 수, 분야 지도(내가 읽은 분야 분포), 어휘장, 레벨 변화.
- **학부모**: 주간 요약 (읽은 글 제목·분야, 자기평가 분포, 보고서 진행 상황) — 알림 발송은 기존 WB 알림 체계(승인 게이트) 경유.
- **강사**: 반별 현황판 — 미수행자, 정답률 급락자, 레벨 조정 대기, 보고서 피드백 대기.

## 5. 콘텐츠 파이프라인 — "최신 비문학"을 만드는 법

이 서비스의 성패는 **콘텐츠 수급의 지속가능성**에 달려 있다. 3층 구조로 설계한다.

### 5.1 소스층 (저작권 안전 확보)
| 소스 | 성격 | 라이선스 |
|------|------|---------|
| 공공저작물 (공공누리 1유형) | 정책브리핑, 부처 보도자료, 국립과학관·창의재단 콘텐츠 | 자유 이용 (출처 표시) |
| 언론 기사 | 시사·과학·기술 최신 이슈 | **원문 게재 아님** — 사실 소재로만 참조, 지문은 재작성 (§5.2). 원문 링크는 "더 읽기"로 제공 |
| 전문 매체 제휴 | 어린이·청소년 과학/시사 매체 | 후순위 (v2) — B2B 제휴 협의 |
| 자체 제작 | WB 강사진 집필 지문 (기존 교재 자산) | 자체 보유 |

### 5.2 가공층 (AI 재작성 + 레벨링)
그림검사 웹의 S0→S3 파이프라인 패턴을 재사용한 **지문 생산 라인**:

```
P0 소재 수집   → 공공자료·이슈 키워드에서 소재 후보 큐 적재 (일 단위 배치)
P1 사실 추출   → Claude가 소재에서 사실·수치·인용을 구조화 추출 (tool-use 강제)
P2 지문 생성   → 레벨별 재작성: 같은 소재로 L1(초등 저)~L5(고등) 지문 병렬 생성
                 - 레벨 규격: 글자 수·문단 수·문장 길이·한자어 비율·개념 밀도 정의
P3 검증 게이트 → ① 자동: 원 소재 대조 사실성 점검, 금지 소재 필터(정치 쟁점·선정성·광고)
                 ② 수동: WB 강사 검수 후 발행 (초기 전수 → 신뢰 쌓이면 표본 검수)
P4 문항 생성   → 발행 지문에서 유형 고정 문항 자동 생성 → 강사 검수 → 활성화
```

- 발행 목표: **일 4~6지문 × 레벨 5 = 주 140~210개 지문 변형**. 초기(MVP)는 주 10소재 수동 큐레이션으로 시작.
- 모든 지문에 태그: 분야(진로 계열 매핑), 레벨, 소재 출처, 발행일, 검수자.

### 5.3 레벨 체계
- 학원 기존 **레벨 5단계**와 1:1 매핑 (L1 초3~4 / L2 초5~6 / L3 중등 / L4 고등 기본 / L5 고등 심화).
- 지문 난도는 규격표(글자 수·문장당 어절·저빈도 어휘 비율)로 관리하고, 한국어 이독성 지수는 보조 지표로 도입 검토.

## 6. 진로 매핑 체계

- **분류 축**: 커리어넷 직업·학과 분류를 기준 축으로 삼아 내부 계열 16개로 단순화 → 지문 태그와 학생 관심사를 같은 축으로 매칭.
- **학년별 해상도**: 초등 = 흥미 12카드 → 계열로 느슨히 매핑 / 중등 = 계열 / 고등 = 계열 + 세부 학과·직업.
- **진로 콘텐츠 확장 (v2)**: 지문 하단 "이 글과 연결된 직업·학과" 카드 (커리어넷 데이터 연동), 진로 변경 이력 관리 (변경은 자유 — 탐색 자체가 목적).

```
├─ 홈(오늘의 피드): 추천 4카드 + 연속 읽기 배지 + 보고서 진행 배너
├─ 읽기 화면: 본문·어휘 탭·자기평가 → [문제 풀기 | 스크랩 | 닫기]
├─ 문제 화면: 문항 → 즉시 채점 → 해설·근거 하이라이트
├─ 서재: 완독 이력 / 스크랩(보고서 재료함) / 어휘장
├─ 탐구 랩: 보고서 위저드 6단계 / 완성작 목록 / 내보내기
├─ 내 리포트: 레벨·분야 지도·주간 요약
└─ (강사용) 관리: 검수 큐 / 반별 현황 / 레벨 조정 승인 / 보고서 피드백
```

- 학생 화면은 기존 `/student` 포털 디자인 시스템(내비·카드·태그 스타일)을 따르고, 진입 링크를 학생 포털 홈에 추가한다.

## 9. 기술 설계

### 9.1 아키텍처 — 기존 wb-site 패턴 준수
- **프론트**: 정적 HTML + 바닐라 JS 단일 파일 앱 (기존 `/student` 포털과 동일 패턴). 신규 경로 `/reading`.
- **백엔드**: Node 22 무의존성 서버 패턴 재사용 (`backend/` 구조 미러링). 인메모리 스토어 → PostgreSQL 전환 지점 동일.
- **AI**: `claudeClient.mjs` 패턴 재사용 — 키 없으면 mock, 있으면 실호출. 지문 생성(P2)은 `claude-opus-5`, 사실 추출·문항 생성은 `claude-sonnet-5`로 단계별 모델 지정.
- **파이프라인 상태머신**: 지문 상태 전이(`draft → generated → verifying → reviewing → published → retired`)를 그림검사 웹 `stateMachine.mjs` 패턴으로.

### 9.2 안전·품질 가드레일
- 지문 금지 소재 필터: 정치적 쟁점 편향, 선정성, 특정 상품 광고성, 미확정 의학 정보.
- 사실성: P1 추출 사실만 지문에 사용 (생성 단계에서 새 사실 추가 금지 — 프롬프트 + 자동 대조 검증).
- 탐구보고서 AI 응답: "문장 대신 써주기" 요청 거부 프롬프트, 학생 텍스트 필수 게이트.
- 개인정보: 학생 실명·연락처는 기존 원생 체계에만, 앱 내부는 학생 코드 참조 (기존 개인정보 게이트 준수).

### 9.3 브라우저 제약 (원내 배포 전제)
- 원내 학생 학습존 태블릿(Advanced2)은 **Chrome 138 영구 동결** → 신규 앱은 Chrome 138 호환 범위의 웹 표준만 사용, 번들 의존성 최소화. (기존 태블릿 기획서 v3의 Tier S 사이트 목록에 본 앱 추가.)

### 9.4 배포
- 정적 프론트는 기존 wb-site 배포 흐름, 백엔드는 기존 backend 배포와 동일 (Dockerfile 패턴).

## 10. 운영 모델

| 구분 | 내용 |
|------|------|
| **원생 (1차)** | 수강에 포함. 수업 보조(원내 태블릿) + 가정 숙제. 강사가 주간 과제로 배정 |
| **외부 학생 (2차, v2)** | 무료: 레벨 진단 + 주 2편 체험 → 유료 구독 or 학원 상담 전환 |
| **콘텐츠 운영** | 주간 소재 편성회의(강사 1인 + 운영 1인, 주 1회 30분) → 파이프라인 자동 생성 → 검수 큐 소화 (강사 1인 일 20분 목표) |
| **검수 SLA** | 지문 발행 전 강사 검수 필수 (초기 전수). 문항 오류 신고 버튼 → 24시간 내 처리 |
