# 진로독서 웹앱 기획서 — WB 리딩커리어 (가칭)

> WB 독해력학원 · 웩슬러브레인센터 | 초·중·고 진로 맞춤 비문학 독서 웹앱
> 문서 버전 v1.1 · 작성일 2026-08-25
> 최신 비문학 자료 기반 → 진로 맞춤 읽기 → (선택) 문제 풀이 → 탐구보고서 작성까지 한 흐름으로 잇는다.
> v1.1 — 원장 추가 요구 반영: 하루 1지문 습관, 의미 단위 끊어 읽기, 한자어 어휘 학습, 스터디포스 붉은 책 요약 세션, 국내외 공개 논문 연계, 영어 대역 보기, 역사·사회·과학 전 분야 편성, 연계도서 추천.

---

## 0. 한 줄 요약

**학생이 자기 진로 관심사를 고르면, 최신 비문학 자료(과학·사회·역사·기술·정책)를 학년 수준에 맞게 다듬은 지문이 매일 1편씩 도착하고 → 의미 단위 끊어 읽기·한자어 어휘 도움을 받으며 읽고 → 원하면 문제를 풀어 이해도를 확인하고 → 원 논문·연계도서·영어 대역으로 확장하고 → 읽은 글들이 쌓이면 이를 재료로 탐구보고서를 단계별로 완성하는 웹앱.**

핵심 원칙 네 가지:
1. **하루 1지문이 기본 단위.** 최소 완수 기준은 "매일 1편 완독". 더 읽는 것은 자유, 안 읽은 날이 보이는 것이 설계의 핵심.
2. **읽기가 먼저, 문제는 선택.** 문제 풀이를 강제하지 않는다. "읽고 끝"도 완결된 경험이다.
3. **진로가 큐레이션의 축.** 같은 최신 자료도 의약 계열 학생과 공학 계열 학생에게 다른 지문으로 다듬어 준다.
4. **AI는 코치, 학생이 저자.** 탐구보고서·요약 훈련에서 AI는 질문으로 유도하고 빠진 것을 짚어 줄 뿐, 문장을 대신 써 주지 않는다.

## 1. 배경 & 문제 정의

### 1.1 왜 이 서비스인가

| 대상 | Pain Point | 이 서비스가 주는 것 |
|------|-----------|-------------------|
| **학생** | 교과서·문제집 비문학은 낡고 재미없다. 진로와 무관한 글을 억지로 읽는다 | 내 진로 관심사에 맞는 "지금 세상 이야기"를 내 수준으로 읽는다 |
| **고등학생** | 세특·탐구활동 소재가 없다. 탐구보고서를 어떻게 시작할지 모른다 | 읽어 온 글이 그대로 탐구 소재가 되고, 보고서가 단계별로 완성된다 |
| **학부모** | 아이가 뭘 읽는지, 독해력이 느는지 보이지 않는다 | 독서 이력·레벨 변화·진로 독서 포트폴리오가 리포트로 보인다 |
| **WB 학원** | 독해 수업 교재가 고정 지문 중심. 원생 외 접점이 없다 | 최신 지문이 자동 수급되는 수업 보조 도구 + 외부 학생 유입 채널 |

### 1.2 왜 WB인가
- WB 독해력학원은 이미 **레벨 5단계 독해 커리큘럼**과 강사 검수 체계를 운영 중 → 지문 레벨링·검수 게이트를 얹을 조직적 기반이 있다.
- 그림검사 AI 해석 웹에서 검증한 **"AI 초안 → 전문가 확정 게이트 → 소비자용 쉬운 출력"** 파이프라인 패턴을 그대로 재사용한다.
- 원내 태블릿 학습존(§9.4)이 있어 **원내 수행 → 가정 연계**의 이중 배포가 즉시 가능하다.

### 1.3 시장 공백 (2026-08-25 웹 리서치 요약 — 상세 §13)

**결론: "진로 맞춤 비문학 읽기 → 문제 풀이 → 탐구보고서"를 잇는 서비스는 시장에 없다.** 조사한 12개+ 서비스에서 확인된 구조적 분절:

1. **공공 독서 플랫폼**(독서로·책열매)은 무료·전국 단위지만 실물 도서 중심 — 비문학 지문 훈련·진로 연계 없음.
2. **유료 문해력 시장은 초등 편중**(밀크T·엘리하이·온리원·홈런·웅진). 중·고 비문학은 기출 반복(매3비류 교재, 기출 앱)으로 좁아진다.
3. **AI 지문 생성 기술은 이미 상용화**(젠큐·꾸거·Phedy Lab)됐으나 교사용 B2B 도구에 머묾 — 학생 개인의 진로에 맞춘 학습 경험으로 패키징한 사업자 없음.
4. **탐구보고서는 컨설팅 영역**(학종Q·세특연구소 — 고가·비정형·읽기 훈련 없음). 읽기(입력)와 보고서(출력)를 잇는 서비스 부재.
5. **진로 기반 비문학 큐레이션은 조사 범위 내 전무.**

**제도 순풍**: 2022 개정 교육과정이 고교 진로선택 과목 **「주제 탐구 독서」**(진로 관련 주제를 정해 깊이 읽는 과목 — 본 앱 컨셉과 그대로 일치)를 신설했고, 초6·중3·고3 **진로연계학기**와 중1 자유학기 진로탐색(102시간)이 정규 시간 슬롯이 됐다. 2024학년도 대입부터 생기부 '독서활동상황'이 미반영·자소서 폐지되면서 **"무엇을 읽었나"가 아니라 "읽고 무엇을 탐구했나"(세특 기재)가 평가되는 구조** — 이 앱의 산출물 지향과 정확히 부합한다.

**네이버 관련**: 네이버가 직접 운영하는 학생 독서·비문학·진로 통합 서비스는 현재 없다(쥬니버·쥬니버스쿨·오디오클립·클로바X 모두 2025~2026년 종료). 원장이 들은 "네이버의 비슷한 서비스"의 실체는 ① **네이버 프리미엄콘텐츠의 국어·비문학 유료 채널**(월 1,800~9,900원대 구독, 지문+해설+문제) 또는 ② **네이버 D2SF가 투자해 "네이버 서비스"로 알려진 레서/러니**(AI·시선추적 독해력 진단·훈련, 초3~고3)로 추정된다. 둘 다 진로 축·탐구보고서 산출물은 없다.

## 2. 목표 & 성공 지표(KPI)

### 2.1 목표
1. 원생의 **하루 1지문 완독 습관화** (주 5일 이상 수행률 70%).
2. 고등 원생 **탐구보고서 학기당 1편 이상** 완성 (세특 대비).
3. 외부 학생 유입 → 레벨 진단 → 상담 예약 전환 리드 창출.

### 2.2 KPI
- **North Star**: 일간 "오늘의 1지문" 완수율 (완수 학생 / 활성 학생).
- 습관 지표: 연속 읽기 일수(스트릭) 중앙값, 주간 활성 학생 비율(WAU/재원생).
- 학습 지표: 문제 풀이 선택률, 정답률 추이, 레벨 승급 수, 훈련 세션 주간 수행 수, 어휘장 적립·복습 완료 수.
- 산출 지표: 탐구보고서 완성 수, 보고서당 인용 지문·논문 수, 연계도서 완독 수, 붉은 책 요약 확인 수.
- 전환 지표: 외부 방문 → 레벨 진단 완료율 → 상담 예약 전환율.

## 4. 핵심 사용자 플로우

```
[온보딩]                [매일 루프 — 하루 1지문]              [마일스톤]
학년 선택            →  오늘의 1지문 (진로 맞춤 필수 미션)    →  읽은 글이 5편 쌓이면
진로 관심사 선택     →  읽기 (끊어 읽기·한자어 도움·타이머)   →  "탐구 주제 제안" 활성화
레벨 진단 (지문 2편) →  (선택) 문제 풀이 → 즉시 채점·해설     →  탐구보고서 위저드
                     →  (선택) 더 깊이: 원 논문·연계도서·영어 →  완성 → PDF/DOCX 내보내기
                     →  한 줄 소감 / 스크랩 / 더 읽기        →  학부모·교사 공유
                     →  (병행) 훈련 세션: 끊어 읽기·어휘·요약
```

### 4.1 온보딩 (첫 방문, 5분)
1. **학년 선택**: 초3~고3.
2. **진로 관심사 선택**: 학년대별로 다른 UI.
   - 초등: 그림 카드 12장 중 3개 (동물·우주·로봇·음식·스포츠·그림·이야기·자연·숫자·만들기·사람 돕기·무대).
   - 중등: 계열 카드 (공학·IT·의약·바이오·경영·경제·미디어·콘텐츠·법·행정·교육·예술·디자인·과학연구·환경·스포츠).
   - 고등: 계열 → 세부 학과/직업 검색 (커리어넷 분류 연동, §7.3).
3. **레벨 진단**: 짧은 지문 2편 + 문항 6개 → 시작 레벨 배정 (WB 레벨 5단계와 매핑).
4. 결과 화면: "너의 시작 레벨은 L3. ○○ 계열 글을 매일 3편 추천할게."

### 4.2 매일 읽기 루프 — "하루 1지문" (10~20분)
1. **오늘의 1지문**: 매일 아침 진로·레벨 맞춤 지문 1편이 "오늘의 미션"으로 도착. 완독하면 연속 읽기 스트릭이 쌓인다 (최소 완수 단위).
   - 아래에 **더 읽기 추천 3편** (진로 2 + 시야 확장 교양 1 — 진로 편식 방지). 각 카드에 분야·레벨·예상 읽기 시간·"왜 추천?" 한 줄.
   - 분야 편성 원칙: 주간 단위로 **과학·기술 / 사회·경제 / 역사·문화** 가 모두 포함되도록 오늘의 1지문을 로테이션 (진로 가중 + 분야 균형).
2. **읽기 화면**:
   - 지문 본문 (원내 태블릿 가독성 기준: 큰 글자, 좁은 열폭).
   - **끊어 읽기 보기 토글**: 의미 단위(구·절)로 분절 표시(`/` 또는 색 블록). 레벨이 낮을수록 기본 켜짐 → 훈련이 쌓이면 끄고 읽기 (§4.5-A).
   - 밑줄·형광펜, 모르는 단어 탭 → 쉬운 풀이 + **한자어 분해**(예: 관측(觀測)=볼 관·잴 측) → 어휘장 자동 적립 (§4.5-B).
   - **영어 대역 토글** (중·고등): 문단 단위 한/영 병렬 보기. 같은 내용을 영어로 다시 읽으며 영어 독해와 연결 (AI 번역 + 검수, §5.2).
   - 읽기 시간 자동 측정 (WPM은 내부 지표로만, 학생에겐 비노출 — 속독 유도 방지).
   - 하단 3택 자기 평가: "잘 이해했어 / 어려웠어 / 다시 읽을래".
3. **읽기 완료 = 완독 기록**. 여기서 끝내도 된다. 이어지는 선택지:
   - **"문제 풀어보기"** (선택) → §4.3.
   - **"더 깊이 보기"** (선택) → 원 자료·논문 링크, 연계도서 카드 → §4.4.
   - **"스크랩"** → 탐구보고서 재료함에 저장 + 한 줄 소감.

### 4.3 문제 풀이 (선택, 5분)
- 지문당 4~6문항, 유형 고정: ① 핵심 내용 확인 ② 세부 정보 ③ 어휘(문맥 추론) ④ 추론·적용 ⑤ (고등) 비판·강화약화.
- 즉시 채점 + 문항별 해설 ("지문 몇째 문단에 근거"). 오답은 지문 해당 문단 하이라이트로 되돌아가기.
- 결과는 레벨 조정 신호로 사용: 최근 10회 정답률 85%↑ → 승급 제안, 60%↓ → 하향 제안 (강사 승인 게이트).

### 4.4 더 깊이 보기 — 원 자료·논문·연계도서 (선택)
완독한 지문 하단에 확장 카드 3종을 노출한다. 지문이 "입구"라면 여기가 "다음 방"이다.

- **원 자료 보기**: 지문의 소재가 된 원 출처(보도자료·기사·보고서) 링크. "이 지문은 이 자료를 너의 수준으로 다시 쓴 것"임을 투명하게 보여준다.
- **원 논문 보기 (중·고등)**: 소재와 연결된 **공개(오픈액세스) 논문**을 국내·국외 각각 연계.
  - 국내: KCI·RISS·KOAR 등 공개 원문. 국외: arXiv·PubMed Central·DOAJ 등.
  - 논문 카드 구성: 제목(원제+한글 번역) · 저자·연도 · **학생 눈높이 초록 해설**(AI 생성 3~5문장, 강사 검수) · 원문 링크.
  - 고등 탐구보고서에서 이 논문을 인용하면 출처 목록에 자동 정리 → 세특 수준을 한 단계 올리는 장치.
  - 링크는 **합법적으로 공개된 원문만** 연결한다 (유료 DB 우회 금지).
- **연계도서 추천**: 지문 주제·진로 계열·학생 레벨에 맞는 권장 도서 1~2권 카드 (표지·한 줄 추천 이유·도서관 소장 검색 링크).
  - 1순위: WB 커리큘럼의 자체 권장도서 목록에서 매칭. 2순위: 공공 도서관 빅데이터 기반 인기 대출 도서.
  - "읽고 있어요/다 읽었어요" 체크 → 독서 이력에 연계도서로 기록되어 지문-도서가 이어진 **연계 독서 포트폴리오**가 된다. 탐구보고서 재료로도 인용 가능.

### 4.5 훈련 세션 — 읽기 근육 만들기 (매일 루프와 병행)
매일 1지문이 "실전"이라면, 훈련 세션은 "기본기"다. 주 2~3회, 회당 5~10분 설계.

**A. 의미 단위 끊어 읽기 훈련** (WB 독해력 커리큘럼의 핵심 훈련을 앱으로)
- 1단계: 분절 표시된 문장을 의미 단위로 따라 읽기 (탭하면 다음 단위 하이라이트).
- 2단계: 분절 없는 문장에 **학생이 직접 `/` 끊기** → 모범 분절과 비교, 차이 해설.
- 3단계: 끊어 읽기 OFF 상태로 지문 읽기 → 이해도 문항으로 전이 확인.
- 훈련 텍스트는 그 주의 지문에서 발췌 (별도 콘텐츠 제작 부담 없음).

**B. 어휘·한자어 학습**
- 읽기 중 탭한 단어가 어휘장에 쌓이고, 훈련 세션에서 복습 퀴즈로 재등장 (간격 반복).
- **한자어 어근 학습**: 어휘를 한자 단위로 분해하고, 같은 한자를 공유하는 어휘를 묶어 확장 (예: 觀 — 관측·관찰·관점·객관). "한자 1개 → 어휘 5개"의 지렛대 구조.
- 학년별 수위: 초등은 뜻풀이 중심(한자 노출 최소), 중등부터 한자 병기, 고등은 개념어(추상·전제·반증…) 중심.
- 주간 리포트에 "이번 주 새로 얻은 어휘 n개, 한자 어근 m개" 표기.

**C. 스터디포스 붉은 책 요약 세션** (원내 프로그램 연계)
- 원생이 수행 중인 **스터디포스 '붉은 책' 교재**의 단원 읽기와 앱의 요약 훈련을 연결한다.
- 흐름: 학생이 책에서 해당 단원을 읽는다 (책은 실물/스터디포스 화면) → 앱에서 **자기 언어로 요약 입력** → AI가 강사 등록 체크리스트(단원별 핵심 포인트)와 대조해 피드백: 빠진 핵심·잘못 이해한 부분·불필요한 세부를 짚는다 → 재요약 1회 → 강사 확인.
- **교재 원문은 앱에 게재하지 않는다** (저작권 — 학생은 책으로 읽고, 앱은 요약만 받는다). 강사가 단원별 핵심 포인트만 등록해 두는 방식이라 교재 전문 사용권 문제를 피한다. 스터디포스와의 이용 계약 범위는 확인 필요 (§14).
- 요약 이력은 스터디포스 수행 관리(구독생 관리 체계)와 연동해 미수행 추적에 반영.

### 4.6 탐구보고서 위저드 (마일스톤, 학기 단위)
스크랩 5편↑ 또는 학생이 원할 때 시작. **단계별 작성 + AI 코칭**:

| 단계 | 학생이 하는 일 | AI가 하는 일 (코치 역할만) |
|------|--------------|--------------------------|
| ① 주제 잡기 | 스크랩한 글 목록에서 관심 글 선택 | 선택한 글들의 공통 주제 후보 3개 제안 + "왜 궁금한지" 질문 |
| ② 탐구 동기 | 자기 언어로 동기 작성 | 막히면 유도 질문 ("이 글에서 가장 놀란 부분은?") |
| ③ 알게 된 내용 | 읽은 지문 요약·정리 | 학생 요약과 원문 대조해 빠진 핵심·잘못 이해한 부분 지적 |
| ④ 더 알아보기 | 추가 지문 1~2편 읽기, (고등) 연계 논문 초록·연계도서 참조 | 주제 관련 추가 지문·공개 논문·도서 추천 (§4.4) |
| ⑤ 결론·느낀 점 | 결론 작성 | 논리 점검 질문 ("근거가 결론을 지지하나?") |
| ⑥ 완성 | 제목 정하고 제출 | 출처 목록 자동 생성 (지문 원 출처 표기), 맞춤법 점검 |

- **대필 방지 원칙**: AI는 문장을 생성해 주지 않는다. 질문·지적·출처 정리만. 학생 입력 최소 글자수 게이트. 작성 과정(단계별 타임스탬프·수정 이력)이 보고서 메타로 남아 "직접 썼음"의 근거가 된다.
- **산출물 템플릿 — 학교 통용 구조와 정렬 (리서치 확인)**: 공통 7블록 = ① 주제 선정 이유(진로 연계 동기) ② 탐구 질문 ③ 읽은 자료·근거(지문·논문·도서명 포함) ④ 탐구 과정 ⑤ 결과·결론 ⑥ 느낀 점과 진로 성찰 ⑦ 참고문헌. 학년대별 분량: 초등 = 그림+3문단 / 중등 = 5문단 / 고등 = 7블록 + 선행연구·논의·한계 추가 (학교 탐구보고서 표준 구조 그대로).
- **생기부 기대 관리 (중요, 리서치 확인)**: 앱의 보고서가 생기부에 그대로 실리는 것이 아니다. 생기부는 학교 교육활동만 기재하므로, 이 보고서는 **수행평가·수업 발표·창체 활동에 가져가 쓰는 '준비물'**로 포지셔닝한다. 도서명의 세특 기재는 "단순 독후활동 외의 교육활동"일 때만 가능한데, 이 앱의 "읽기 → 탐구 → 보고서" 체인이 정확히 그 요건에 맞는 재료를 만들어 준다. 학생·학부모 안내 문구에 이 한계와 활용법을 명시한다.
- 고등은 완성 후 **강사 피드백 요청** 버튼 → 세특 연계 코멘트 (§6 교사 도구).

### 4.7 리포트 (주간·학기)
- **학생**: 연속 읽기 일수(하루 1지문 스트릭), 완독 수, 분야 지도(과학·사회·역사 분포), 어휘장·한자 어근 수, 연계도서 이력, 레벨 변화.
- **학부모**: 주간 요약 (읽은 글 제목·분야, 자기평가 분포, 요약 훈련·보고서 진행 상황) — 알림 발송은 기존 WB 알림 체계(승인 게이트) 경유.
- **강사**: 반별 현황판 — 오늘의 1지문 미수행자, 정답률 급락자, 붉은 책 요약 확인 대기, 레벨 조정 대기, 보고서 피드백 대기.

## 5. 콘텐츠 파이프라인 — "최신 비문학"을 만드는 법

이 서비스의 성패는 **콘텐츠 수급의 지속가능성**에 달려 있다. 3층 구조로 설계한다.

### 5.1 소스층 (저작권 안전 확보)
| 소스 | 성격 | 라이선스 (리서치 확인) |
|------|------|---------|
| **공공저작물 — 공공누리 제1유형** | 정책브리핑(korea.kr), 국립중앙과학관, 국립국어원 등 | **기본 축.** 4개 유형 중 상업적 이용+변형(리라이팅)까지 허용되는 것은 제1유형뿐. 출처 표시 필수. 사진은 제3자 저작권이라 텍스트만 사용 |
| 언론 기사 | 시사·과학·기술 최신 이슈 | **원문 게재·리라이팅 모두 라이선스 필요** (사설 서비스는 저작권법 제25조 학교교육 예외 미적용, 뉴스토어 단건도 개작 금지·1년 단위 허락). 따라서 기사 속 '사실'만 참조해 지문을 새로 쓰고, 원문은 링크로 제공. 대량 활용 시 언론재단 뉴스저작권팀과 별도 협의 |
| **공개 논문 (오픈액세스)** | 국내 KCI·RISS·KOAR / 국외 arXiv·PubMed Central·DOAJ | 공개 원문 **링크 연계** + 초록 눈높이 해설 (§4.4). 지문 소재로도 활용 |
| 전문 매체 제휴 | 어린이·청소년 과학/시사 매체 | v2 협의. **1순위 동아사이언스**(과학동아·어린이과학동아 — 부커스·AI 학습데이터 등 B2B 라이선싱 전례 활발), 어린이 신문 NIE 계열(어린이조선·어린이동아도 교육기업 제휴 전례 확인) |
| 자체 제작 | WB 강사진 집필 지문 (기존 교재 자산) | 자체 보유 |

**AI 생성 원칙 (리서치 확인)**: 국내 사례(부산교육청 BeAT의 폐쇄형 RAG, 레서의 생성+전문가 검수)가 수렴하는 표준은 **"신뢰 원천 기반 생성 → 자동 검증 → 전문가 검수"**다. AI 자동검증을 통과한 교육 자료에서도 1% 오류가 발견된 사례가 있어(의학교육 자료 검증 연구) **강사 검수 게이트는 생략 불가**. 업계 경쟁 축도 '생성'에서 '검증'으로 이동 중 — 검수 체계를 갖춘 학원이 유리한 지형이다.

**분야 편성 원칙**: 소재 큐는 **과학·기술 / 사회·경제 / 역사·문화 / 인문·예술 / 환경** 5개 분야를 모두 커버하도록 주간 편성한다. 역사·사회 분야는 최신 이슈(전시·발굴·기념일·제도 변화)와 상설 교양(사건·인물 재조명)을 섞어 "최신성"을 유지한다.

### 5.2 가공층 (AI 재작성 + 레벨링)
그림검사 웹의 S0→S3 파이프라인 패턴을 재사용한 **지문 생산 라인**:

```
P0 소재 수집   → 공공자료·이슈 키워드·공개 논문에서 소재 후보 큐 적재 (매일 새벽 배치 — "최신 지문 자동 업데이트"의 심장)
P1 사실 추출   → Claude가 소재에서 사실·수치·인용을 구조화 추출 (tool-use 강제)
P2 지문 생성   → 레벨별 재작성: 같은 소재로 L1(초등 저)~L5(고등) 지문 병렬 생성
                 - 레벨 규격: 글자 수·문단 수·문장 길이·한자어 비율·개념 밀도 정의
                 - 부속 데이터 동시 생성: ① 의미 단위 분절 정보(끊어 읽기용)
                   ② 어휘 주석(쉬운 풀이·한자어 분해) ③ 영어 대역(중·고등 레벨만)
P3 검증 게이트 → ① 자동: 원 소재 대조 사실성 점검, 금지 소재 필터(정치 쟁점·선정성·광고), 영어 대역 역번역 대조
                 ② 수동: WB 강사 검수 후 발행 (초기 전수 → 신뢰 쌓이면 표본 검수)
P4 문항 생성   → 발행 지문에서 유형 고정 문항 자동 생성 → 강사 검수 → 활성화
P5 연계 콘텐츠 → 지문별 원 자료 링크·공개 논문 매칭(국내외)·연계도서 매칭 → 강사 확인 후 노출
```

- 발행 목표: **일 4~6지문 × 레벨 5 = 주 140~210개 지문 변형**. 초기(MVP)는 주 10소재 수동 큐레이션으로 시작.
- **신선도 규칙**: 오늘의 1지문은 원칙적으로 발행 30일 이내 소재. 시의성 없는 교양(역사 재조명 등)은 예외 풀로 운영.
- 모든 지문에 태그: 분야(진로 계열 매핑 + 과학/사회/역사 대분류), 레벨, 소재 출처, 발행일, 검수자.

### 5.3 레벨 체계
- 학원 기존 **레벨 5단계**와 1:1 매핑 (L1 초3~4 / L2 초5~6 / L3 중등 / L4 고등 기본 / L5 고등 심화).
- 지문 난도는 자체 규격표(글자 수·문장당 어절·저빈도 어휘 비율)로 관리. 어휘 난도 판정에는 **국립국어원 등급화 어휘(41,823개, 0~10등급 — 공공 데이터)**를 기반으로 쓴다.
- 정밀화 옵션 (리서치 확인): ① **낱말 LQ 지수 API** — 즉시 계약 가능한 상용 한국어 가독성 API. ② **KReaD 지수**(대교, 0~2000점 '한국판 렉사일') — 상용 API 공개 정보가 없어 제휴 협의 필요. 렉사일 자체는 영어 전용으로 한국어판이 없다. → MVP는 자체 규격표로 시작, v1에서 낱말 LQ 도입 검토 (§14).

## 6. 진로 매핑 체계

- **분류 축 (리서치 확인)**: 커리어넷의 **직업 10분류군 + 대학 학과 7계열**(인문/사회/교육/자연/공학/의약/예체능)을 기준 축으로 삼아 내부 계열 16개 카드로 재구성 → 지문 태그와 학생 관심사를 같은 축으로 매칭. 초등은 **주니어 커리어넷**의 아동용 직업정보를 별도 트랙으로.
- **데이터 수급 (리서치 확인)**: 커리어넷 직업정보·학과정보·진로심리검사·워크넷 직업사전 모두 **공공데이터포털 오픈API로 무료 개방, KOGL 제1유형**(출처 표시만으로 상업적 이용·변형 가능) — 법적 마찰 없이 연동 가능.
- **학년별 해상도**: 초등 = 흥미 12카드 → 계열로 느슨히 매핑 / 중등 = 계열 / 고등 = 계열 + 세부 학과·직업 검색.
- **교육 설계 정합 (리서치 확인)**: 학년대 3단계(탐험→탐색→설계)는 국가 진로교육 성취기준 4대 영역(자기이해 → 일과 직업세계 이해 → 진로탐색 → 진로디자인과 준비)과 맞물린다. 진로 변경은 자유 — 탐색 자체가 목적이며 변경 이력도 포트폴리오다.
- **진로 콘텐츠 확장 (v2)**: 지문 하단 "이 글과 연결된 직업·학과" 카드 (커리어넷 API 연동), 커리어넷 진로심리검사 결과 가져오기(관심사 초기값으로).

## 9. 기술 설계

### 9.1 아키텍처 — 기존 wb-site 패턴 준수
- **프론트**: 정적 HTML + 바닐라 JS 단일 파일 앱 (기존 `/student` 포털과 동일 패턴). 신규 경로 `/reading`.
- **백엔드**: Node 22 무의존성 서버 패턴 재사용 (`backend/` 구조 미러링). 인메모리 스토어 → PostgreSQL 전환 지점 동일.
- **AI**: `claudeClient.mjs` 패턴 재사용 — 키 없으면 mock, 있으면 실호출. 지문 생성(P2)은 `claude-opus-5`, 사실 추출·문항 생성은 `claude-sonnet-5`로 단계별 모델 지정.
- **파이프라인 상태머신**: 지문 상태 전이(`draft → generated → verifying → reviewing → published → retired`)를 그림검사 웹 `stateMachine.mjs` 패턴으로.

### 9.2 안전·품질 가드레일
- 지문 금지 소재 필터: 정치적 쟁점 편향, 선정성, 특정 상품 광고성, 미확정 의학 정보.
- 사실성: P1 추출 사실만 지문에 사용 (생성 단계에서 새 사실 추가 금지 — 프롬프트 + 자동 대조 검증).
- 탐구보고서 AI 응답: "문장 대신 써주기" 요청 거부 프롬프트, 학생 텍스트 필수 게이트.
- 개인정보: 학생 실명·연락처는 기존 원생 체계에만, 앱 내부는 학생 코드 참조 (기존 개인정보 게이트 준수).

### 9.3 브라우저 제약 (원내 배포 전제)
- 원내 학생 학습존 태블릿(Advanced2)은 **Chrome 138 영구 동결** → 신규 앱은 Chrome 138 호환 범위의 웹 표준만 사용, 번들 의존성 최소화. (기존 태블릿 기획서 v3의 Tier S 사이트 목록에 본 앱 추가.)

### 9.4 배포
- 정적 프론트는 기존 wb-site 배포 흐름, 백엔드는 기존 backend 배포와 동일 (Dockerfile 패턴).

### 13.3 포지셔닝 시사점

- **최근접 경쟁자**: 레서 (AI 진단·비문학·전국 검사까지 갖춤) — 그러나 진로 축·탐구보고서 산출물이 없다. 반대편의 학종Q·세특연구소는 진로·보고서는 있으나 읽기 훈련이 없다. **입력(읽기)과 출력(보고서)을 잇는 것이 본 기획의 유일 포지션.**
- **가격 벤치마크**: 외부 공개 시 B2C 월 3~8만 원(리딩게이트~매일국어 구간), 학원 B2B 1인 월 1만 원대(리딩게이트 모델)가 시장 수용 범위.
- **차별화 자산**: ① 진로 계열 태그 기반 최신 지문 (시장 공백) ② 강사 검수 게이트 (업계 경쟁 축이 '생성→검증'으로 이동 — 검수 조직을 가진 학원이 유리) ③ 세특 요건("단순 독후활동 외 교육활동")에 정합하는 산출물 체인 ④ 원내 태블릿 학습존과의 즉시 결합.

## 14. 열어 둔 결정

1. 서비스명 확정 (후보: 리딩커리어 / 진로독서랩 / WB 리딩패스).
2. 외부 공개 시점과 과금 모델 (v2 시점 재논의).
3. 이독성 지수 3택 — 자체 규격표(국립국어원 등급 어휘 기반) 유지 / 낱말 LQ API 계약(즉시 가능) / KReaD 제휴(대교 협의 필요). MVP는 자체 규격표, v1 전 재결정.
4. 전문 매체 제휴 우선순위 — 1순위 동아사이언스(B2B 전례 다수), 2순위 어린이 신문 NIE 계열. v2 착수 전 협의 시작 시점 결정.
5. 스터디포스 이용 계약 범위 확인 — 붉은 책 단원 체크리스트 등록·요약 연동이 계약상 허용되는지.
6. 영어 대역 노출 범위 (중등부터 vs 고등만, 초등 제외 확정 여부).
7. 연계도서 데이터 소스 선정 (WB 자체 목록 우선, 공공 도서관 빅데이터 API 후보 비교).
