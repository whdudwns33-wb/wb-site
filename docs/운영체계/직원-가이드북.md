# WB 직원 가이드북 — 우리 시스템, 어디에 뭘 기록하나요?

- 버전: v1.2 (2026-08-15) · 대상: WB 전 직원
- 궁금한 게 생기면 이 문서 → 그래도 애매하면 관리자(김혜지 선생님) → 원장님 순서로 물어보세요.

---

## 우리가 쓰는 시스템은 딱 2개입니다

| | **업무지시서 앱** | **아카플로우** |
|---|---|---|
| 무엇 | 매일 쓰는 내 업무 화면 | 학원 원무 프로그램 |
| 어디서 | 휴대폰·PC, 내 개인 링크 | 원내 PC |
| 언제 | 매일, 수업 중에도 | 학생 등록·퇴원 등 변동이 있을 때만 |
| 담긴 것 | 내 할 일, 수업 지시서, 학생 이름 | 학생 전체 정보 (연락처 등) |

**구분법 한 줄**: 학생이 *누구인지*가 바뀌면(신규·퇴원·반 변경) → 아카플로우. 학생에게 *무엇을 했는지* 남기려면(수업·체크·연락) → 업무지시서 앱.

> mini(원내 관제 화면)는 시간표·충돌 확인용 조회 화면입니다. 기록은 하지 않습니다.

---

## 업무지시서 앱 — 하루 사용법

접속: 받은 **개인 링크**로 들어갑니다. 링크가 곧 내 계정입니다 — **다른 사람에게 전달 금지**, 잃어버리면 원장님께 재발급 요청.

### 출근하면
1. 오늘 화면 맨 위 **[출근했습니다]** 버튼 (퇴근할 때 [퇴근했습니다])
2. 오늘 업무 목록 확인 — 시간순으로 정렬되어 있습니다

### 수업할 때 (수업 지시서가 있는 학생)
1. `[수업] 학생명` 카드 열기 → **진도·지도법·목표** 확인하고 수업
2. 수업 중/직후에 카드에서:
   - **학생 출결** — 출석/지각/결석 하나 탭
   - **단계 체크** — 진도 확인·수업·숙제 안내
   - **메모** — `+잘한점 / -보완점 / 숙제○○` 형식으로 쓰면 피드백 문구에 자동 배치됩니다
3. **[💬 학부모 피드백 문구]** — 보기 3개만 고르면 문구가 자동으로 만들어집니다. 확인·수정 후 복사해서 학부모 카톡으로 보내세요.

### 학부모와 연락했을 때 (전화·카톡·대면 무엇이든)
- 학생 이름 옆 **[📞 기록]** 버튼 → 유형 하나만 탭 (10초). 메모는 선택.
- **오늘 화면의 "이번 달 학부모 연락" 카드**에 아직 연락 못 한 학생이 떠 있습니다. 매달 담당 학생 전원 1회 이상이 기본입니다.
- ⚠️ 메모에 상담 상세 내용·가정사·전화번호는 적지 않습니다. 짧은 용건만.

### 막혔을 때
- 해당 업무에서 **[🚧 막혔어요]** + 이유 메모 → 원장님·관리자에게 자동 알림이 갑니다. 혼자 안고 있지 마세요.

### 원생 탭 (📈)
- **내 학생**: 담당 학생 명단, 마지막 연락일, 월별 변동
- **⚠️ 관심 필요**: 결석·지각이 쌓이거나 연락이 끊긴 학생이 자동으로 올라옵니다. **여기 뜬 학생이 이번 주 최우선입니다** — 결석이 이어질 때 그날 연락하는 것이 가장 효과가 큽니다.
- 유지율 숫자는 경향입니다. 퇴원은 반드시 사유와 함께 봅니다.

### 교재 탭 (📚)
- 교재 목차·학생별 진도 위치 확인
- 재고 부족 시 **[🛒 주문]** → 담당자 할 일로 자동 등록되고, 담당자는 [📱 발주 문자]로 원터치 발주

## 아카플로우 — 언제 쓰나

이런 일이 생기면 아카플로우에 입력합니다 (입력 담당이 아니면 담당자·관리자에게 전달):

- 신규생 등록 / 퇴원 / 휴원
- 반 배정·시간 변경
- 학생 연락처 등 인적 사항 변경

**앱의 학생 명단은 아카플로우 자료를 주간 다리로 확인한 뒤 관리자가 승인해 반영합니다.** 앱 명단이 실제와 다르면 “앱을 고쳐달라”가 아니라 “아카플로우가 맞는지”부터 확인하세요 — 아카플로우가 정본입니다. 퇴원은 사유 확인 후 앱에 반영합니다.

---

## 절대 규칙 3가지

1. **앱의 공개 화면에는 학생 이름과 필요한 수업 내용만.** 전화번호는 관리자가 아카플로우 명부에서 가져와 인증된 비공개 연락처에만 저장하고, 동의된 목적과 담당 범위에서만 사용합니다. 주소·학교·성적·검사결과·가정사는 업무 메모에 쓰지 않습니다.
2. **같은 일을 두 군데 적지 않습니다.** 등하원은 등하원 프로그램, 수업 출결·기록은 앱, 학생 정보는 아카플로우.
3. **개인 링크는 개인 것.** 공유 금지, 단톡방 게시 금지.

## 자주 묻는 질문

**Q. 체크를 깜빡했어요.** — 날짜를 이동해 지난 날짜에도 체크할 수 있습니다. 늦게라도 남기는 게 안 남기는 것보다 낫습니다.

**Q. 학생이 안 왔는데 수업 지시서는 어떡하나요?** — 출결에서 [결석] 탭하고 넘어가면 됩니다. 결석이 반복되면 관심 필요에 자동으로 올라오니 그때 연락을 남겨주세요.

**Q. 지시서 내용(진도·시간)이 실제와 달라요.** — 본인이 추가한 업무는 직접 수정, 원장 발행 지시는 막힘 메모나 관리자에게 알려주세요. 다음 주 지시서에 반영됩니다.

**Q. 토/일 변동 등원 학생(예: 학생A·학생B)은요?** — 지시서가 토·일 양쪽에 뜹니다. 실제 온 날에만 체크하고, 안 온 날은 비워두면 됩니다 (불이익 없음).

**Q. 피드백 문구가 어색해요.** — 만들어진 문구는 초안입니다. 자유롭게 고쳐 보내세요. 다만 점수 비교·진단성 표현은 넣지 않습니다.

**Q. 관리자(김혜지 선생님)는 뭐가 다른가요?** — 전체 현황 보기·지시서 발행·연락 현황 전체 열람이 가능합니다. 직원 관리·설정·삭제는 원장님 전용입니다.
