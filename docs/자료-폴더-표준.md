# 학습 자료 폴더 표준 (구글 드라이브)

원장이 구매 자료 PDF를 올리는 자리와 이름 규칙. **앱이 여러 개이고 앞으로 더 늘어나므로,
한 드라이브 폴더 안에서 앱별로 이름이 갈리게 둔다.**

이 문서는 사람이 지키는 규칙이고, 추출 도구가 그 규칙을 읽는다
(국어: `naesin-ko/extract/build-pack.mjs`, 초기 배치 계획 정본: `/Users/wb/wb-packs/tools/plan_ms.py`).
규칙을 어기면 도구가 **멈추고 이유를 말한다** — 조용히 잘못 넣지 않는다(단, 같은 단원 폴더에 든
미지원 상품 PDF는 경고로 건너뛴다).

---

## 1. 전체 모양

```
WB 학습자료/                                   ← 드라이브에서 공유 폴더 하나만 만든다
├── naesin-ko/                                 ← 국어브레인   (저장소 디렉터리 이름과 같다)
│   └── 2026-2/                                ← 시험기 서랍 (사람용. 도구는 안 읽는다)
│       ├── 중등 내신/                         ← 과정 서랍 (지금은 중등 내신만 제작)
│       │   └── 중2 천재(노미숙) 1학기/        ← <학년 출판사(저자) N학기> 서랍
│       │       ├── 2022-cheonjae-nomisuk-m2-1-U1/  ← 폴더 이름 = 팩 id  ★여기가 규칙의 핵심
│       │       │   ├── _meta.txt                   (중1·중2는 revision: 2022, 중3은 revision: 2015)
│       │       │   ├── 이해완성-01-저녁항구.pdf
│       │       │   ├── 요약노트.pdf
│       │       │   ├── 단원집중-1회.pdf
│       │       │   └── 서술형공략.pdf              (단원의 모든 상품을 한 폴더에 넣는다)
│       │       ├── 2022-cheonjae-nomisuk-m2-1-U2/
│       │       └── 시험 대비 모의고사/        ← 단원을 걸친 [Final모의고사] 보관
│       ├── 고등 내신/                         ← (나중에 따로)
│       └── 모의고사/                          ← (나중에 따로)
├── naesin/                                    ← 내신브레인(영어)
│   └── 2026-2/
│       └── 2022-ne-kimgitaek-m2-L6/
│           ├── _meta.txt
│           └── ... .pdf
├── reading/                                   ← 진로독서 (자료가 생기면)
├── vocab/                                     ← 워드브레인 (자료가 생기면)
└── hanja/                                     ← 어휘브레인 — 문제집 단어장(폴더 이름 = 단어장 id)
    └── eohwi-dokhae-1/                        ← 예: 어휘 교재 1권. words.txt(붙여넣기 형식) 또는 book.json
        └── words.txt
```

**앱 폴더 이름은 저장소 디렉터리 이름과 같게 둔다.** `naesin-ko`·`naesin`·`reading`·`vocab`·`hanja`.
한글 이름(‘국어브레인’)을 쓰면 사람은 편하지만 도구·경로·문서가 저장소와 어긋나기 시작한다.
헷갈리면 드라이브에서 폴더 설명란에 한글 이름을 적어 둔다.

**국어(`naesin-ko/`)는 `중등 내신` / `고등 내신` / `모의고사`로 나누고, 지금은 `중등 내신`만 만든다**
(고등 내신 · 모의고사는 나중에 따로).
`중등 내신/` 아래에는 `<학년 출판사(저자) N학기>/`(예: `중2 천재(노미숙) 1학기/`) 서랍을 두고,
그 안에 단원별 `<팩 id 폴더>/`(예: `2022-cheonjae-nomisuk-m2-1-U1/`)와 단원을 걸친 시험 대비용
`시험 대비 모의고사/` 폴더(`Final모의고사` 보관)를 함께 둔다.

**시험기 서랍(`2026-2`)과 과정·교과서 서랍(`중등 내신/중2 천재(노미숙) 1학기`)은 사람 편의다.**
추출 도구는 팩 id 폴더만 본다 — 서랍을 몇 겹으로 만들든 상관없다.
다만 같은 팩 id 폴더가 두 군데 있으면 안 된다.

## 2. 팩 id — 폴더 이름이 곧 팩 id다

폴더 이름을 그대로 팩 id로 쓴다. 그래서 이름 규칙 = 팩 id 규칙이다.

| | 형식 | 예 |
|---|---|---|
| 국어 | `<개정>-<출판사저자>-<학년>-<학기>-U<대단원>` | `2022-cheonjae-nomisuk-m2-1-U1` |
| 영어 | `<개정>-<출판사저자>-<학년>-L<과>` | `2022-ne-kimgitaek-m2-L6` |

- **영문·숫자·하이픈만.** 3~60자. 한글·공백·밑줄·괄호를 쓰면 서버가 거부한다
  (`^[A-Za-z0-9-]{3,60}$`). **이 제한은 팩 id 폴더 이름에만 걸린다** — 위쪽 공유 폴더
  (`WB 학습자료`)와 시험기·과정·교과서 서랍, `시험 대비 모의고사/`, 그리고 폴더 안 PDF 파일명은 한글·공백을 써도 된다.
- **국어 개정 연도 규칙(2026년 시행 기준)**: **중1·중2 = `2022`, 중3 = `2015`**.
  팩 id 접두사와 각 팩 id 폴더 안 `_meta.txt`의 `revision:` 값 모두 이 기준을 따른다.
- **영어의 과(`L…`) 자리는 숫자만이 아니다.** 교과서에 Special Lesson·Special Reading 이
  있고 그것도 시험 범위에 들어간다. 토큰은 넷뿐이다(`desk/lib/ledger-core.js` 의 `UNIT_RE`):

  | 자료 목록 표기 | 토큰 | 예 |
  |---|---|---|
  | Lesson 6 | `L6` | `2022-ne-kimgitaek-m2-L6` |
  | Special Lesson | `SL` | `2022-ne-kimgitaek-m2-SL` |
  | Special Lesson 2 | `SL2` | `2022-ne-kimgitaek-m2-SL2` |
  | Special Reading 1 | `SR1` | `2022-ne-kimgitaek-m1-SR1` |

  `L` 뒤 번호는 **0 을 채우지 않는다**(`L6`, `L12`). 목록 이름을 그대로 적지 않는다 —
  공백이 들어가 팩 id 가 깨진다.
- `m2` = 중2, `h1` = 고1. 학기는 국어만 붙인다(국어는 학기별로 교과서가 갈린다).
- 출판사 로마자 표기는 아래 표를 따른다. 새 출판사가 오면 이 표에 **먼저 추가**하고 쓴다 —
  같은 출판사를 두 가지로 적으면 팩이 갈라져 시험 범위 배정이 어긋난다.

*국어(`naesin-ko/`)* — 현행 중등 내신 11종 + 기존 표기(배치 정본: `/Users/wb/wb-packs/tools/plan_ms.py`. 파일명의 오타 별칭 `해냄(걍양희)`·`해냄(강영희)`는 `해냄(강양희)`로 정규화한다)

## 3. PDF 파일 이름과 단원 폴더 구성 — 추출 도구는 파일 이름을 **안 본다**

**같은 단원 폴더에 모든 상품을 넣는다.** 다운받은 중등 파일(6,892개)은 상품 종류와 관계없이
해당 단원(팩 id) 폴더에 **모두** 넣는다(단원을 걸친 `[Final모의고사]`만 같은 교과서·학기 서랍 아래
`시험 대비 모의고사/` 폴더에 둔다). 추출 도구가 아직 모르는 상품이 섞여 있어도 폴더를 나누지 않는다 —
**도구가 모르는 상품은 경고로 건너뛴다.**

추출 도구가 읽는 상품:
- 기본: `이해완성` · `직전 요약노트` · `단원집중` · `서술형 공략`
- 확장(추가 중): `최다빈출` · `최다오답` · `최상위` · `꼭 나오는 문제` · `수준별_기본` · `중3 개념완성 step1`, `실력완성` · `대표유형` · `풀이완성` · `개념완성 step2`
- **중3에는 `이해완성`이 없고 `개념완성 step1`이 정본이다.**

**추출 도구(`build-pack.mjs`)는 파일 이름으로 시리즈를 판별하지 않는다.** 드라이브에서 내려받으면 한글 파일명이 깨지기 때문이다
(실제로 깨졌다: `_____11.1_____________2___.pdf`). 추출 도구는 **지면 내용**(머리말 태그·마커 등)으로 상품을 판별한다.

다만 **초기 정리·배치 단계(`/Users/wb/wb-packs/tools/plan_ms.py`)는 파일 이름을 쓴다** — 다운받은 원본 PDF 파일 이름과 상위 경로에서
학년·출판사(저자)·학기·대단원(`U1` 등)과 `[Final모의고사]` 여부를 읽어 어느 단원 폴더로 보낼지 계획(`ms-plan.tsv`)을 만든다
(오타 별칭 `해냄(걍양희)`·`해냄(강영희)` → `해냄(강양희)`).

사람이 직접 정리할 때 알아보기 쉽게 적는 예시(추출 도구는 파일명을 무시한다):

```
이해완성-01-저녁항구.pdf     요약노트.pdf     단원집중-1회.pdf     서술형공략.pdf
```

- 같은 시리즈가 여러 개면 뒤에 번호를 붙인다(이해완성은 작품마다 한 파일이다).
- **학생용과 선생님용이 한 파일에 든 원본**을 받아 그대로 올린다. 나누지 마라 —
  이해완성은 두 지면을 대조해 정본을 검증한다.
- 표지·안내 쪽을 빼지 마라. 마스트헤드가 작품 경계를 알리는 신호다.

## 4. `_meta.txt` — 자료에 **인쇄되지 않은 것만** 적는다

추출 도구는 파일 이름을 보지 않고 지면에서 출판사·학년·학기·단원·작품명·작가를 읽어 서로 채운다
(초기 폴더 배치 단계인 `plan_ms.py`만 파일 이름을 읽어 폴더를 나눈다).
**딱 하나, 개정 연도만 지면 어디에도 없다.**

따라서 팩 id 폴더마다 메모장으로 만든 `_meta.txt` 파일을 두고 `키: 값` 한 줄씩 적는다.
2026년 시행 기준 **중1·중2는 `2022`, 중3은 `2015`** 다:

```
revision: 2022
```

(중3 단원 폴더는 `revision: 2015`)

필요할 때만 덧붙인다(도구가 못 읽었다고 알려 줄 때):

```
revision: 2022
publisher: 천재(노미숙)
grade: 중2
semester: 1
unit: 1. 문학을 펼치면
note: 3단원은 프린트로만 나가므로 올리지 않음
```

작가명(`함기석` 등)은 단원집중·서술형 공략 지면에 인쇄돼 있어 자동으로 붙는다.
그 두 자료가 없는 단원에서만 도구가 물어본다.

## 5. 올린 다음 — 내려받아 돌린다

드라이브에 있는 파일을 그대로 처리하지 않는다. **로컬로 내려받아 오프라인 도구로 돌린다** —
구매 자료를 외부 서비스·외부 AI API로 보내지 않는 것이 원칙이다(국어 기획서 §1.5).

방법 두 가지:
- **드라이브 데스크톱**(권장): 공유 폴더를 내 PC에 동기화해 두면 경로가 늘 같다.
- **폴더 내려받기**: 드라이브에서 팩 id 폴더를 통째로 다운로드(zip) 후 풀기.

그다음 국어는 한 줄이다:

```bash
node naesin-ko/extract/build-pack.mjs "~/WB 학습자료/naesin-ko/2026-2/중등 내신/중2 천재(노미숙) 1학기/2022-cheonjae-nomisuk-m2-1-U1"
```

도구가 하는 일: 폴더 이름을 팩 id로 검증 → PDF마다 시리즈를 내용으로 판별(모르는 상품은 경고로 건너뜀) →
맞는 추출기로 돌림 → 메타를 교차 보강 → 작품 단위로 병합 → `pack/` 과 `review/` 를 만든다.
자세한 절차와 검수 항목은 `naesin-ko/extract/README.md`가 정본이다.

영어(`naesin/`)는 드라이브가 아니라 원내 PC 자료실로 모은다. 받기·모으기 규칙은 아래 §7이다.

## 6. 하지 말 것

- **저장소에 PDF·추출 결과·팩 JSON을 커밋하지 않는다.** 저장소는 public이다
  (CLAUDE.md 절대 규칙 1). 자료는 드라이브와 작업 PC, 팩은 서버(KV)에만 산다.
- **드라이브 폴더를 링크로 외부 공유하지 않는다.** 원내 계정만 접근 권한을 준다.
  이용 조건이 ‘학원 내부 무료 사용’이다(국어 기획서 §10-1).
- 팩 id 폴더 안에 하위 폴더를 만들지 않는다(도구가 한 겹만 본다).
- 같은 단원 자료를 두 팩 id에 나눠 넣지 않는다 — 시험 범위 배정이 갈라진다.
- 이용권이 끝나면 드라이브 자료와 서버 팩을 함께 지운다(기획서 §13-1 1-c).

## 7. 영어(내신브레인) — 이그잼포유 자료 받기·모으기 (2026-11-12)

국어와 원칙은 같다. 폴더 이름이 곧 팩 id이고, 도구는 **지면 내용과 파일 앞 번호**로 판별한다. 구매 원문은 로컬 도구로만 처리하고 외부 AI·Git·정적 배포로 보내지 않는다. 다른 점은 보관 자리다. 영어는 드라이브가 아니라 **원내 PC 자료실**에 모으고, 목록 `index.json`이 정본이다.

### 7.1 받는 곳·계정

- 원천: 이그잼포유 정회원 자료(2026-12-03 만료 확인). 정회원은 결제 없이 받는다. **결제·이용권 변경이 필요한 자료는 받지 말고 원장에게 묻는다.** 연간 다운로드 한도(5,000건 안내)가 있으니 목록 대조로 빠진 것만 받는다.
- 브라우저: Aside 브라우저. 로그인은 **Aside Vault 자동 입력**으로만 한다. 비밀번호를 사람이 채팅에 쓰거나 에이전트가 타이핑하지 않는다. 2단계 인증·약관 화면이 나오면 멈춘다.
- 범위: 중1·중2는 2022 개정 10종, 중3은 2015 개정 12종(2022 개정 중3은 아직 받을 링크가 없다). 고등·수능은 넣지 않는다.

### 7.2 단원마다 받을 것

| 학년 | 필수(없으면 팩이 빈다) | 함께 받는 것 |
|---|---|---|
| 중1·중2 | `[02]`본문10단계 워크북 통합본 · `[03]`WORD TEST | 교과서 본문 · `[01]`내용정리 플러스 · `[04]`PRE-STEP · `[05]`1회 · `[06]`2회(**각각 교사용도**) · `[07]`~`[09]` Grammar Build Up · 워크북 1~10 |
| 중3 | `본문7단계 워크북 Part 2 해석연습`(문장 정본) · `[04]`WORD TEST | `[01]`~`[15]` 전부 · 워크북 Part 0~7 · 내신기출 FINAL |

- 교사용은 학생용보다 늦게 올라오기도 한다(예: 천재(소영순) 중2 8과는 11-12 기준 교사용 미게시). 받은 목록에 「교사용 대기」로 남기고 다음 대조 때 다시 본다. 학생용 뒤에 정답·해설이 있으면 그것으로 먼저 채운다.
- 특별 단원(SL·SR)은 출판사가 워크북·본문만 내는 경우가 많다. 사이트에 없는 자료를 빠짐으로 세지 않는다.

### 7.3 언제 대조하나

- **주 1회**와 시험 범위를 정하기 전에, 사이트 목록(단원·자료 이름·업로드일)과 `index.json`을 맞춘다. 사이트 「최근 등록」 목록을 **직전 대조일부터** 빠짐없이 넘겨 본다(11-12에 특정 단원만 보다가 11-03~11-10 등록분을 놓쳤다). 없는 자료와 업로드일이 바뀐 자료(수정본 후보)만 받는다.
- 수정본은 해시를 비교한다. 같으면 받은 기록만 남기고, 다르면 7.4대로 새 판본으로 넣는다.

### 7.4 모으는 순서

1. Aside로 받는다 → `~/Downloads/`(원래 파일명 그대로).
2. 원내 수신 폴더 `naesin-materials/incoming-<YYYYMMDD>/`로 옮긴다(권한 700). PDF 머리말(`%PDF-`)·쪽수·크기를 확인한다. HWP를 고를 수 있으면 PDF로 받는다.
3. 자료실 `naesin-materials/library/<팩 단원 id>/`에 넣는다.
   - 중1·중2 정본 이름: `00_교과서본문` · `01_내용정리` · `02_본문워크북` · `03_단어시험` · `04_예상문제_PRE-STEP`(`_교사용`) · `05_예상문제_1회`(`_교사용`) · `06_예상문제_2회`(`_교사용`) · `07_문법워크북` · `08_문법객관식` · `09_문법주관식` + `.pdf`. 워크북 1~10은 `_raw/`에 원래 파일명으로 둔다.
   - 중3은 `_raw/`에 원래 파일명 그대로 둔다. 도구가 이름 속 `[NN]` 번호와 `Part N`으로 판별한다.
   - 이미 있는 파일은 덮어쓰지 않는다. 수정본은 새 파일로 넣고, 이전 판본은 `index.json`의 `history`에 남긴다. 기존 검수가 그 해시를 가리킨다.
4. `index.json`에 한 줄씩 더한다. 들어가는 값은 `id`(`src-` 6자리 연번), `packId`, `curriculum`, `textbook`(사이트 표기 그대로), `grade`, `unit`, `title`, `file`, `sha256`, `bytes`, `pageCount`이다. 바꾸기 전에 `index.json` 사본을 남긴다.
5. 낱말·본문·문항을 로컬 도구로 다시 뽑는다(poppler만 사용, 도구 사본은 `naesin-materials/fill-20261112/tools/`). 그다음 `pack-check` 오류 0을 확인하고 단원별 전후 숫자를 남긴다. 정답이 확정되지 않은 문항은 넣지 않는다.
6. **반영은 원장 승인 뒤에만 한다.** 순서는 서비스 내림 → 운영 팩이 초안 기준 시각 뒤에 바뀌지 않았는지 확인 → `naesin-packs` 기록·이미지 복사 → 서비스 올림 → 검증이다. 반영 전 사본을 같은 작업 폴더에 둔다.

### 7.5 팩 단원 id — 자료실 폴더 이름이 정본

자료실 폴더 이름이 운영 팩 id(`<단원 id>-questions`)다. **README 교과서 코드표와 다른 철자가 이미 운영 중이다**(`visang-`·`donga-yoonjeongmi`·`miraen-moonyoungin`·`chunjae-soyoungsoon`). 고치면 학생 기록·배정이 끊기므로 기존 폴더 이름을 그대로 쓴다. 중1(NE능률 제외)과 중3은 출판사 번호 형식이다.

| 중1 `2022-m1-pNN-m1-` | 중3 `2015-m3-pNN-m3-` |
|---|---|
| (NE능률 김기택은 `2022-ne-kimgitaek-m1-`) | p01 NE능률(김성곤) · p02 NE능률(양현권) |
| p02 YBM(김은형) · p03 YBM(박준언) | p03 YBM(박준언) · p04 YBM(송미정) |
| p04 동아(윤정미) · p05 동아(이병민) | p05 금성(최인철) · p06 동아(윤정미) |
| p06 미래엔(문영인) · p07 비상(황종배) | p07 동아(이병민) · p08 미래엔(최연희) |
| p08 지학사(송미정) · p09 천재(소영순) | p09 비상(김진완) · p10 지학사(민찬규) |
| p10 천재(이상기) | p11 천재(이재영) · p12 천재(정사열) |

새 출판사가 생기면 같은 학년의 다음 번호를 쓰고 이 표에 더한다.

### 7.6 하지 말 것 (영어)

- 구매 PDF·추출 결과·팩을 저장소·Git·드라이브 공유 링크에 두지 않는다. 자료실은 원내 PC 비공개 폴더에만 둔다.
- 자료실 원본 파일을 고치거나 덮어쓰지 않는다. 이름을 바꿀 때도 `index.json`의 해시와 함께 바꾼다.
- 다운로드 중에 결제·이용권 화면이 나오면 진행하지 않는다.
- 사이트에 없는 자료를 임의로 만들어 채우지 않는다. 빠진 곳은 「미게시」로 남긴다.
