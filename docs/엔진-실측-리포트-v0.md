# 엔진 실측 리포트 v0 — 실제 그림 판독 기반

> AI 해석 엔진(S1 관찰 → S2 가설매핑 → S3 생성)을 **실제 렌더링된 두 그림**에 적용한 실측.
> 재현: `backend/test/measure.mjs` · 대상 이미지: `apps/picture-test/samples/{sample-a,variant-b}.svg`

---

## 방법 (정직한 고지)

- **실제 Claude API 키가 이 환경에 없어**, S1(관찰 추출)은 **Claude Opus(비전 능력)가 렌더링된 PNG를 직접 판독**해 수행했습니다. 즉 자동 파이프라인의 mock 관찰이 아니라 **사람=모델이 실제 이미지를 보고** 관찰을 뽑았습니다.
- S2(가설 매핑)·S3(생성)·가드레일은 **백엔드 실제 코드**(`mapHypotheses`, `generateText`, `guardrails`)를 그대로 사용.
- 핵심 검증 질문: *엔진이 canned mock이 아니라 "그림 내용"에 반응하는가?* → **다른 그림(변형본)**을 새로 만들어 대조.

## 핵심 발견

1. **엔진은 그림 내용에 반응한다 (증명됨).** 두 그림이 서로 다른 특징 → 서로 다른 가설. 특히 **같은 element에서 정반대 가설**이 나왔다:
   - `tree.root`: (강조)**안정감 추구** ↔ (없음)**기반 부족**
   - `person.face`: (미소)**긍정 강점** ↔ (처진 입)**부정 정서**
   → 이는 attribute 조건부 매핑(`derive`)이 실제로 작동한다는 강한 증거. canned mock이면 불가능.

2. **KB v0의 실제 갭을 발견하고 확장했다.** 최초 실측에서 Variant B는 가설이 **0개**였다 — KB v0가 Sample A의 5개 특징만 담고 있었기 때문. 실측을 통해 울타리·가는 줄기·뿌리 없음·앙상한 가지·처진 입 항목을 추가(모두 근거 약~중, 경고 부착). **실측이 KB 개선을 이끈** 사례.

3. **연령 보정·근거수준·가드레일이 실제로 동작.** 만 8세 손 생략은 자동 강등(mid→low)+문구, 투사검사 특성상 '강' 없음, 금지어 차단.

## 한계 (정식 검증 조건)

- 본 실측의 관찰은 **모델이 직접 판독**한 것 — 프로덕션의 자동 S1(Claude API Vision tool-use)과 **동일하지 않다.** 실제 API 키로 tool-use 경로를 실측해야 함.
- 그림은 **합성 SVG 2점**. 실제 아동 그림 다수(N)로 확대 필요.
- **정답 비교 부재**: 전문 심리사가 같은 그림을 채점한 결과와 **초안 채택률·오탐/미탐**을 비교해야 신뢰도 측정이 됨.
- KB 가설·근거수준은 여전히 **심리사 검수 전 초안**.
