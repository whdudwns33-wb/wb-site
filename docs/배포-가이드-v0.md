# 그림검사 AI 해석 웹 · 배포 가이드 v0

> 대상: WB 웩슬러브레인센터 운영자
> 원칙: **기존 홈페이지 서비스에 영향을 주지 않는다.** 새 서비스는 별도 경로·별도 서버로 올린다.

## 0. 한눈에 보는 현재 상태

| 구성 | 상태 | 주소 / 위치 |
|---|---|---|
| 기존 홈페이지 | 🟢 운영 중 (변경 없음) | GitHub Pages · 저장소 루트 `index.html` |
| 그림검사 프로토타입 (화면) | 🟢 **배포 완료** | `/apps/picture-test/` |
| 그림검사 백엔드 (AI 서버) | 🔴 미배포 | 별도 호스팅 필요 (아래 2단계) |

즉 지금 접속해도 화면 흐름 전체를 볼 수 있고, AI 호출·비용은 발생하지 않습니다.

## 1단계 · 프론트엔드 (이미 배포됨)

### 배포 방식
이 저장소는 **GitHub Pages(Deploy from a branch: `main` / root)** 로 이미 연결되어 있습니다.
`main`에 푸시·머지가 일어나면 `pages build and deployment` 워크플로가 자동 실행돼 사이트가 갱신됩니다.
→ **그림검사 프로토타입도 별도 작업 없이 함께 배포됩니다.**

### 주소 구조
```
<사이트 루트>/                       ← 기존 홈페이지
<사이트 루트>/apps/picture-test/     ← 그림검사 프로토타입
```
기본 Pages 주소는 `https://whdudwns33-wb.github.io/wb-site/` 입니다.
커스텀 도메인을 연결해 두었다면 그 도메인 뒤에 같은 경로를 붙이면 됩니다.

### 배포 확인 방법
1. GitHub 저장소 → **Actions** 탭 → `pages build and deployment` 의 최신 실행이 ✅ 인지 확인
2. `Settings → Pages` 상단에 표시된 실제 사이트 주소 확인
3. 그 주소 + `/apps/picture-test/` 로 접속 → 랜딩 화면이 뜨면 성공
4. 화면이 안 바뀌면 브라우저 강력 새로고침 (`Ctrl/Cmd + Shift + R`) — Pages는 CDN 캐시가 있어 최대 몇 분 지연될 수 있습니다.

### 의도적으로 하지 않은 것 (중요)
- **홈페이지에 링크를 걸지 않았습니다.** 학부모가 우연히 들어오면 데모를 실제 검사로 오인할 수 있습니다.
- 프로토타입 페이지에 `<meta name="robots" content="noindex">` 를 넣어 **검색 노출을 차단**했습니다.
- 공개 링크로 홍보하는 것은 **심리사 검수 완료 후**에 하십시오. (아래 4단계 체크리스트)

## 2단계 · 백엔드 (해야 할 일)

### 왜 GitHub Pages에 못 올리나
Pages는 **정적 파일만** 서비스합니다. 백엔드는 Node 서버 프로세스 + 데이터베이스 + 파일 저장소가
계속 떠 있어야 하므로 별도 호스팅이 필요합니다.

### 호스팅 선택 — 한국 리전이 기준
아동의 그림·생년·검사결과는 **민감한 개인정보**입니다. 설계서(`백엔드-설계-v0.md`)대로
**데이터 저장 위치를 한국 리전**으로 잡는 것을 전제로 후보를 비교합니다.

| 후보 | 한국 리전 | 난이도 | 월 비용(소규모) | 비고 |
|---|---|---|---|---|
| **Cloudtype** | ✅ 서울 | 낮음 (GitHub 연결→자동배포) | 무료~2만원대 | 국내 서비스·한국어 지원. **MVP 1순위 추천** |
| 네이버 클라우드 (NCP) | ✅ 한국 | 중 | 3~10만원대 | 국내 사업자·계약서/약관 정리에 유리 |
| AWS `ap-northeast-2`(서울) | ✅ 서울 | 높음 | 3~15만원대 | 확장성 최고, 초기 설정 부담 |
| Render / Railway / Fly.io | ❌ (일본·싱가포르) | 낮음 | 무료~1만원대 | 편하지만 **개인정보 국외 저장** 이슈 → 실서비스 부적합 |

> 결론: **테스트용 임시 배포는 아무 곳이나, 실제 아동 데이터가 들어가는 순간부터는 한국 리전 필수.**

### 배포 준비물 (이미 저장소에 포함)
- `backend/Dockerfile` — 컨테이너 이미지 정의 (Node 22, 비루트 실행, 헬스체크 포함)
- `backend/.dockerignore`
- `backend/.env.example` — 넣어야 할 환경변수 목록

### 환경변수
| 이름 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 실제 해석 시 필수 | 비워 두면 mock 모드(호출·비용 0) |
| `MODEL_S1` / `MODEL_S3` | 선택 | 기본 `claude-opus-5` |
| `PORT` | 선택 | 호스팅이 자동 주입하는 경우가 많음. 기본 8787 |
| `CORS_ORIGIN` | **운영 시 필수** | `*` 금지. 프론트 도메인만 (예: `https://whdudwns33-wb.github.io`) |

> ⚠️ API 키는 **환경변수(또는 호스팅의 Secret 기능)** 에만 넣습니다.
> 코드·커밋·채팅창·문서에 붙여넣지 마십시오. 한 번 노출된 키는 폐기 후 재발급이 원칙입니다.

### Cloudtype 기준 배포 절차
1. Cloudtype 가입 → GitHub 계정 연결 → `whdudwns33-wb/wb-site` 선택
2. 앱 추가 시 **루트 디렉터리를 `backend`** 로 지정 (빌드 방식: Dockerfile)
3. 리전 = **서울**
4. 환경변수에 `ANTHROPIC_API_KEY`, `CORS_ORIGIN` 입력
5. 배포 후 발급된 주소로 헬스체크:
   ```
   curl https://<발급주소>/api/health      # {"ok":true, ...} 가 나오면 성공
   ```
6. 스모크 테스트(선택, 로컬에서):
   ```
   cd backend && npm ci && npm test        # 17건 통과 확인
   ```

### 아직 MVP 수준인 부분 (실서비스 전 교체 필요)
현재 백엔드는 **메모리 저장(`store.mjs`)** 입니다. 서버가 재시작되면 데이터가 사라집니다.
`db/schema.sql` 로 PostgreSQL을 올리고 저장 계층을 교체해야 실운영이 가능합니다.
이미지도 현재는 영구 저장소에 붙어 있지 않습니다. (설계서 §데이터 모델 참조)

## 3단계 · 프론트 ↔ 백엔드 연결

백엔드 주소가 나오면 프로토타입에서 **한 줄만** 바꿉니다.

`apps/picture-test/index.html`
```js
var WB_API_BASE='';                                  // 변경 전 (데모 모드)
var WB_API_BASE='https://<백엔드주소>';               // 변경 후 (실제 연결)
```
커밋·푸시하면 Pages가 자동 재배포합니다.

임시로 테스트만 해 보려면 코드를 고치지 않고 주소 뒤에 붙여도 됩니다:
```
/apps/picture-test/?api=https://<백엔드주소>
```

### 연결 시 주의
- **HTTPS 필수** — Pages는 https이므로 백엔드가 http면 브라우저가 차단(혼합 콘텐츠)합니다.
- `CORS_ORIGIN` 에 프론트 도메인을 정확히 넣어야 합니다. 안 맞으면 브라우저 콘솔에 CORS 오류가 뜹니다.
- 연결되면 화면 우측 상단 배지가 `백엔드 연결됨` 으로 바뀝니다. 안 바뀌면 데모 모드로 조용히 폴백합니다.

## 4단계 · 실서비스 오픈 전 필수 체크리스트

기술 배포가 끝나도 **아래가 다 되기 전에는 학부모에게 공개하지 마십시오.**

- [ ] **노출된 API 키 폐기 및 재발급** (console.anthropic.com → API Keys → Revoke)
- [ ] **심리사 검수** — `HTP-…`, `KFD-DAP-자유화-…` 지식베이스의 가설·근거수준 검토 및 서명
- [ ] **전문가 확정 게이트 동작 확인** — 확정 전 학부모 리포트가 절대 안 나가는지 실제로 시도해서 확인
- [ ] **동의 플로우** — 만 14세 미만 법정대리인 동의 (`동의서-면책-개인정보처리방침-v0.md` 반영)
- [ ] **개인정보 저장 위치** = 한국 리전, 전송·저장 암호화
- [ ] **파기 배치** — 보관기간 경과 건 자동 삭제 동작 확인
- [ ] **위기 신호 대응 절차** — 자해·학대 의심 시 담당자 지정, 112/119 안내 문구 확인
- [ ] **면책 문구** — 모든 산출물에 "참고용이며 진단이 아님" 노출 확인
- [ ] **감사 로그** — 누가 무엇을 확정했는지 기록되는지 확인

## 5단계 · 도메인 · 비용 · 롤백

### 커스텀 도메인
- 프론트: `Settings → Pages → Custom domain` 에 도메인 입력 → DNS에 `CNAME` 레코드 추가
- 백엔드: 별도 서브도메인 권장 (예: `api.도메인`) → 호스팅이 안내하는 CNAME 등록

### 비용 개요
| 항목 | 예상 |
|---|---|
| 프론트(GitHub Pages) | **0원** |
| 백엔드 호스팅 | 0~3만원/월 (소규모) |
| Claude API | 1건당 약 **$0.08~0.15** (≈ 110~210원) · 3회 호출 기준 |
| 예: 월 100건 | API 약 1.1~2.1만원 + 호스팅 |

### 롤백
- 프론트: GitHub에서 해당 커밋/PR **Revert** → Pages가 자동으로 이전 상태 재배포
- 백엔드: 호스팅의 이전 배포 버전으로 되돌리기, 또는 `ANTHROPIC_API_KEY` 를 비워 mock 모드로 즉시 무력화
