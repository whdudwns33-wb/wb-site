## 0. 한 줄 요약

**"단어를 낱개로 억지로 외우는 앱"이 아니라, ① 잘 심고(부호화) ② 잊기 직전에 물 주고(간격 인출) ③ 실제로 써먹어(산출) 장기 기억으로 굳히는 어휘 훈련 웹앱.** 5가지 콘셉트는 각각 기억과학의 다른 원리를 대표하며, 최종 추천은 "단어 정원(SRS 엔진)"을 골격으로 "뿌리 나무(어원 구조)"와 "연상 공장(AI 연상)"을 흡수한 하이브리드다.

핵심 원칙 네 가지:
1. **재인(보면 앎)이 아니라 회상(떠올림)을 훈련한다.** 4지선다 넘기기가 아니라 능동 인출이 기본 동작.
2. **어종별로 다른 암기법을 쓴다.** 한자어는 형태소 분해, 영어는 키워드 연상·어원, 고유어는 이미지·맥락. 한 가지 카드 형식으로 셋을 똑같이 다루지 않는다.
3. **망각을 전제로 설계한다.** 에빙하우스 망각곡선에 맞춘 간격 반복이 모든 콘셉트의 공통 엔진.
4. **읽기에서 온 단어가 진짜 내 단어다.** 진로독서 앱 어휘장(지문에서 몰랐던 단어)이 이 앱의 1순위 입력이다 — WB만의 해자.

## 1. 배경 & 문제 정의

### 1.1 왜 이 서비스인가

| 대상 | Pain Point | 이 서비스가 주는 것 |
|------|-----------|-------------------|
| **학생** | 단어장을 외워도 시험 끝나면 증발. 한자어는 뜻이 안 와닿고, 영어는 철자·뜻이 안 붙는다 | 단어마다 "외워지는 방법"이 붙어서 오고, 잊을 때쯤 앱이 먼저 부른다 |
| **학부모** | "어휘력이 부족해서 독해가 안 된다"는 말은 듣는데 뭘 어떻게 시켜야 할지 모름 | 주간 리포트: 장기 기억으로 전환된 단어 수가 눈에 보인다 |
| **WB 학원** | 어휘 훈련을 클래스카드(외부 서비스)에 의존 — 데이터·암기법·리포트를 우리가 설계 못 함 | 자체 어휘 엔진: 수업·진로독서 앱·레벨 체계와 완전 연동, 원생 데이터 자산화 |
| **강사** | 단어 시험 출제·채점·재시험 관리가 수작업 | 배정→자동 훈련→자동 리포트. 강사는 검수와 개입만 |

### 1.2 왜 WB인가
- **독해력 = 어휘력**이 학원의 포지셔닝 그 자체. 비문학 독해 실패의 최대 원인이 한자어 어휘이고, WB는 이미 진로독서 앱에서 **한자어 분해(예: 관측(觀測)=볼 관·잴 측)·어휘장 자동 적립**을 구현해 놓았다. 이 앱은 그 어휘장을 "소화"하는 후속 단계다.
- 그림검사·진로독서에서 검증한 **"AI 초안 → 강사 검수 게이트 → 학생용 쉬운 출력"** 파이프라인을 그대로 재사용한다.
- 원내 태블릿 학습존이 있어 **원내 10분 훈련 → 가정 복습 알림**의 이중 루프가 즉시 가능하다.
- 웩슬러(작업기억 지표) 센터로서 "기억의 과학"을 말할 자격이 있는 브랜드 — 마케팅 서사가 자연스럽다.

### 1.3 기존 서비스와의 차별점 (경쟁 구도 요약)

| 서비스 | 구조 | 한계 |
|--------|------|------|
| 클래스카드 (현재 사용 중) | 교사 배정 + 암기/리콜/스펠 학습 + 배틀 | 카드 뒤집기 중심(재인 편향), 어종별 암기법 없음, 한자어 분해 없음, 망각곡선 개인화 약함 |
| 안키/큐즐렛류 | SRS 플래시카드 | 초·중등 혼자 쓰기엔 진입장벽·동기 설계 부재, 한국어 어휘 콘텐츠 없음 |
| 수능·영단어 앱 (워드마스터 등) | 고정 단어장 + 테스트 | 영어 단일 어종, 읽기 활동과 무관한 남의 단어 목록 |
| **본 앱** | **3어종 통합 + 어종별 암기법 + 개인 망각곡선 + 읽기 연동** | — |

## 2. 공통 기억과학 엔진 (5개 콘셉트의 공통 뼈대)

어떤 콘셉트를 고르든 아래 엔진은 동일하게 깔린다. 각 콘셉트는 이 엔진 위에 "무엇을 전면에 내세우느냐"가 다를 뿐이다.

### 2.1 기억의 3단계와 앱의 대응

```
[부호화 Encoding]          [응고화 Consolidation]        [인출 Retrieval]
단어를 "붙는 형태"로 가공   단기 → 장기 전환               꺼내는 연습이 기억을 강화
─────────────────────    ─────────────────────        ─────────────────────
· 어종별 암기법 적용        · 당일 밤 "자기 전 3분" 복습    · 회상형 퀴즈(주관식 우선)
· 이중 부호화(글+그림+소리) · 수면 응고화 활용 푸시(21시)   · 간격 반복(SRS) 스케줄
· 생성 효과(내가 만든 연상) · 학습 직후 10분 뒤 1차 재인출  · 맥락 바꿔 인출(문장→그림→음성)
```

### 2.2 단기 기억 설계 (작업기억을 넘치지 않게)

- **한 세션 = 신규 5~7개** (작업기억 용량 4±1 청크 존중, 청킹으로 확장). 10~15분 내 종료.
- 세션 내 3회 미니 인출: **즉시 → 10분 후 → 세션 종료 직전**. 같은 단어를 형식을 바꿔 3번 꺼낸다.
- 멀티모달 입력: 눈(글자·이미지) + 귀(발음 TTS) + 입(따라 말하기) + 손(쓰기/타이핑) 중 최소 2채널.
- 신규 학습은 **의미 유사 단어를 한 세션에 몰지 않는다**(간섭 방지) — 뿌리 학습(콘셉트①)만 예외적으로 의도적 묶음.

### 2.3 장기 기억 설계 (단기 → 장기 전환)

- **간격 반복 스케줄(기본값)**: 학습 당일 밤 → 1일 → 3일 → 7일 → 14일 → 30일 → 90일. 회상 성공 시 간격 확대, 실패 시 축소 (SM-2 계열 개인화 알고리즘).
- **인출 난이도 사다리**: 연상 힌트 보고 회상 → 힌트 없이 회상 → 문맥 빈칸 → 산출(문장 만들기·말하기). 단계가 오를수록 "바람직한 어려움"이 커져 기억 흔적이 깊어진다.
- **졸업제**: 서로 다른 맥락에서 3회 연속 회상 성공 + 30일 간격 통과 = "장기 기억 전환" 판정 → 졸업 단어도 월 1회 랜덤 소환(과잉학습 유지).
- **자기 전 복습 모드**: 21:00~22:00 푸시 → 오늘 배운 단어만 3분 회상. 수면 중 응고화를 노린 하루의 마지막 인출.

### 2.4 어종별 암기법 매트릭스 (부호화 규칙)

| 어종 | 1차 암기법 | 2차 암기법 | 예시 |
|------|-----------|-----------|------|
| **한자어** | **형태소 분해** — 한자 뿌리의 뜻으로 단어 뜻을 "조립" | 같은 뿌리 가족 묶기(스키마) | 관측(觀測) = 볼 관 + 잴 측 → "보고 잰다" / 觀 가족: 관찰·관점·관객·주관 |
| **영어** | **키워드 연상법** — 발음과 비슷한 우리말 + 뜻을 잇는 장면 | 어원(라틴·그리스 어근) 분해 | tenacious → "테나(끈)이 셔츠를 끈질기게 안 놓음" / spect(보다): inspect·respect·spectator |
| **고유어** | **이미지·상황 연상** — 뜻이 살아나는 그림 한 장 + 예문 | 유의어·반의어 짝, 말맛(어감) 비교 | 가늠하다 → 눈금자를 눈으로 재는 장면 / 가늠하다↔어림하다↔재다 |

> 세 어종을 **하나의 의미망**으로도 잇는다: 觀(보다) ↔ spect/vis(보다) ↔ 살펴보다·눈여겨보다. "보다" 의미 하나에 3어종이 매달리는 구조가 WB식 통합 어휘망이다.

### 2.5 훈련 모드 스펙트럼 — 플래시카드와 "깜빡이 모드" (v1.1 추가)

**배경 판단**: 예전 "깜빡이 학습기"(단어를 짧게 보여 줬다 감추고, 잠시 뒤 뜻을 보여 주는 자동 반복 기계)를 기억과학으로 분해하면, 취할 성분과 버릴 성분이 분명히 갈린다.

| 깜빡이 기계의 성분 | 과학적 판정 | 본 앱의 처리 |
|------|------|------|
| 짧은 노출 뒤 뜻 공개 — 그 "빈틈"이 사실상 회상 시도를 유도 | **유효** — 시간 압박 인출(시험 효과의 변형) | 스피드 리콜 모드의 핵심 동작으로 채택 |
| 기계가 템포를 정하는 외부 페이싱 | **유효** — 시작 마찰·딴짓 제거, 저노력으로 지속 | 자동 재생 리듬 + TTS 발음 동시 재생 |
| 짧은 시간 대량 반복 노출 | **부분 유효** — 친숙도·프라이밍은 형성되나, 그것만으로는 급속 망각(몰아치기 학습) | 신규 단어 "워밍업 2회전"과 자기 전 복습에만 사용, 간격 관리는 SRS가 담당 |
| "우뇌·무의식 학습" 마케팅 | **무효** — 근거 없음(학습은 주의를 요구) | 채택하지 않고, 마케팅 문구에도 쓰지 않는다 |
| "봤으니 안다"는 느낌 | **위험** — 친숙도 착각(재인≠회상) | 깜빡이 결과는 졸업 판정에 불산입, 보조 가중치만 |

**결론: 별도의 6번째 콘셉트가 아니라, ④ 단어 정원 엔진 안의 "훈련 모드 3종"으로 추가한다.**

| 모드 | 동작 | 용도(슬롯) | SRS 반영 |
|------|------|-----------|---------|
| **클래식 플래시카드** | 앞면 보고 속으로 답 → 탭해서 뒤집기 → 자기 채점(다시/알쏭/알아) | 강사 배정 단어 시험 대비, 익숙한 UX를 원하는 학생·강사 | 자기 채점이 간격에 정식 반영 (안키 방식) |
| **노출 깜빡이** | 단어 0.8초 → 뜻+발음(TTS) 1.2초 자동 리듬 재생, 채점 없음 — 손 안 대고 눈·귀로만 | ① 신규 단어 심기 전 워밍업 2회전 ② 자기 전 3분 복습(피곤해도 가능한 저마찰 모드) | 반영 안 함 (노출 기록만) |
| **스피드 리콜 깜빡이** | 단어 flash → 제한시간 안에 뜻 떠올리기 → 정답 공개 → ○/× 원터치. 연속 성공 시 노출 시간이 줄어드는 "속도 레벨" | **인출 자동화 훈련** — 이미 회상 가능한 단어를 "빨리 아는 단어"로 | 보조 가중치 (졸업 판정은 여전히 회상·산출만) |

**왜 이것이 WB에 특히 맞는가**
1. **인출 속도가 곧 독해력이다.** 읽다가 단어 하나 해석에 반 박자씩 걸리면 작업기억이 새서 문장 이해가 무너진다(자동성 이론). 스피드 리콜은 "아는 단어"를 "즉시 아는 단어"로 만드는 훈련 — 어휘 앱 대부분이 정확도만 재고 속도는 훈련하지 않는다.
2. **자기 전 3분 슬롯의 최적 형식.** 피곤한 밤의 타이핑 퀴즈는 이탈 포인트 — 노출 깜빡이는 누워서도 가능하다(수면 응고화 직전 마지막 재노출).
3. **학부모 세대의 언어.** "그때 그 깜빡이, 기억과학으로 다시 만들었습니다" — 설명이 필요 없는 마케팅 서사. 단, 옛 기계의 우뇌·무의식 주장은 계승하지 않는다.
4. **개발 비용 극소.** 타이머 + 카드 전환 + TTS뿐 — Phase 1에 넣어도 일정 영향이 거의 없다.
5. **측정 가치.** 단어별 반응 속도(ms)가 쌓인다 → "평균 인출 속도 1.8초 → 0.9초" — 학부모 리포트의 눈에 보이는 새 지표(§7).

**안전장치**
- 깜빡이는 짝 연결(단어↔뜻) 훈련에만 최적 — 뉘앙스·용법은 여전히 연상(③)·산출(⑤)의 몫. 신규 단어는 반드시 부호화(뿌리·연상)를 거친 뒤 깜빡이에 투입한다.
- 실제 점멸(스트로브)이 아니라 카드 전환 리듬으로 구현 — 광과민성·접근성 배려, 노출 시간 하한 0.5초 고정, 모션 최소화 설정 존중.

### 2.6 어종 분리와 문제 풀이형 판정 (v1.2 — 파일럿 피드백 반영)

**배경**: 파일럿 배포 후 원장 판단 두 가지 — ① 한글·한자·영어가 한 정원에 섞여 있으니 나누는 게 낫겠다 ② "아는지 모르는지"를 학생 자기 채점이 아니라 문제로 확인해야겠다. 둘 다 타당하여 반영했다.

**① 어종별 정원 분리 — 화면은 나누되 습관은 하나로**

| 층 | 결정 | 이유 |
|------|------|------|
| **화면(정원)** | **분리** — 홈은 3개 정원(한자어·고유어·영어) 입구, 들어가면 그 어종만 | 학생의 학습 의도가 어종별로 갈린다("오늘 영어 외울래"). 강사 배정·학부모 진도 확인도 어종 단위. 어종 간 간섭도 줄어든다 |
| **오늘 할 일(큐)** | **통합 유지** — 홈의 "오늘 물 주기"는 세 정원을 합쳐 잊기 직전 순서로 | 큐까지 3개로 쪼개면 하루 할 일이 3번 생겨 습관이 무너진다. 매일 한 번 끝나는 구조를 지킨다 |
| **훈련·심기** | 어종 범위 선택 (전체/한자어/고유어/영어) | 필요할 때만 좁혀서 집중 |

> 설계 원칙: **분리는 표면(화면·심기·훈련)에서, 통합은 엔진(SRS 큐·기억 계단)에서.** 어종을 갈라도 "매일 한 번 물 주기"라는 습관 단위는 하나로 남는다.

**② 자기 채점 → 문제 풀이형 판정**

기존 "몰랐어/알쏭해/알았어" 자기 채점은 §2.5에서 지적한 **친숙도 착각**에 그대로 노출된다 — 특히 어린 학생일수록 "봤으니 안다"고 과대평가한다. 그래서 물 주기를 **객관적으로 채점되는 문항**으로 바꿨다. 어종별 문항 형식은 §2.4 매트릭스에서 이미 예고한 그대로다.

| 어종 | 문항 형식 (기억 계단이 오를수록 뒤쪽 유형) |
|------|------|
| **한자어** | 뜻 4지선다 → **한자 조립**(한 글자를 가리고 훈음 고르기) → 예문 빈칸 |
| **영어** | 뜻 4지선다 → **철자 입력**(첫 글자만 힌트) → **듣고 고르기**(TTS) |
| **고유어** | **예문 빈칸**(활용형까지 가림) → 비슷한 말 고르기 → 뜻 4지선다 |

- 오답 보기는 **같은 어종의 다른 단어**에서 뽑아 난이도를 유지한다(엉뚱한 보기로 정답이 드러나지 않게).
- 채점 → 기억 간격: **첫 시도 정답 = good / 재시도·힌트 후 정답 = hard / 오답 = fail**. 오답은 한 번 더 기회를 주고, 그래도 틀리면 정답과 해설을 공개한다.
- 어떤 경로로 끝나든 **정답·뜻·연상·예문 해설 패널**을 보여 준다 — 틀린 순간이 가장 잘 배우는 순간이기 때문.
- **플래시카드 모드는 자기 채점을 유지한다** — 그건 원래 "뒤집어 보는 카드"가 본질이고, 간격 반영도 정식으로 되므로 선택지로 남긴다.

## 4. 다섯 가지 콘셉트

> 다섯 개는 장식이 다른 같은 앱이 아니라, **각각 기억과학의 다른 원리를 전면에 내세운 서로 다른 형식**이다.
> ① 구조로 외운다 ② 공간에 붙여 외운다 ③ 이야기로 외운다 ④ 잊기 직전에 살려낸다 ⑤ 써먹어서 굳힌다.

### 콘셉트 ① 단어 뿌리 나무 — 어원 네트워크형

> **"단어를 낱개로 외우지 않는다. 뿌리 하나를 심으면 단어 열 개가 자란다."**

**형식**: 화면의 중심이 카드 목록이 아니라 **자라나는 지식 그래프(나무/숲)**다. 한자 1자(觀·測·不…) 또는 영어 어근(spect·port·dict…)이 뿌리 노드, 파생 단어들이 가지. 학습할수록 "내 단어 숲"이 자란다.

**적용 암기법과 근거**
- **청킹**: 관찰·관측·관점·관객을 4개의 낱단어가 아니라 "觀 청크 1개"로 압축 — 작업기억 부담이 1/4.
- **스키마 이론**: 새 단어를 기존 지식망(아는 뿌리)에 붙이면 인출 경로가 여러 개 생겨 장기 기억이 빨리, 튼튼하게 형성된다.
- **정교화**: "왜 이 단어가 이 뜻인지"를 뿌리로 설명할 수 있으면 이해 기반 기억이 된다(기계적 암기의 반대).

**단기 → 장기 설계**
- 단기: "오늘의 뿌리 1개 + 파생어 5~6개"가 한 세션. 뿌리의 미니 스토리(觀: 황새 관(雚)+볼 견(見) = 황새가 높은 데서 내려다봄) → 파생어 조립 → 즉시 회상.
- 장기: 복습이 **뿌리 단위 자유 회상**("觀 보고 아는 단어 전부 말해 봐") — 하나의 인출이 가족 전체를 재활성화해 복습 효율이 낱단어 SRS보다 높다. 진로독서 지문에서 아는 뿌리를 만나면 하이라이트 → 실전 재노출.
- 전이 효과: **처음 보는 단어도 뿌리로 뜻을 추론**하는 능력이 생긴다. 이것이 곧 독해력 — 학원 포지셔닝과 정확히 일치.

**3어종 처리**: 한자어(최적 — 본 콘셉트의 주인공), 영어(어근·접두사로 동일 구조: in-spect, re-spect), 고유어(뿌리 대신 "말 가족" — 밟다·짓밟다·밟히다, 유의어망). 그리고 §2.4의 **의미 다리**(觀↔spect)로 3어종 교차 연결 — 국내 어휘 서비스에 없는 구조.

**핵심 화면**: ① 내 단어 숲(줌 가능한 뿌리 지도) ② 오늘의 뿌리(스토리+조립 학습) ③ 뿌리 회상 테스트(뿌리→파생어 쏟아내기) ④ 단어 상세(분해도+형제 단어) ⑤ 뿌리 도감(수집 요소).

**게임화**: 뿌리 수집 도감(초등 필수 한자 100자·중등 300자), 숲 성장 레벨, "이 뿌리로 몇 단어까지 아니?" 최고 기록.

**MVP 범위**: 한자 뿌리 100 + 영어 어근 50 + 파생어 1,500 (AI 생성 → 강사 검수). 그래프는 D3/캔버스 2D로 충분.

**리스크**: 뿌리가 낯선 초3 이하에겐 추상적 — 초등 저학년은 콘셉트 ③·④와 결합 필요. 어원이 불투명한 단어(외래어·고유어 다수)는 커버 불가 → 다른 콘셉트로 보완.

### 콘셉트 ② 내 단어 마을 — 기억 궁전(공간 기억)형

> **"단어를 장소에 놓아 두면, 장소가 단어를 대신 기억해 준다."**

**형식**: 학생이 **자기만의 2.5D 마을을 짓는 빌더**가 메인. 건물(학교·시장·우주정거장·서당·공항…)을 세우고, 방 하나에 단어 5개를 "물건처럼" 배치한다. 단어마다 AI 생성 연상 이미지가 그 자리에 붙는다. 복습은 "마을 산책" — 정해진 경로로 방을 걸으며 그 자리에 뭐가 있었는지 회상한다.

**적용 암기법과 근거**
- **장소법(Method of Loci)**: 세계기억력대회 선수 전원이 쓰는 검증된 기법. 시공간 기억은 언어 기억보다 용량이 크고 잘 안 지워진다.
- **이중 부호화**: 단어(언어) + 이미지(시각) + 위치(공간) 3중 흔적.
- **생성 효과**: "어느 방 어느 자리에 둘까"를 학생이 직접 결정하는 행위 자체가 정교화다.

**단기 → 장기 설계**
- 단기: 방 1개 = 1세션(단어 5개). 배치 직후 "불 끄고 산책"(방금 놓은 것 회상) 1회.
- 장기: **복습 안 한 방엔 안개가 낀다** — 망각곡선을 공간의 시각 상태로 번역. 산책 경로가 SRS 스케줄대로 자동 편성되어 "오늘 걸을 길"만 따라가면 복습 완료. 안개 걷기(회상 성공)를 반복한 방은 "빛나는 방"으로 승격(장기 기억 전환).
- 인출 사다리: 이미지 보고 회상 → 빈 방 보고 회상 → 마을 지도만 보고 경로 전체 회상.

**3어종 처리**: 구역으로 자연 분리 — 한자어는 "서당 거리"(건물마다 뿌리 현판), 영어는 "국제 공항 구역", 고유어는 "전통 마을". 또는 의미별 건물(감정의 집·과학 타워)로 어종 혼합 배치도 선택 가능.

**핵심 화면**: ① 내 마을(줌·산책) ② 방 꾸미기(단어 배치+이미지 선택) ③ 오늘의 산책(SRS 복습 경로) ④ 안개 지도(위험 단어 현황) ⑤ 친구 마을 방문(잘 지은 배치 구경).

**게임화**: 건물·장식 해금(복습 완수 재화로 구매), 마을 인구(=장기 기억 단어 수), 계절 이벤트.

**MVP 범위**: 3D 아님 — **일러스트 타일 + 고정 시점 2.5D**로 단순화. 건물 8종, 방 템플릿 12종이면 시작 가능.

**리스크**: 다섯 중 개발 비용 최대(그래픽 자산). 배치에 시간을 쓰다 학습이 뒷전이 될 수 있음 → 배치 시간 제한(방당 3분)과 "자동 배치 후 수정" 옵션으로 제어. 고등학생에겐 유아적으로 보일 수 있어 초·중등 특화.

### 콘셉트 ③ 찰떡 연상 공장 — AI 연상·스토리형

> **"AI가 내 취향으로 찰떡 연상을 뽑아 주고, 내가 한 번 고치면 완전히 내 것이 된다."**

**형식**: 단어가 들어오면 AI가 **연상 3종 세트**를 생성한다 — ① 발음 키워드 연상(영어) / 한자 모양·뜻 이야기(한자어) / 상황 연상(고유어) ② 연상 장면 이미지 ③ 15초 초단편 이야기. 학생은 셋 중 하나를 **고르고, 한 군데를 자기 말로 고쳐서** "내 연상 카드"를 완성한다. 잘 만든 연상은 반 갤러리에 공유되고 좋아요를 받는다.

**적용 암기법과 근거**
- **키워드 연상법**: 외국어 어휘 학습에서 효과가 가장 많이 검증된 기법(Atkinson) — 발음 유사어와 뜻을 잇는 상호작용 이미지.
- **기괴함 효과**: 평범한 장면보다 엉뚱하고 과장된 장면이 오래 남는다 — AI에게 "약간 황당하게"를 기본 지시.
- **생성 효과 + 자기참조 효과**: 남이 준 연상보다 내가 손 댄 연상이, 남의 소재보다 **내 관심사(게임·축구·아이돌·웹툰 — 온보딩에서 수집)** 소재가 더 오래간다.

**단기 → 장기 설계**
- 단기: 신규 7개 → 단어당 "연상 고르고 고치기 60초" → 즉시 가림 퀴즈(연상 카드 절반 가림).
- 장기: SRS 복습에서 **연상 비계(飛階)가 점점 흐려진다** — 1차 복습은 연상 카드 전체, 2차는 이미지만, 3차는 단어만. "연상 없이 3연속 회상" = 졸업. 연상은 사다리일 뿐 목적지가 아니라는 걸 시스템이 강제.
- 갤러리 재노출: 친구 연상에 좋아요를 누르는 행위가 비의도적 추가 노출이 된다.

**3어종 처리**: 영어(키워드법 최적 — tenacious→"테나 셔츠"), 한자어(한자 자원(字源) 이야기 — 觀=황새가 크게 본다), 고유어(소리·어감 연상 — "미쁘다: 믿음직해서 미소가 피식"). 어종마다 연상 생성 프롬프트 템플릿을 분리 설계.

**핵심 화면**: ① 연상 공장(생성→선택→수정) ② 내 연상첩 ③ 가림 퀴즈 ④ 반 갤러리(좋아요·이 주의 연상왕) ⑤ 강사 검수함(부적절 연상 필터 — 게이트 필수).

**게임화**: 연상왕 주간 랭킹, 좋아요 획득 배지, "내 연상이 후배 기본 카드로 채택"(명예 시스템).

**MVP 범위**: 이미지 생성은 초기엔 단어당 1회(비용 제어), 텍스트 연상은 3안. 검수 게이트는 기존 파이프라인 재사용.

**리스크**: 연상 의존증(연상만 기억하고 뜻은 못 꺼냄) → 비계 흐리기·졸업제로 구조적 해결. AI 연상 품질 편차 → 강사 검수 + 좋아요 데이터로 자동 품질 학습. 유해·부적절 연상 생성 → 검수 게이트 통과분만 갤러리 노출.

### 콘셉트 ④ 단어 정원 — 망각곡선 케어(SRS)형

> **"단어마다 기억 씨앗을 심는다. 시들기 직전에 물을 주면, 뿌리가 점점 깊어진다."**

**형식**: 홈 화면이 **내 정원**이다. 단어 1개 = 화분 1개. 기억 강도가 식물의 생명 상태로 그대로 보인다 — 새싹(방금 배움) → 줄기 → 꽃 → 나무(장기 기억). 에빙하우스 곡선에 따라 시간이 지나면 시들기 시작하고, **"물 줄 시간"(=최적 복습 타이밍)에 푸시가 온다.** 물 주기 = 회상 퀴즈 성공. 성공할수록 다음 물 주기 간격이 벌어진다(1일→3일→7일→…). 나무가 된 단어는 "평생 숲"으로 이식된다.

**적용 암기법과 근거**
- **간격 반복 + 인출 연습**: 학습과학에서 효과 크기가 가장 크게, 가장 반복적으로 검증된 두 기법의 결합. 이 콘셉트는 그 자체를 제품화한 것.
- **망각의 가시화**: 아이들이 복습을 안 하는 이유는 "잊고 있다는 사실 자체가 안 보여서"다. 시드는 화분은 망각을 정서적 사건으로 바꾼다(돌봄 심리 — 다마고치 효과).
- **바람직한 어려움**: 아슬아슬하게 잊을 뻔한 순간의 인출이 기억을 가장 강화한다 — 물 주기 타이밍이 바로 그 순간을 조준.

**단기 → 장기 설계 (이 콘셉트가 곧 그 설계다)**
- 단기: 오늘 심기 5~7개 → 당일 3회 미니 인출(즉시·10분 후·**자기 전 3분 물주기 푸시 21:00**).
- 장기: 단어별 개인화 간격(SM-2 계열: 실패하면 간격 리셋+연상 카드 재제시, 쉽게 성공하면 간격 점프). "나무 승급" = §2.3 졸업 판정과 동일. 시든 단어만 모은 **"응급 화단"**이 매일 복습의 최우선 큐.
- 학부모 리포트: "이번 주 물 준 횟수 34회, 나무가 된 단어 23개, 응급 화단 5개" — 장기 기억 전환이 숫자로 보인다.

**3어종 처리**: 씨앗 3종 — 한글꽃(고유어)·한자나무(한자어)·영어허브(영어)로 정원 구역 분리. 퀴즈 유형도 어종별로 다름(한자어: 분해→조립형 / 영어: 철자 타이핑+발음 듣기 / 고유어: 문맥 빈칸). 부호화 단계는 §2.4 매트릭스를 그대로 사용.

**핵심 화면**: ① 내 정원(기억 상태 한눈에) ② 오늘의 물 주기(SRS 큐) ③ 심기(신규 학습) ④ 평생 숲(졸업 단어 아카이브) ⑤ 응급 화단 ⑥ 학부모·강사 리포트.

**게임화**: 정원 레벨·희귀 식물 해금(연속 출석), 스트릭(연속 물 주기 일수), 반 대항 "숲 넓이" 경쟁.

**MVP 범위**: 다섯 중 **개발 난이도 대비 학습 효과가 가장 확실**. 화분 상태는 CSS/SVG 5단계 일러스트면 충분. SRS 알고리즘 + 푸시(PWA 알림) + 퀴즈 3형 + 훈련 모드 3종(클래식 플래시카드·노출 깜빡이·스피드 리콜 — §2.5)이 코어.

**리스크**: 원리 자체는 안키·클래스카드도 표방 — 차별화는 ① 망각의 정서적 가시화 ② 어종별 부호화 ③ 진로독서 어휘장 자동 유입("내가 읽다 막힌 단어"가 씨앗으로 도착)에서 나온다.

### 콘셉트 ⑤ 써먹기 훈련소 — 산출·실전형

> **"외운 단어는 써먹어야 내 것이 된다. 말하고, 쓰고, 대결하며 굳힌다."**

**형식**: 주간 미션 구조. 이번 주 단어 20개가 "장전"되고, 5가지 훈련장에서 **실제로 사용해야** 불이 켜진다 — ① **AI 대화 미션**: AI 캐릭터(진로별 — 과학자·기자·셰프)와 대화하며 목표 단어를 자연스럽게 사용하면 클리어(영어 단어는 영어 대화) ② **한 문장 짓기**: 내가 만든 문장을 AI가 뜻·용법 판정+교정 ③ **스피드 아레나**: 반 친구와 실시간 뜻 맞히기 대전 ④ **빈칸 스토리**: 이번 주 단어로 이야기 완성 ⑤ **소리 내기**: 발음하고 뜻 말하기(음성 인식 채점).

**적용 암기법과 근거**
- **산출 효과**: 소리 내어 말하거나 써 본 단어가 눈으로만 본 단어보다 확실히 오래 남는다.
- **시험 효과의 최상급**: 회상 중에서도 "맥락 속 사용"은 가장 깊은 인출이다.
- **맥락 다양화(전이)**: 같은 단어를 대화·작문·게임 등 다른 상황에서 꺼내 본 기억은 상황 단서에 묶이지 않는 유연한 기억이 된다 — 시험장·실전에서 나오는 어휘력.
- **사회적 동기**: 또래 대전·리그는 초·중등 지속률의 가장 검증된 지렛대(클래스카드 배틀의 인기 요인).

**단기 → 장기 설계**
- 단기: 입력은 가볍게(주초 단어 미리보기 5분×2회) — 이 앱의 본질은 인출·산출 훈련에 있다.
- 장기: **"3맥락 졸업제"** — 서로 다른 3가지 훈련장에서 성공해야 졸업. 졸업 단어도 월간 "복귀전"에 랜덤 소환. AI 대화 로그가 그대로 포트폴리오가 된다.
- 한자어 산출은 **격식 문장 미션**(탐구보고서·서술형 문체)으로 설계 → 진로독서 앱의 탐구보고서 작성과 직결.

**3어종 처리**: 영어(AI 영어 대화 — 회화 훈련 겸용), 한자어(서술형·보고서 문장 짓기 — 학업 언어 훈련), 고유어(감정·상황 묘사 대화 — 표현력 훈련). 어종마다 "써먹는 무대"가 다르다는 것 자체가 설계.

**핵심 화면**: ① 이번 주 장전 단어판(사용하면 불 켜짐) ② AI 대화방 ③ 문장 공방(판정·교정) ④ 아레나(실시간 대전·리그) ⑤ 내 사용 기록(문장 포트폴리오).

**게임화**: 주간 리그(반별), 콤보(한 대화에 목표 단어 2개 이상), 캐릭터 친밀도(대화 누적).

**MVP 범위**: ②문장 짓기 + ⑤소리 내기부터(판정 프롬프트만으로 가능). AI 대화·실시간 대전은 Phase 2. 음성은 Web Speech API로 시작.

**리스크**: 신규 부호화 기능이 없어 **단독으로는 불완전**(외우는 단계는 다른 콘셉트 필요). AI 판정 오류 → 이의신청 버튼+강사 확인. 대화 미션의 억지 사용 문장 → "자연스러움" 판정 기준 포함.

### 5.2 추천: "어떤 형식으로 하면 좋을까?"에 대한 답

**결론 — 하나를 고르지 말고, ④를 운영체제로 삼아 ①·③을 흡수한 하이브리드로 시작한다.**

```
[부호화]                       [유지·전환]                  [인출·전이]
① 뿌리 분해 (한자어·영어 어원)                                ⑤ 써먹기 미션
③ AI 찰떡 연상 (관심사 기반)  →  ④ 단어 정원 (SRS 물 주기)  →   (문장 짓기부터)
   "잘 심는다"                    "잊기 전에 살린다"            "써서 굳힌다"
                                        ↑
                          진로독서 앱 어휘장 자동 유입 (씨앗 공급)
```

이유:
1. **장기 기억의 과학적 몸통은 결국 간격 인출이다.** ④가 없는 ①·②·③은 "잘 외웠다가 그대로 잊는" 앱이 되고, ④만 있으면 "붙지 않는 단어에 물만 주는" 앱이 된다. 부호화(①·③)와 유지(④)는 선택지가 아니라 직렬 파이프라인이다.
2. **④는 개발 난이도 대비 효과가 가장 확실**하고 전 학년을 커버한다 — MVP 골격으로 최적.
3. **①은 WB 포지셔닝의 심장**이다(한자어 분해→처음 보는 단어 추론=독해력). 진로독서 앱에 이미 있는 한자어 분해 데이터를 그대로 카드로 쓴다.
4. ②(마을)는 그래픽 비용이 커서 Phase 3의 초등 특화 스킨/모드로, ⑤(훈련소)는 문장 짓기 한 종만 Phase 2에 넣고 대화·아레나는 후순위로.
5. **씨앗 공급이 차별화의 반이다**: 진로독서 지문에서 막힌 단어가 다음 날 정원에 씨앗으로 도착하는 연결 — "읽다가 몰랐던 진짜 내 단어를 외우는" 경험은 고정 단어장 앱이 흉내 낼 수 없다.

### 5.3 통합 후 일일 사용자 루프 (10분)

```
(1분) 정원 입장 — 시든 화분·오늘 물 줄 단어 확인
(4분) 물 주기 — SRS 회상 퀴즈 (연상 비계는 점점 흐려짐)
(3분) 새로 심기 — 신규 5~7개: 뿌리 분해(①) 또는 AI 연상(③)으로 부호화
(2분) 써먹기 1개 — 어제 단어로 문장 하나 짓기(⑤)
(밤 21:00) 자기 전 3분 물주기 푸시 — 오늘 심은 단어만 노출 깜빡이 모드로 재노출 (§2.5)
```

## 6. 시스템·기술 설계 (공통)

### 6.1 아키텍처 — 기존 WB 패턴 재사용

- **프런트**: 정적 PWA(vanilla HTML/CSS/JS) — `reading/`·`student/`와 동일 스택. 오프라인 캐시(sw.js)로 태블릿 학습존·가정 모두 대응. 푸시는 PWA Notification + (보조) 알림톡 후보 연동.
- **백엔드**: Cloudflare Workers + KV(진로독서 서버 패턴). 학습 이벤트 로그·SRS 상태·단어 DB.
- **AI 파이프라인**: 연상·예문·이미지·문장 판정 생성 → **강사 검수 게이트**(그림검사·진로독서에서 검증된 "AI 초안→전문가 확정" 패턴) → 학생 노출.
- **데이터 모델(핵심)**: `word(어종, 뿌리[], 뜻, 예문, 연상카드[])`, `root(자원 스토리, 파생어[])`, `memory_state(user, word, 강도, 다음 복습일, 단계, 연속 성공)`, `usage_log(맥락, 산출문)`.

### 6.2 콘텐츠 소싱

| 어종 | 소스 | 규모(MVP) |
|------|------|-----------|
| 한자어 | 교육부 기초 한자 + 진로독서 지문 빈출 한자어(이미 분해 데이터 축적 중) | 뿌리 100자·단어 1,000 |
| 고유어 | 초·중 교과 필수 어휘 + 수능 기출 어휘 | 600 |
| 영어 | 학년별 교과 단어 + 어근 50 | 1,000 |

- 학생별 동적 소스: **진로독서 어휘장(1순위)**, 강사 배정 단어장, 학생 직접 추가.

### 6.3 개인정보·안전
- 학습 로그는 원생 계정 체계(student 포털)와 통합, 학부모 열람 동의 기존 절차 준수.
- AI 생성 콘텐츠(연상·이미지·대화)는 검수 게이트 통과분만 공유 영역(갤러리) 노출. 미검수분은 본인 화면 한정.

## 7. KPI

- **North Star**: **장기 기억 전환 단어 수** (30일 간격 회상 통과 = "나무" 승급 수 / 주).
- 습관: 일일 물 주기 완수율, 스트릭 중앙값, 자기 전 복습 실행률.
- 학습: 신규 심기 수/주, 복습 정답률 추이, 응급 화단(리스크 단어) 해소율, 연상 비계 없는 회상 도달률, **평균 인출 속도(ms)** — 아는 단어를 얼마나 빨리 꺼내는지(자동화 지표, 스피드 리콜 깜빡이에서 측정).
- 연동: 진로독서 어휘장 → 씨앗 전환율(적립 단어 중 학습 시작 비율).
- 전환(외부): 체험판(무료 진단 "우리 아이 어휘 나이") → 상담 예약 전환율.
