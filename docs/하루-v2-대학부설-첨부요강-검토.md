목포대 두 요강의 지역명은 **‘전남광주통합특별시’**로 표기돼 있다. 이 표현을 법적 행정구역 확정이나 광주 학생의 지원 가능 판단에 사용하지 않고 기관 확인 대상으로 남겼다. 상태도 ‘확인 필요’다. 전북대 PDF 안의 공동 선교육 참여 대학 수 26/27 상충은 화면 자격 조건으로 사용하지 않았다.

순천대·전북대는 읽은 범위만 ‘공식 확인’이며 사회통합 개별 증빙·평가 세부 시각/장소까지 확정한 뜻이 아니다. 순천대 선교육 접수는 일정 표와 방문·우편 흐름을 함께 확인해야 해 제출 방법 재확인 문구를 남겼다. 등록 마감 시각이 없는 일정은 날짜만 표시했다. 순천대 검사의 종료 시각도 없어 14시 시작은 설명에만 넣었다. 중복 지원과 중복 등록·동시 입학 금지를 구분한다.

## 파일과 검사

- `haru/v2/catalog.json`: 공식 출처 4개 추가, 기존 세 기관 안내 보완·목포대 특별전형 분리. 기존 출처 이력 유지. 다른 학교·지역 펼침 안내 총 15개.
- `haru/v2/catalog.js`: 관찰평가 후 ‘지난 일정’ 표시.
- `haru/v2/index.html`: 데이터에서 재생성. 광주·삼육 상세 화면 생성물 변경 없음.
- `haru/v2/public.test.cjs`: 전형 분리, 자격/지역·우편 조건, 접수 마감 경계, 관찰평가·출처 이력 보존 검사.
- README·AGENTS·이 문서: 확인 범위·다음 작업 인계.

`node scripts/check.mjs` **299/299 통과(41.4초)**. 최신 main의 검사 2개 증가가 포함됐다. 공개 화면 세부 검사 **7개 통과**, `node reading-server/build-dist.mjs`와 `git diff --check` 통과.

실제 브라우저에서 목포대 특별전형과 순천대 상세를 펼쳐 본문·날짜가 반영된 것을 확인했다. 긴 설명을 펼친 320·390px에서 가로 넘침이 없고 오류 로그도 없었다. 기본 화면 크기로 복원했다. 실제 휴대전화·운영 주소는 미검증이다.

PDF는 임시 폴더에서 읽었고 원본·양식·외부 콘텐츠를 저장소에 추가하지 않았다. 읽기 도구 `pypdf`도 임시 폴더에만 설치해 앱 의존성은 늘리지 않았다. PDF 텍스트를 추출해 대조했으며 원문 전체의 시각 검수나 증빙별 자격 판정은 하지 않았다.

## 검토와 남은 일

이 PC의 [다른 학교·지역 안내](http://127.0.0.1:8941/haru/v2/#other)에서 대학별 펼침 항목을 확인한다. 생성은 `node haru/v2/build.mjs`. 롤백은 이번 첨부 요강 보완 커밋만 되돌리고 다시 생성·검사한다.

수업 운영값은 전부 **미정**: 대상·인원, A/B 경로, 담당 교사, 대체 시간, 시행일, 배부 담당·방식, 기록 수집 여부. 실제 수업·배정·접수·추천 대행·발송을 시작하지 않았다. 학생 흐름·채점·API·권한·KV·플랜과 기존 정본 후보 상태도 유지한다.

다음 독립 작업은 광주 기관별 첨부 상세, 키움 운영학교·KAIST 2027 연도, 다른 학교 첨부 및 전남·전북 전수 명부 확인이다. 전체 기관 확인 완료로 표시하지 않는다. 원장의 수업 운영 결정은 나중에 받으며 T2/T3와 사람 전용 작업 조건은 그대로다.
