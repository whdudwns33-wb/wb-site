## 2. 다른 컴퓨터에서 코드 받기

GitHub 저장소 접근 권한이 있는 계정의 Git과 Node.js24를 사용한다. PC에 저장소가 없으면 PowerShell에서 원하는 작업 폴더를 연 뒤 실행한다.

```powershell
git clone --branch codex/haru-gwangju-latest-20261027 https://github.com/whdudwns33-wb/wb-site.git wb-site-haru
Set-Location wb-site-haru
git status --short
git log -3 --oneline
```

이미 저장소가 있으면 먼저 `git status --short`와 `git remote -v`를 확인한다. 미커밋 파일을 지우거나 강제 전환하지 말고, 원격 작업 브랜치를 별도 worktree로 받는다. 같은 브랜치를 다른 PC에서 동시에 수정·푸시하지 않는다.

읽는 순서:

1. 루트 `AGENTS.md` → `haru/README.md` → `haru/AGENTS.md`.
2. [광주 최신 요강·원문·남은 미확인 검토](하루-v2-광주영재-최신요강-1027-검토.md).
3. [세 중학교 등록·예비소집 후속](하루-v2-등록예비소집-후속검토.md), 필요할 때 [개인 계정·API·MCP 운영](하루-개인계정-API-MCP-운영.md).

`ponytail` full을 기본 적용하되 스킬 경로는 해당 PC에서 찾아 읽는다. 없으면 그 사실을 알리고 기존 코드 재사용·최소 변경·출처 확인·검증 원칙을 따른다. 답변·커밋 메시지·새 주석은 한국어로 쓴다.

## 3. 운영 계정 없이 로컬 화면 보기

저장소 루트에서 아래 PowerShell 명령을 실행하고 창을 열어 둔다. 테스트용 빈 계정 저장소만 쓰는 로컬 미리보기이며 운영 계정·키가 필요하지 않다. 8943을 다른 프로그램이 쓰고 있으면 비어 있는 포트로 바꾸고 URL도 맞춘다.

```powershell
@'
import { createStaffServer } from './reading-server/haru-staff-server.mjs';
import path from 'node:path';
const app = await createStaffServer({
  port: 8943,
  publicOrigin: 'https://preview.invalid',
  backend: 'https://backend.invalid',
  secret: 'local-preview-only',
  privateDir: path.resolve('.private/haru-preview-kjh')
});
app.server.listen(8943, '127.0.0.1');
'@ | node --input-type=module
```

- 공개 홈: http://127.0.0.1:8943/haru/v2/
- 광주 영재교육: http://127.0.0.1:8943/haru/v2/gwangju-gifted/
- 학생 예시: http://127.0.0.1:8943/haru/?preview=1
- 보호자 예시: http://127.0.0.1:8943/haru/parent.html?preview=1

이 미리보기에서 실제 관리자 로그인/API는 연결하지 않는다. 확인 순서는 초5·초6 필터 → 전남대 전형별 펼침 → 일반/선교육 추천 차이 → 원서11/23·일반 추천11/24 → 심화11/28·면접12/12·등록12/18~22 → 키움·KAIST와 각 기관 추가 공지다.

**127.0.0.1은 주소를 여는 컴퓨터 자신이다.** wb1에서 쓰던8941/8943 주소를 김정현 PC에서 그대로 열어도 wb1 화면에 연결되지 않는다. 위 서버를 김정현 PC에서 직접 실행해야 한다.

## 5. 운영·비밀정보·승인 경계

- 운영 화면: https://haru.wbcowork.com/ — 서버는 **현재 wb1**, Node8951·Cloudflare 터널 `wb-haru-wb1`. 개발 PC를 바꾼다고 운영 서버가 이동하지 않는다. wb1 전원·네트워크·로그인이 필요하다.
- 운영 작업트리는 wb1의 `wb-site-haru-access`, 개발은 `wb-site-haru-gwangju-latest`다. 이 폴더명·절대경로는 김정현 PC의 필수 경로가 아니다.
- 운영 비공개 설정·SQLite·세션·API 키·Cloudflare 터널 자격 파일은 Git에 없고 인수인계 묶음에도 없다. 개발용으로 복사·초기화·새 터널 생성하지 않는다.
- 기존 관리자 `wb김정현`은 대비 앱 관리자다. 비밀번호를 재설정하거나 로그인했다고 가정하지 않는다. 초기 비밀번호 변경이 미완료라면 기존 정책상 **서버 PC wb1의 로컬8951**에서 당사자가 먼저 변경해야 외부 로그인 가능하다. 완료 여부는 이 문서에서 확인하지 않았다.
- 실제 개인 API/MCP 연결이 필요한 별도 요청 때 기존 운영 문서를 따른다. 개발 검토에 운영 쓰기 권한은 필요하지 않다.
- 수업 시간·횟수·수강료·담당자·개설·배부·기록 수집 조건은 미정. 학생 기록·실제 추천서/증빙 수집·발송·자동 수집 활성화·권한 개편·데이터 이관·영재학습 MVP로 범위를 확대하지 않는다.
- `main` 직접 푸시는 운영 배포다. PR 머지는 원장 승인 뒤 진행한다. 운영 플랜 재업로드·정본 후보 체크·주간 스윕 등 사람 전용 작업은 실행하지 않는다.

## 7. Git에 없는 참고 산출물
