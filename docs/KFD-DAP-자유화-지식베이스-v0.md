# KFD · DAP · 자유화 해석 지식베이스 v0 (AI 엔진 재료)

> 그림검사 AI 해석 웹 · 검사별 지식베이스 초안 (HTP는 별도 문서)
> 출처: Perplexity 딥리서치(2026-07-27), 임상·학술 자료 종합. **전문 심리사 검수 전 초안입니다.**
> 근거수준: **강**=연구/표준화 채점 / **중**=임상·교재 통념 / **약**=상징·이론 추정.

## 공통 원칙 (전 검사 하드코딩)

- 모든 해석은 **"가능성·경향" 가설** — 단일 지표·단일 그림으로 진단 금지.
- 발달·문화·가족구조·미술경험을 먼저 고려한 뒤 해석(예: "아버지 생략=갈등" 단정 금지).
- 그림 후 질문(PDI, "누구인가요?/무슨 일이 일어나나요?")으로 아동 설명 확인 필수.
- 표준화 검사·면담·행동관찰과 **교차검증**. 반복 패턴에 더 높은 의미.

## 1. KFD (동적 가족화) — 가족 관계·역동 지각

### 관찰요소 → 가설 → 근거수준

| 관찰요소 | 통상 가설 | 근거수준 |
|---------|----------|:-------:|
| 인물 간 거리·배치 | 가까움=친밀·의존 / 멂=갈등·회피·소외감 | 중 |
| 활동·상호작용 | 함께 활동=지지적 체계 / 각자 활동=단절감 / 특정인만 노동=역할 부담 | 중 |
| 생략된 가족원 | 덜 중요·갈등·두려움·상실 (반복 시 의미 강화) | 중 |
| 추가된 인물(친구·반려동물) | 정서적 지지 대체원, 정서 중심 이동 | 중 |
| 자기 위치·크기 | 크게·중앙=자기중심·주목욕구 / 작게·구석=위축·소외감 | 중 |
| 구획화(선·벽으로 분리) | 정서적 분열, 하위체계 갈등, 방어적 분리 | 약~중 |
| 장벽(사물로 가로막기) | 의사소통 차단, 갈등, 방어 욕구 | 약~중 |
| 인물 순서 | 먼저=정서적 중요·애착 / 자기 나중=자기 중요성 축소 | 약~중 |

### 연령 유의
- 만 4~6세: 가족 전원 못 그림·단순 장면 흔함 → 발달적 미숙 우선, 순서·구획화 과잉적용 금지.
- 만 7~9세: 친구·반려동물 중시 문화·개인차 가능. 1회 생략·거리로 단정 금지.
- 만 10세~: **반복 패턴**(특정 인물 지속 생략, 자기만 분리)이 임상 의미 가질 수 있으나 사춘기 독립욕구 병행 고려.

### 타당도 한계
- 투사검사는 "엄밀한 공식 심리검사 아님"(대한의사협회). **가설 생성·정서 탐색 도구.**
- 단, **구조화 평정척도**(한국판 동적가족화 평가기준)는 평정자 간 신뢰도 .967~.975, α .859 등 도구 수준 타당도 보고 — 단 "자유 해석"과는 구분.
- 가족 구성·상황 변화로 그림이 계속 변함 → 재검사 신뢰도 불안정, 한 시점 과잉 의미부여 위험.

## 2. DAP (인물화) — 두 용도를 반드시 분리

> **핵심: DAP는 (a)발달·지능 지표와 (b)정서 지표가 근거수준이 크게 다르다.** 엔진에서 분리 처리.

### (a) 발달·지능 지표 (Goodenough-Harris / Naglieri DAP-IQ) — 근거수준 **중~강**
- 신체부위 수·비율·연결·세부 표현을 **정량 채점** → 연령 규준 대조로 발달 수준 추정.
- 채점자 간 신뢰도 높게 유지 가능, WISC 지능과 유의 상관 보고.
- ⚠ 단, **한국 최신 규준 부재로 실제 IQ 산출은 타당하지 않음** → "연령 대비 전형적/지연 가능성/고급" 정도로만 분류.

### (b) 정서 지표 (Koppitz emotional indicators / Machover) — 근거수준 **약~중**
- 크기·필압·부위 강조·생략으로 자존감·불안·공격성 추론.
- ⚠ 개별 정서지표의 **진단적 타당도 낮고 판별오차 큼.** 비전문가 채점 시 특히 저하.
- 단, **DAP:SPED**(구조화 선별도구)는 CBCL과 준거타당도(정확도 65~70%, α .83) — **집단 선별엔 유용, 개인 진단엔 부적절.**

### 관찰요소 → 가설 → 근거수준

| 관찰요소 | 가설 | 발달 | 정서 |
|---------|------|:---:|:---:|
| 신체부위 유무·수 | 발달=시각운동통합·지적성숙 / 임상=발달지연·신체상 미성숙 | 중~강 | 약 |
| 비율·연결 정확성 | 극단 왜곡·분절=발달장애·심한 불안 가능성 | 중 | 약 |
| 세부 표현 | 주의집중·시각기억 / 극단 과다·빈약=불안·집착 가설 | 중 | 약 |
| 부위 생략(목·손·입) | 목=충동통제 어려움 / 손=통제감 부족·억제 / 입=표현 억제 | 약~중 | 약 |
| 그림 크기 | 작음=위축·자존감 저하 / 큼=자기중심·충동 | — | 약 |
| 필압·선의 질 | 강함=긴장·공격 / 약함·끊김=위축·불안 | — | 약 |
| 표정·감정기호(눈물·상처) | 노골적 상징=현재 정서·대인 경험 반영 가능성 | — | 약~중 |

### 연령 유의
- 3세: '올챙이 사람'(머리-다리 도식) 정상. / 4~5세: 몸통·사지 분리. / 6~9세: 세부·비율 급증, 지능과 상관. / 10세~: 미술 스타일·흥미 개입 커 지능과 단선 연결 금지, 발달지연 추정은 주로 9세 이전에 의미.

## 3. 자유화 · 확장검사 (PITR 등)

### 3-1. PITR (빗속의 사람) — 스트레스 vs 대처자원

| 관찰요소 | 가설 | 근거수준 |
|---------|------|:-------:|
| 빗줄기 양·굵기 | 많고 굵음=스트레스 크거나 민감 / 거의 없음=둔감·회피 | 중 |
| 먹구름·번개·웅덩이 수·크기 | 위협·불안 요인 다수 지각 (스트레스 채점 14항목 포함) | 중 |
| 우산 유무·크기 | 있음=대처자원 / 과대=과도한 방어 / 작음=자원 있으나 효과 부족 | 약~중 |
| 비옷·장화·건물 등 보호물 | 풍부=활용 가능한 내·외적 자원 / 없음=자원 부족 | 약~중 |
| 인물-비 상호작용 | 우산 없이 맞음=과다 노출·대처 실패·체념 / 충분히 피함=자기보호 | 약~중 |
| 표정·자세 | 밝음·단호=능동적 대처 / 무표정·처짐=억제·취약·우울 | 약~중 |

> PITR 스트레스 총점은 **참고치**로만. 채점 표준화 진행 중이나 아동 임상 적용엔 제한.

### 3-2. 자유화 일반

| 요소 | 읽을 수 있는 정보 | 근거수준 |
|------|-----------------|:-------:|
| 주제 선택(반복 대상) | 정서적으로 중요한 대상·이슈 / 공격·파괴 반복=공격성·불안 표상 가능성 | 약~중 |
| 공간 구성·위치·여백 | 중앙·큼=자기존재감 / 구석·작음=위축 / 여백 과다=불안·표현 최소화 | 약 |
| 필압·선의 질 | 강함=긴장·공격 / 약함=위축 / 잦은 지움=결정 어려움·자기검열 | 약 |
| 전체 구성 붕괴 | 극단 왜곡=인지·지각 문제·혼란 가설 (발달 고려 필수) | 약~중 |

### 3-3. ⚠ 색채 심리 — 단정 위험 (엔진에서 낮은 신뢰도 처리)
- 색의 정서적 의미는 **문화·개인차가 매우 큼**(같은 빨강도 길상 vs 위험). "파랑=우울, 빨강=분노" 도식 해석 금지.
- 색채심리 실증 연구는 **초기 단계** → 색은 **핵심 지표가 아닌 참고 수준.** "이 색을 왜 골랐나?" 질문으로 개인 의미 확인 후에만 가설.

## 4. 4종 종합 — 타당도 한계 (공통)

- 투사 그림검사 전반은 **타당도·신뢰도가 대체로 낮음.** 단독 진단 도구 아님.
- 자유화는 주제·매체 자유로 **표준화 채점·타당도 검증 부족** → 탐색적·서술적 수준 유지.
- 평가자 주관성 큼 → AI의 규칙 기반 해석도 여전히 "가설"임을 명시.
- **메타규칙(전 출력 자동 부착)**: ①가설 언어("~일 가능성") ②단일 지표 진단 금지 ③문화·개인차 질문 ④연령 기준 내 해석 ⑤타 검사·면담 통합 필요.
