# 컨설팅 앱 이름·목표별 안내 변경

2026-11-01 원장 요청의 최종 표시 이름: **영재원 대비 삼육중 화산중 영선중 용정중 컨설팅 앱웹**.

## 변경 범위

- `haru/v2/build.mjs` 및 공개 HTML 4개: 제목·브랜드·설명, 영재원/삼육중/화산중/영선중/용정중의 5개 홈 섹션과 개별 메뉴. 화산·영선·용정은 기존 `middle-schools/#hs`, `#ys`, `#yj` 상세로 직접 연결한다. 기존 학교 비교 화면과 다른 지역 안내는 유지한다.
- `haru/index.html`, `parent.html`, `guide.html`, `manifest.webmanifest`: 학생·보호자·기존 안내·설치 이름 통일. 로그인 전·학생 샘플·보호자의 준비 안내는 컨설팅 홈 `/haru/v2/`로 연결하며 기존 `/haru/guide.html` 주소도 유지한다. 긴 이름은 줄바꿈하고, 320px에서 기존 학습 카드 문장으로 생기는 가로 넘침도 보완했다.
- `reading-server/haru-staff.html`, `public/haru-admin.html`, `haru-staff-server.mjs`: 개인 로그인·관리 화면·MCP 도구 설명의 표시 이름만 변경한다. 인증·MCP 도구 이름·권한·API 응답 모양은 그대로다.
- `haru/v2/public.test.cjs`, `haru/guide.test.cjs`, `reading-server/sec-headers.test.mjs`: 새 이름·5개 진입점·설치 경로·컨설팅 안내 링크·서버의 안내 본문 검사를 맞췄다. `haru/AGENTS.md`에 현재 표시 이름과 인수인계 경계를 남겼다.

## 기존 기능과 승인 경계

최신 main `eb45ebc`에서 새 브랜치 `codex/haru-name-sections-20261101`를 만들었다. 미머지 PR #507의 광주 공식 정보 보완은 별도이며 이번 변경이 해당 PR을 승인·머지한 것은 아니다. 두 PR을 합칠 때 빌더 변경을 모두 보존하고 `node haru/v2/build.mjs`로 HTML을 다시 생성한다.

학습실은 기존 삼육중 학습용이다. 영재원·다른 학교의 학습 MVP나 새 상담 접수·결과 저장·합격 판정 기능을 추가하지 않는다. 학생/보호자 경로·학습·채점·인증·KV·데이터 계약·서비스 워커 처리 경계는 유지한다. 수업 시간·횟수·수강료·담당자·개설·배부·기록 수집 조건은 미정이다. 원장 승인 전 main 푸시·운영 배포·머지는 하지 않는다.
