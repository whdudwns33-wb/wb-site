## 원칙

1. **AI 리서치 도구(퍼플렉시티)는 스카우트, 원료가 아니다.** 스캔 결과의 요약문을 지문에 옮겨 쓰지 않는다. 지문은 항상 확인된 '사실'만으로 새로 쓴다.
2. **자동 루틴의 산출물은 draft까지.** `status: "published"` 전환(학생 노출)은 반드시 강사가 review.html 검수 후 수동으로 한다.
3. **신뢰도 등급을 남긴다.** A = 공식 출처(정부·공공·연구기관) 확인 / B = 2차 보도만 확인 → B는 검수 시 공식 출처 재확인 필수.
4. **금지 소재**: 정치 쟁점 편들기, 선거, 특정 상품 홍보, 공포 조장, 미확정 의학 정보, 진행 중 수사·재판.

## 도구 역할 분담

- **퍼플렉시티 (자동, 주간)**: 소재 스캔·사실 교차 확인. API/MCP로 자동화 가능한 유일한 축.
- **제미나이 딥리서치 (수동, 월간)**: 편성회의 전 심층 기획 1~2주제 (예: 계열별 유망 탐구 주제). API 자동화 불가 → 사람이 실행해 결과를 편성회의에 지참.
- **공공누리 1유형·공개 논문**: 지문 본문의 저작권 안전 원료 (기획서 §5.1).

## 수동 개입 지점

- selected 선정에 이견이 있으면 큐 파일의 `status`를 직접 수정 후 "소재 큐 반영해서 집필해줘"라고 요청.
- 루틴 중지: "주간 소재 스캔 루틴 중지해줘" (Routine 삭제).
- 발행 승인: 검수 후 "queue 신규 지문 발행해줘" 또는 직접 status 수정.

## 검수 부담에 관한 안전장치

주 4~5편 체제에서도 학생 노출은 강사의 발행 버튼(review.html)으로만 일어난다. 검수가 밀리면 draft가 쌓일 뿐 학생 화면은 변하지 않으므로, 밀린 주에는 편한 속도로 골라 발행하면 된다. 검수 없이 발행하지 않는 원칙은 유지.
