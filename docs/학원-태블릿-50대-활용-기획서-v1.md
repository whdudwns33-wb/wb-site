## 0. 결론 먼저

**50대를 한 덩어리로 보면 실패합니다.** 갤럭시탭 Advanced2와 Tab A7은 출시가 2년 차이지만 소프트웨어로는 **세대가 갈립니다**. 같은 용도로 굴리려는 순간 "왜 저 탭만 앱이 안 깔리지"에서 프로젝트가 멈춥니다.

| 결론 | 내용 |
|---|---|
| **Tab A7** (Android 12) | **학습 단말**. 클래스카드·스터디포스·리드인·메타수학 등 실제 온라인 프로그램 구동 |
| **Advanced2** (Android 8) | **단일 목적 단말**. 앱 1개만 띄우고 고정 — 설문 키오스크, 녹음, 필기, 사이니지 |
| **공통** | 태블릿 자체가 성과를 내지 않습니다. **기존 시스템(클래스카드·Fillout·업무지시서 앱)의 "미수행 구멍"을 메우는 도구**로만 씁니다 |

가장 큰 기대효과 한 줄: **집에서 안 하는 온라인 프로그램을 원내에서 끝내게 만드는 것.** 지금 학원의 최대 누수 지점이고, 태블릿은 정확히 그 문제의 해법입니다.

## 1. 하드웨어 실사 — 기획의 전제

### 1.1 기종별 사실관계

| 항목 | **갤럭시탭 Advanced2** (SM-T583) | **갤럭시탭 A7** (SM-T500/T505) |
|---|---|---|
| 출시 | 2018년 하반기 | 2020년 9월 |
| 최초 OS | Android 8.0 Oreo | Android 10 |
| **최종 OS** | **Android 8.0 — 메이저 업데이트 0회** | **Android 12 (One UI Core 4.1)** |
| 보안 패치 | 사실상 종료 | 2024년경 종료 |
| AP | Exynos 7870 (2016년, A53 8코어) | Snapdragon 662 |
| RAM | 3GB | 3GB |
| 화면 | 10.1" 1280×800 | 10.4" 2000×1200 |
| **S펜** | **지원 ✅** | 미지원 ❌ |
| 유통 형태 | B2B 교육용 (엠베스트 인강 단말로 다량 유통) | 일반 리테일 |

### 1.2 이 사실이 만드는 제약

**Advanced2 = Android 8**이라는 게 핵심입니다.

- 최신 크롬이 Android 8/9 지원을 종료했습니다. 브라우저 기반 최신 웹앱은 **깨지거나 아예 안 열립니다.**
- 플레이스토어 신규 앱 상당수가 Android 9 이상을 요구합니다. **클래스카드·스터디포스 등 학습앱이 설치조차 안 될 가능성이 높습니다.**
- Exynos 7870 + 3GB는 무거운 웹앱을 감당하지 못합니다. 켜지는 것과 쓸 만한 것은 다릅니다.
- **엠베스트 B2B 물량이면 전용 런처가 잠겨 있을 수 있습니다.** 일반 초기화로 안 풀리고, 엠베스트 학습지원센터(1544-2300) 경유 절차가 필요합니다. → **W0 실사에서 1대로 반드시 먼저 확인**

**반대로 Advanced2의 유일한 우위가 S펜입니다.** A7에는 없습니다. 필기·그리기가 필요한 활동은 오히려 Advanced2 쪽이 맞습니다. 구형이라 버리는 게 아니라, **"쓰기 전용기"로 포지션을 바꿉니다.**

> ⚠️ 수량 가정: Advanced2 약 35대 / A7 약 15대로 가정하고 작성했습니다. W0 실사에서 확정하세요. 비율이 뒤집히면 2장 배치를 조정해야 합니다.

## 2. 배치 전략 — 3개 티어

```
Tier A  Tab A7 (~15대)        → 학습 단말      : 온라인 프로그램 구동
Tier B  Advanced2 (~30대)     → 단일 목적 단말  : 앱 1개 고정
Tier C  불량/잉여 (~5대)       → 즉시 격리      : 배터리 부풀음·충전 불가
```

**Tier C를 먼저 걸러내세요.** 2018년 배터리는 부풀어 있을 확률이 높고, 부푼 리튬 배터리를 아이들 공간에 두는 건 안전 문제입니다. 실사 항목 1번입니다.

## 3. 활용 아이디어 — 우선순위 순

각 항목은 **① 무엇을 ② 어느 기기로 ③ 기존 시스템 어디에 붙는지 ④ 왜 지금** 순서로 정리했습니다.

### 🥇 1순위 — 원내 온라인 프로그램 학습존

| | |
|---|---|
| **무엇** | 수업 시작 전/후 15분, 클래스카드 단어 테스트·스터디포스를 **집이 아니라 원내에서** 끝냄 |
| **기기** | Tier A (A7) 10~12대 |
| **연결** | 클래스카드 수행상태 · 스터디포스 구독생 관리 · 플래너 이월 후보 |
| **왜 지금** | 지금 가장 큰 누수가 **"집에서 안 함 → 미수행 이월 → 다음 주에도 안 함"** 루프입니다. 이걸 끊는 가장 확실한 방법이 원내 수행이고, 태블릿은 정확히 이 용도의 도구입니다 |

**운영 방식**
- 학습존 존치형(고정 자리 8~10석) — 반출하지 않음. 분실·파손 리스크가 0에 가까워집니다.
- 수업 전 10분 = "단어 존", 수업 후 10분 = "미완료 존"
- 선생님은 완료 여부만 보면 됨 → **업무지시서 앱 단계 체크에 그대로 연결**

**기대 효과 (측정 가능)**
- 클래스카드 주간 수행률 (현재 값 → 목표 90%)
- 미수행 이월 건수 (주 단위 감소 추이)

### 🥈 2순위 — 대기실 문진·설문 키오스크

| | |
|---|---|
| **무엇** | 검사 전 보호자 문진, 상담 만족도, 동의서, 재원생 설문을 **종이 대신 태블릿 Fillout 폼**으로 |
| **기기** | Tier B (Advanced2) 2~3대 — 브라우저로 폼 1개만 띄우므로 구형도 가능 |
| **연결** | Fillout 응답 자동 수집 → 상담 자료 5종 점검 |
| **왜 지금** | 종이 문진의 진짜 비용은 종이가 아니라 **전사(轉寫) 노동**입니다. 손으로 받아서 손으로 옮겨 적는 시간이 매주 쌓입니다. 폼 링크만 띄우면 그 작업이 통째로 사라집니다 |

**주의**: 키오스크 모드(다른 앱 못 열게 고정) 필수. Android 8에서도 삼성 Knox 또는 무료 키오스크 런처로 가능합니다.

### 🥉 3순위 — 낭독 유창성 측정 스테이션 ⭐ 차별화 포인트

| | |
|---|---|
| **무엇** | 학생이 지문을 소리 내어 읽고 **녹음** → 분당 읽은 어절 수(WPM)·정확도 → 월간 학부모 리포트에 **그래프로** |
| **기기** | Tier B (Advanced2) 4~6대 + 헤드셋(마이크 일체형) |
| **연결** | 의미 단위 끊어 읽기 워크북 · 학생 리포트 · 학부모 커뮤니케이션 |
| **왜 지금** | **독해력 학원인데 "읽기"를 숫자로 보여주는 학원은 거의 없습니다.** 녹음은 구형 태블릿에서도 100% 돌아가는 몇 안 되는 기능이고, "3월 92어절 → 8월 128어절" 한 장이면 학부모 상담의 무기가 됩니다 |

**단계별로**
1. (1개월) 녹음만 — 파일 저장, 선생님이 듣고 수기 채점
2. (2~3개월) 지문별 기준 어절 수 표 만들기 → WPM 자동 계산
3. (이후) 리포트 자동 삽입

> 처음부터 자동화하지 마세요. 1단계 녹음만으로도 학부모 반응이 나옵니다.

### 4순위 — 인지 훈련 스테이션 (웩슬러 연계)

| | |
|---|---|
| **무엇** | 처리속도·작업기억 훈련 활동지의 태블릿 버전. **S펜으로 직접 쓰기** |
| **기기** | Tier B (Advanced2) 4~6대 — **S펜이 있는 유일한 기종** |
| **연결** | 웩슬러 연계 인지 활동지 저작 |
| **왜 지금** | 처리속도 훈련은 본질이 "타이머 + 반복"이라 구형 하드웨어로 충분합니다. 검사받은 아동에게 **"검사만 하고 끝"이 아니라 훈련까지 이어지는 센터**라는 포지션이 만들어집니다 |

> ⚠️ **검사 문항 자체를 태블릿에 옮기지 마세요.** K-WISC 문항은 검사 보안 대상입니다. 훈련용 창작 활동지만 올립니다.

### 5순위 — 상담·레벨테스트 단말

| | |
|---|---|
| **무엇** | 상담실에서 보호자에게 커리큘럼·샘플 리포트를 태블릿으로 보여주고, 그 자리에서 아이 레벨테스트 |
| **기기** | Tier A (A7) 2대 — 화질 차이(2000×1200 vs 1280×800)가 체감되는 유일한 용도 |
| **왜 지금** | 상담 테이블에 종이 뭉치 대신 태블릿 한 대가 놓이면 그 자체로 "체계 있는 학원"으로 읽힙니다. **A7의 좋은 화면을 여기 쓰세요** |

### 6순위 — 학습지·숙제 촬영대

| | |
|---|---|
| **무엇** | 손으로 푼 학습지를 태블릿으로 촬영 → 업무지시서 앱 기록에 첨부 |
| **기기** | Tier B 1~2대 (거치대 필요) |
| **왜** | "숙제 했다"의 증거가 남습니다. 학부모 문의 시 근거가 됩니다 |

### 7순위 — 디지털 사이니지 / 시간표 보드

| | |

## 5. 인프라 체크리스트 — 여기서 성패가 갈립니다

아이디어보다 이쪽이 더 자주 프로젝트를 죽입니다.

| 항목 | 확인할 것 | 기준 |
|---|---|---|
| **WiFi** | AP 대수·모델·주파수 | **AP 1대당 동시 25~30대가 현실 한계.** 학습존 10~12대면 전용 AP 1대. 5GHz 우선, 채널 겹침 확인 |
| **전원** | 동시 충전 구수 | 50구 충전 카트는 고가 → **10구 멀티탭 5세트 + 전용 선반**으로 시작 |
| **보관** | 학습존 존치 vs 회수 | 존치형 권장. 회수형이면 번호 지정 슬롯 필수 |
| **잠금** | 키오스크 모드 수단 | 삼성 Knox는 Android 8 지원. 무료 키오스크 런처도 가능 |
| **계정** | 프로그램별 계정 정책 | 반별 공용 구글 계정 5개 + 클래스카드만 학생 개인 |
| **자산** | 라벨·대장 | 일련번호 스티커 부착 + 구글시트 대장 (기종/상태/배치/담당) |
| **규정** | 파손·분실 | 원내 존치면 학생 책임 규정 불필요 — **이것도 존치형의 장점** |

## 6. 4주 파일럿 플랜

| 주차 | 할 일 | 완료 기준 |
|---|---|---|

| **W2** | Advanced2 2대 대기실 Fillout 키오스크 | 종이 문진 0건 달성 |
| **W3** | Advanced2 5대 낭독 녹음 시범, 헤드셋 구매 | 학생 10명 녹음 확보, WPM 수기 산출 |

**W4 판단 기준**
- 학습존: 파일럿 반 클래스카드 수행률이 **20%p 이상** 올랐는가 → Yes면 전 반 확대
- 키오스크: 전사 작업이 실제로 사라졌는가 → Yes면 3대로
- 낭독: 학부모 반응이 있었는가 → Yes면 리포트 자동화 착수

### ② WiFi 실측

학습존 예정 자리에서 스마트폰으로 속도 측정 → AP 모델명·대수 확인. **AP가 1대뿐이면 태블릿 10대는 그 자체로 무리입니다.** 이건 태블릿 세팅보다 먼저 확인해야 합니다.

### ③ 학습존 자리 정하기

기존 교실을 쓰지 말고 **대기 공간·복도 끝 등 죽은 공간**에 8~10석. 수업 공간을 줄이면 안 됩니다.
