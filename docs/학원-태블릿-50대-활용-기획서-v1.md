# 학원 태블릿 50대 활용 기획서

> WB 독해력학원 · 웩슬러브레인센터 | 보유 태블릿 약 50대 재배치 계획
> 문서 버전 v2.0 · 작성일 2026-08-09
> v2 변경 — **Tab A7 15대를 교사 전용으로 확정**, 학생 학습존을 Advanced2 웹 기반으로 이관. Android 8 브라우저 제약 서술 정정.

## 0. 결론 먼저

**50대를 한 덩어리로 보면 실패합니다.** Advanced2와 Tab A7은 출시가 2년 차이지만 소프트웨어로는 **세대가 갈립니다.**

이번 판(v2)의 결정: **좋은 기기(A7 15대)는 학생이 아니라 선생님에게 갑니다.**

| 배치 | 기기 | 대수 | 역할 |
|---|---|---|---|
| **Tier T — 교사** | Tab A7 | **15** | 업무지시서 앱 상시 거치, 학부모 피드백·연락 기록, 수업 자료 제시 |
| **Tier S — 학생 학습존** | Advanced2 | 10~12 | 원내 온라인 프로그램 수행 (**브라우저 경유**) |
| **Tier B — 단일 목적** | Advanced2 | 15~18 | 설문 키오스크 · 낭독 녹음 · S펜 필기 · 사이니지 |
| **Tier C — 격리** | 혼재 | ~5 | 배터리 부풀음 · 충전 불가 · 파손 |

**A7을 교사에게 주는 것이 옳은 판단인 이유** — 선생님은 이 기기를 매일, 몇 년간 씁니다. Advanced2는 크롬이 138에서 **영구 동결**되어 시간이 갈수록 웹앱 호환이 무너집니다. 상시 업무용으로는 부적합합니다. 반대로 학생 학습존은 정해진 사이트 몇 개만 쓰고, 안 되면 그때 바꾸면 됩니다. **수명이 필요한 쪽에 수명이 있는 기기를 배치합니다.**

가장 큰 기대효과 두 줄:
- **교사** — 지금 폰으로 하는 출결·단계 체크·피드백 문구를 태블릿 거치대에서. 수업 흐름을 끊지 않고 기록이 남습니다.
- **학생** — 집에서 안 하는 온라인 프로그램을 원내에서 끝냅니다. 지금 학원의 최대 누수 지점입니다.

## 1. 하드웨어 실사 — 기획의 전제

### 1.1 기종별 사실관계

| 항목 | **갤럭시탭 Advanced2** (SM-T583) | **갤럭시탭 A7** (SM-T500/T505) |
|---|---|---|
| 출시 | 2018년 하반기 | 2020년 9월 |
| 최초 OS | Android 8.0 Oreo | Android 10 |
| **최종 OS** | **Android 8.0 — 메이저 업데이트 0회** | **Android 12 (One UI Core 4.1)** |
| **크롬 상한** | **138에서 영구 동결** (2025.08~) | 최신 버전 계속 수신 |
| 보안 패치 | 사실상 종료 | 2024년경 종료 |
| AP | Exynos 7870 (2016년, A53 8코어) | Snapdragon 662 |
| RAM | 3GB | 3GB |
| 화면 | 10.1" 1280×800 | 10.4" 2000×1200 |
| **S펜** | **지원 ✅** | 미지원 ❌ |
| 유통 형태 | B2B 교육용 (엠베스트 인강 단말로 다량 유통) | 일반 리테일 |

### 1.2 Advanced2의 진짜 제약 — 정정

> ⚠️ **v1에서 "브라우저 기반 최신 웹앱은 깨지거나 아예 안 열린다"고 썼던 것을 정정합니다.** 과한 서술이었습니다.

구글은 **Chrome 138을 Android 8·9의 마지막 버전**으로 공지했고, Chrome 139부터 Android 10 이상을 요구합니다. 그런데 **Chrome 138은 2025년 6월 빌드로 사실상 현대 브라우저**입니다. 최신 자바스크립트와 웹 API를 폭넓게 지원합니다.

따라서 Advanced2의 실제 제약은 이렇게 정리됩니다.

| 구분 | 판정 | 설명 |
|---|---|---|
| **웹앱 (브라우저)** | ⭕ **대체로 가능** | 업무지시서 앱, Fillout 폼, 클래스카드 웹 등. **단 크롬을 138로 업데이트해 두어야 함** |
| **네이티브 앱 설치** | ❌ **상당수 불가** | 플레이스토어 신규 앱 다수가 Android 9 이상 요구. 학습앱 설치 실패 가능성 높음 |
| **장기 사용** | ⚠️ **부적합** | 크롬이 138에서 동결 → 보안 패치 없음, 시간이 갈수록 웹 호환 붕괴 |
| **성능** | ⚠️ **제한적** | Exynos 7870 + 3GB. 켜지는 것과 쓸 만한 것은 다릅니다 |

**이 정정이 계획을 바꿉니다.** 웹으로 되는 게 확인되면 학생 학습존을 Advanced2로 옮길 수 있고, 그래야 A7 15대를 온전히 선생님께 드릴 수 있습니다. → **W1의 최우선 검증 항목**(§6)

### 1.3 그 외 확인 사항

- Advanced2가 **엠베스트 B2B 물량이면 전용 런처가 잠겨 있을 수 있습니다.** 일반 초기화로 안 풀리고, 엠베스트 학습지원센터(1544-2300) 경유 절차가 필요합니다.
- **Advanced2의 유일한 우위가 S펜입니다.** A7에는 없습니다. 필기·그리기 활동은 오히려 Advanced2가 맞습니다.

> 수량 가정: Advanced2 약 35대 / A7 약 15대. W0 실사에서 확정하세요. **A7이 15대에 못 미치면 교사 배치(§2)를 우선 채우고 학습존을 줄입니다.**

## 2. 교사용 15대 — 배치와 활용 ⭐ v2 신규

### 2.1 전제: 선생님은 6명입니다

로스터 기준 담당 선생님 6명, 학생 35명입니다.

| 선생님 | 담당 학생 |
|---|---|
| 김남기 | 15명 |
| 최인찬 | 12명 |
| 정다원 | 7명 |
| 공현정 | 6명 |
| 김동현 | 4명 |
| 김혜지 (관리자) | 1명 |

**15대는 1인 1대의 2.5배입니다.** 그러니 "선생님 1인당 1대"로 끝내면 9대가 놀게 됩니다. 사람이 아니라 **자리 기준**으로 배치하는 게 맞습니다.

### 2.2 15대 배분안

| 용도 | 대수 | 배치 방식 | 핵심 기능 |
|---|---|---|---|
| **담임 전담** | **6** | 선생님 이름 라벨, 개인 귀속 | 업무지시서 앱 (개인 링크 저장) |
| **강의실 거치** | **4** | 교실별 교탁 거치대 고정 | 수업 지시서 조회 · 출결 · 자료 제시 |
| **상담실** | **2** | 상담 테이블 | 커리큘럼·리포트 제시, 레벨테스트 |
| **데스크·행정** | **1** | 카운터 | 등하원 확인, mini 관제 조회 |
| **예비 · 충전 로테이션** | **2** | 충전 선반 | 배터리 소진 시 즉시 교체 |
| **합계** | **15** | | |

> 예비 2대는 사치가 아닙니다. 태블릿 배터리는 4~5시간이면 바닥나는데, 수업 중 충전하러 가면 그 순간 기록이 끊깁니다. **교체용 2대가 운영을 살립니다.**

### 2.3 담임 전담 6대 — 무엇을 하나

직원 가이드북의 하루 흐름을 그대로 태블릿으로 옮깁니다.

| 시점 | 하는 일 | 지금(폰) | 태블릿에서 달라지는 것 |
|---|---|---|---|
| 출근 | `[출근했습니다]` + 오늘 업무 확인 | 폰으로 확인 | 거치대에 세워두고 하루 종일 열려 있음 |
| 수업 중 | 진도·지도법·목표 확인 | 폰 화면이 좁아 스크롤 반복 | **지시서 전문이 한 화면에** |
| 수업 중/직후 | 출결 · 단계 체크 · 메모 | 폰 꺼내기가 어색 → 나중에 몰아서 | **그 자리에서 즉시** — 기록 누락이 줄어듭니다 |
| 수업 후 | 학부모 피드백 문구 생성 → 복사 | 좁은 화면에서 수정 어려움 | **보기 3개 선택 + 수정이 편함** |
| 상시 | `[📞 기록]` 학부모 연락 | 10초짜리 작업인데 폰을 꺼내야 함 | 탭 한 번 |
| 주간 | `⚠️ 관심 필요` 학생 확인 | 잘 안 보게 됨 | 큰 화면이라 **실제로 보게 됩니다** |
| 필요 시 | 교재 진도 · 재고 부족 시 `[🛒 주문]` | | 목차 조회가 편함 |

**핵심은 "기록 시점을 당기는 것"입니다.** 지금은 폰이라 수업 끝나고 몰아서 쓰게 되고, 몰아서 쓰면 기억이 흐려지고 빠집니다. 교탁에 태블릿이 열려 있으면 수업 중에 바로 남습니다.

### 2.4 ⚠️ 개인 링크 정책 — 반드시 지켜야 할 선

직원 가이드북 **절대규칙 3번: "개인 링크는 개인 것. 공유 금지."** 태블릿을 공용으로 쓰는 순간 이 규칙이 무너집니다.

| 기기 | 개인 링크 | 규칙 |
|---|---|---|
| **담임 전담 6대** | ⭕ 저장 허용 | 기기에 **이름 라벨** 부착, 브라우저 홈 화면에 본인 링크 추가, 화면 잠금 설정 |
| **강의실 거치 4대** | ❌ **저장 금지** | 개인 링크 로그인 금지. 조회 전용(mini·교재)만. 출결 입력이 필요하면 본인 전담 기기로 |
| **상담실 2대 · 데스크 1대** | ❌ 저장 금지 | 시연·조회 전용 |

> 이 구분이 애매하면 결국 "아무 태블릿이나 집어서 내 링크로 로그인"이 됩니다. **라벨과 화면 잠금 두 가지로 물리적으로 구분하세요.**

### 2.5 강의실 거치 4대의 별도 쓰임

거치형은 개인 링크를 안 쓰는 대신 이런 일을 합니다.

- **수업 자료 제시** — 지문·도표를 확대해서 학생에게 보여주기. A7의 2000×1200 화면이 여기서 값을 합니다
- **mini 관제 조회** — 시간표·강의실 충돌 확인 (기록 없이 조회만)
- **낭독 녹음 감독** — §4의 낭독 스테이션과 연계, 선생님이 즉석에서 재생·청취
- **타이머 · 스톱워치** — 시간 제한 독해 훈련

## 3. 전체 배치 전략 — 4개 티어

```
Tier T  Tab A7      15대   → 교사 단말      : 업무지시서 앱 · 자료 제시 · 상담
Tier S  Advanced2   10~12대 → 학생 학습존    : 브라우저로 온라인 프로그램 수행
Tier B  Advanced2   15~18대 → 단일 목적 단말 : 앱 1개 고정
Tier C  혼재         ~5대   → 즉시 격리      : 배터리 부풀음 · 충전 불가
```

**Tier C를 먼저 걸러내세요.** 2018년 배터리는 부풀어 있을 확률이 높고, 부푼 리튬 배터리를 아이들 공간에 두는 건 안전 문제입니다. 실사 항목 1번입니다.

## 4. 학생용 활용 아이디어 — 우선순위 순

### 🥇 1순위 — 원내 온라인 프로그램 학습존 (Tier S)

| | |
|---|---|
| **무엇** | 수업 시작 전/후 15분, 클래스카드 단어 테스트·스터디포스를 **집이 아니라 원내에서** 끝냄 |
| **기기** | **Advanced2 10~12대 — 브라우저 경유** (v2 변경: A7 → Advanced2) |
| **연결** | 클래스카드 수행상태 · 스터디포스 구독생 관리 · 플래너 이월 후보 |
| **왜 지금** | 지금 가장 큰 누수가 **"집에서 안 함 → 미수행 이월 → 다음 주에도 안 함"** 루프입니다. 이걸 끊는 가장 확실한 방법이 원내 수행입니다 |

**⚠️ 선결 조건 — W1에서 반드시 실측**

Advanced2로 옮긴 이상, 아래가 실제로 되는지 확인 전에는 10대를 세팅하지 마세요.

1. Advanced2 1대에 **크롬을 138로 업데이트**
2. 클래스카드 **웹(브라우저)** 로그인 → 단어 세트 1개를 **끝까지 수행**
3. 스터디포스·리드인·메타수학도 같은 방식으로 1개씩
4. 소요 시간·버벅임·중간 튕김 기록

| 결과 | 다음 수순 |
|---|---|
| 전부 정상 | Advanced2 10대 세팅, 계획대로 진행 |
| 일부만 정상 | 되는 프로그램만 학습존 운영, 나머지는 기존 방식 유지 |
| 대부분 실패 | **A7 예비 2대 + 강의실 거치 일부를 학습존으로 전환**하고 교사 배분을 재조정 |

**운영 방식**
- 존치형(고정 자리 8~10석) — 반출하지 않음. 분실·파손 리스크가 0에 가까워집니다
- 수업 전 10분 "단어 존", 수업 후 10분 "미완료 존"
- 선생님은 완료 여부만 확인 → **본인 전담 태블릿의 업무지시서 앱 단계 체크로 연결**

**측정 지표** — 클래스카드 주간 수행률(목표 90%), 미수행 이월 건수 추이

### 🥈 2순위 — 대기실 문진·설문 키오스크 (Tier B)

| | |
|---|---|
| **무엇** | 검사 전 보호자 문진, 상담 만족도, 동의서, 재원생 설문을 **종이 대신 Fillout 폼**으로 |
| **기기** | Advanced2 2~3대 — 폼 1개만 띄우므로 크롬 138로 충분 |
| **연결** | Fillout 응답 자동 수집 → 상담 자료 5종 점검 |
| **왜 지금** | 종이 문진의 진짜 비용은 종이가 아니라 **전사(轉寫) 노동**입니다. 손으로 받아서 손으로 옮겨 적는 시간이 매주 쌓입니다 |

키오스크 모드(다른 앱 못 열게 고정) 필수. Android 8에서도 삼성 Knox 또는 무료 키오스크 런처로 가능합니다.

### 🥉 3순위 — 낭독 유창성 측정 스테이션 (Tier B) ⭐ 차별화 포인트

| | |
|---|---|
| **무엇** | 학생이 지문을 소리 내어 읽고 **녹음** → 분당 어절 수(WPM)·정확도 → 월간 학부모 리포트에 **그래프로** |
| **기기** | Advanced2 4~6대 + 헤드셋(마이크 일체형) |
| **연결** | 의미 단위 끊어 읽기 워크북 · 학생 리포트 · 학부모 커뮤니케이션 |
| **왜 지금** | **독해력 학원인데 "읽기"를 숫자로 보여주는 학원은 거의 없습니다.** 녹음은 구형 태블릿에서 100% 돌아가는 몇 안 되는 기능이고, "3월 92어절 → 8월 128어절" 한 장이면 학부모 상담의 무기가 됩니다 |

**단계별로**
1. (1개월) 녹음만 — 선생님이 **강의실 거치 태블릿으로 즉석 청취**, 수기 채점
2. (2~3개월) 지문별 기준 어절 수 표 → WPM 자동 계산
3. (이후) 리포트 자동 삽입

> 처음부터 자동화하지 마세요. 1단계만으로도 학부모 반응이 나옵니다.

### 4순위 — 인지 훈련 스테이션 (Tier B · S펜)

| | |
|---|---|
| **무엇** | 처리속도·작업기억 훈련 활동지의 태블릿 버전. **S펜으로 직접 쓰기** |
| **기기** | Advanced2 4~6대 — **S펜이 있는 유일한 기종** |
| **연결** | 웩슬러 연계 인지 활동지 저작 |
| **왜 지금** | 처리속도 훈련의 본질은 "타이머 + 반복"이라 구형 하드웨어로 충분합니다. 검사받은 아동에게 **검사만 하고 끝이 아니라 훈련까지 이어지는 센터**라는 포지션이 만들어집니다 |

> ⚠️ **K-WISC 문항 자체를 태블릿에 옮기지 마세요.** 검사 보안 대상입니다. 훈련용 창작 활동지만 올립니다.

### 5순위 — 학습지·숙제 촬영대 (Tier B)

손으로 푼 학습지를 촬영 → 업무지시서 앱 기록에 첨부. 거치대 1~2대. "숙제 했다"의 증거가 남아 학부모 문의 시 근거가 됩니다.

### 6순위 — 디지털 사이니지 / 시간표 보드 (Tier B)

벽걸이 고정, 오늘 시간표·공지 상시 표출. 잉여분 2~3대. **남는 기기 소진용** — 앱 1개 상시 표출은 Android 8이 가장 잘하는 일입니다.

### 보류 — 가정 대여

원내 활용이 안정된 뒤 6개월 후 재검토. 50대 중 절반이 밖으로 나가면 파손·분실·초기화·회수 관리가 학원 업무 하나를 새로 만듭니다.

### ② WiFi 실측 — 이번엔 27대 기준

교사 15대 + 학습존 12대가 **동시에** 붙습니다. AP 1대당 25~30대가 한계이니 **AP 최소 2대**가 필요합니다. 학습존 예정 자리와 교실에서 각각 속도를 재고 AP 모델명·대수를 확인하세요. 태블릿 세팅보다 먼저입니다.

### ③ 거치대 12개 발주

교사 전담 6 + 강의실 4 + 상담실 2. 각도 조절되는 저가형으로 충분합니다. **거치대가 없으면 태블릿은 서랍으로 들어갑니다** — 이게 태블릿 도입이 실패하는 가장 흔한 이유입니다.
