## 1. 계정 일괄 발급

### ① 명단 CSV 만들기

UTF-8로 저장한다. 첫 줄은 머리글.

```
이름,학년,반
김서준,초4,화목B
이하윤,중2,월수금A
박도현,7세,토요반
```

학년에 쓸 수 있는 값: `7세 초1 초2 초3 초4 초5 초6 중1 중2 중3 고1 고2 고3`
(학년을 넣으면 읽는 글 수준이 자동으로 정해진다 — 7세~초2 / 초3~6 / 중1~3 / 고1~3)

### ② 미리보기

```
node reading-server/enroll.mjs 명단.csv --dry
```

서버에 아무것도 쓰지 않고 발급될 코드만 보여 준다. 이름·학년·반이 맞는지 확인한다.

### ③ 실제 발급

```
ADMIN_PIN=… node reading-server/enroll.mjs 명단.csv
```

`명단-발급결과.csv`가 같은 폴더에 생긴다 (이름·학년·반·학생코드·읽는글).

### ④ 확인

관리 웹 → 학생 현황판에 새 이름이 보이면 끝. 학년·반·읽는 글은 표에서 바로 고칠 수 있다.

## 1-2. 배부 — QR로 하세요

학생 코드는 이 앱의 **유일한 자격 증명**이다(비밀번호가 없다). 그래서 두 겹으로 막았다.

**① 코드를 학생에게 안 보여 준다 — QR**

관리 웹 → 학생 현황판에서 **이름 클릭** → 학생 상세 → **「앱 연동 QR」**.
학생 기기 카메라로 찍으면 앱이 열리면서 연동 요청이 걸린다. 코드를 손으로 칠 일이 없고,
종이나 카톡에 코드가 남지 않는다. 저학년일수록 이 방법이 훨씬 낫다.
(인쇄해서 나눠 줄 수도 있다 — QR 아래 「인쇄」)

**② 첫 연동은 강사가 승인해야 열린다**

학생이 코드를 넣거나 QR을 찍으면 관리 웹 맨 위에 **「연동 승인 대기」** 카드가 뜬다.
이름·코드·기기·요청 시각이 보이니 **본인이 맞는지 확인하고 승인**한다.
승인 전에는 앱이 연결되지 않으므로, 친구 코드를 알아내 찍어 봐도 소용이 없다.

- 승인은 **기기 1대에 한 번뿐**이다. 그 뒤로는 자동으로 연결된다.
- 요청은 **30분 뒤 사라진다**. 시간이 지났으면 학생이 다시 찍으면 된다.
- 본인이 아니면 **거절**을 누른다.

> 가장 매끄러운 흐름: 배부 자리에서 학생 기기로 QR을 찍게 하고, 그 자리에서 승인까지 누른다. 30초면 끝난다.

## 2. 학생용 안내문 (그대로 복사해 쓰세요)

```
📖 WB 진로독서 — 하루 한 편 읽기

1. 아래 주소를 눌러 주세요.
   https://wb-reading.whdudwns33.workers.dev/

2. 처음 한 번만: 학년 고르기 → 좋아하는 분야 고르기 → 짧은 글로 수준 확인
   (2~3분이면 끝나요)

3. 선생님이 보여 주는 QR을 카메라로 찍으면 자동으로 연결돼요.
   (직접 넣으려면: 오른쪽 위 ⚙ → '선생님 연동' → 내 코드 ____________ )
   → 선생님이 '승인'을 눌러 주시면 연결이 끝나요. 한 번만 하면 됩니다.

4. 매일 '오늘의 1지문' 한 편만 읽으면 됩니다. 5분이면 충분해요.

📱 홈 화면에 앱처럼 두기
  · 아이폰: 사파리에서 열고 아래 [공유] → '홈 화면에 추가'
  · 안드로이드: 크롬에서 열고 오른쪽 위 ⋮ → '홈 화면에 추가'

❓ 안 될 때: 위 주소가 안 열리면 아래 주소로 들어와 주세요.
   https://whdudwns33-wb.github.io/wb-reading/
```

## 4. 학부모 링크 발급

관리 웹 → 학생 현황판에서 이름 클릭 → 학생 상세 → **링크 복사**.
이미 보낸 링크를 무효화하려면 같은 자리의 **재발급**을 누른다(옛 링크는 즉시 죽는다).

링크는 읽기 전용이고 해당 학생 한 명분만 보인다. 관리 기능은 들어 있지 않다.

## 5. 자주 나오는 질문

**Q. 코드를 잊어버렸대요.**
코드를 다시 알려 주기보다 **학생 상세의 QR을 다시 찍게 하는 편**이 빠르고 안전하다.

**Q. 승인 대기 카드가 안 없어져요.**
학생이 두 번 찍었거나 요청이 겹친 것이다. 본인 것 하나만 승인하고 나머지는 거절하면 된다.
30분이 지나면 저절로 사라진다.

**Q. 모르는 이름이 승인 대기에 떴어요.**
다른 학생이 그 코드를 넣었다는 뜻이다. **거절**을 누르고, 해당 학생 코드를 새로 발급한 뒤
(학생 등록 화면에서 코드만 바꿔 저장) QR로 다시 배부한다.

**Q. 형제가 한 기기를 같이 써요.**
앱은 기기 하나에 학생 하나를 기억한다. 설정 ⚙ → 연동 해제 후 다른 코드로 연동하면
바뀌지만, 읽기 기록은 기기에도 남으므로 형제가 각자 기기를 쓰는 편이 낫다.

**Q. 소리가 안 나요.**
'들으며 읽기'는 기기의 음성 기능을 쓴다. 무음 스위치와 볼륨을 먼저 확인하고,
그래도 안 되면 '자동 읽기'(소리 없이 의미 단위로 넘겨 주는 기능)를 쓰면 된다.

**Q. 학년을 잘못 넣었어요.**
관리 웹 표에서 '읽는 글' 칸을 바꾸면 다음 접속부터 바로 반영된다.
