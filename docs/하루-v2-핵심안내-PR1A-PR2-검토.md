# 하루 v2 핵심 안내 PR-1A 보완·PR-2 검수

확인일: 2026-10-13. 사용자 지정 이름 ‘삼육중 및 영재원 대비’ 유지. 이번 결과는 **로컬 검토판**이며 운영 배포·PR 게시·실제 발송·자동 수집·학생 데이터 변경은 하지 않았다.

## 결과와 배포 검토 판정

두 핵심 섹션은 **미확인 범위를 표시하는 공개 읽기 안내로 배포 검토 가능**하다. PR-1A의 공개 정보 보완과 PR-2의 진입·상세·일정·상담·기존 링크 검수는 끝냈다. 모든 기관의 2027 최종 요강이 확정됐다는 뜻은 아니다. 키움·KAIST·전남대의 미확인 과정은 확정 후보 필터에 추가하지 않았다. 전수 명부 완료를 선언하지 않는다.

운영 배포는 하지 않았다. 기존 운영 `/haru/`·학생/보호자 링크·학습·채점 계약을 변경하지 않았으며 새 공개 홈의 `/haru/` 승격도 하지 않았다. 운영 환경의 실제 기존 SW 갱신·공개 주소 응답 검수는 배포 승인 이후 별도 단계다.

수업 시간·횟수·수강료·담당·인원·경로·개설일·배부·새 기록 수집은 모두 미정이다. 기관 공식 접수·추천·증빙 안내는 실제 학생 서류를 WB나 앱에 제출하라는 요구가 아니다.
