# 삼육중 대비 — 학생별 주기 평가와 피드백 규격 (v0)

> WB 독해력학원 · 웩슬러브레인센터 | 작성 2026-09-04
> **지위**: 기획서 v1.1 §8·§9-3·§13과 설계안 v1 §4-7·§6-8(`report.js`)의 **운영 규격**이다. 리포트에 어떤 문장이 어떤 원천 필드에서
> 나오는지, 누가 언제 무엇을 승인하는지, 어떤 말을 절대 쓰지 않는지를 정한다. 코드는 이 문서를 따라 만들고, 이 문서에 없는 문장은
> 화면에 존재하지 않는다.
> **원장 요청**: "학생별로 주기적으로 평가를 해서 현재 상태 및 개선·보완점을 피드백" — 이 문서가 그 답이다.

---

## 0. 원칙 다섯 — 이 상품의 평가가 학원가의 '성적표'와 다른 점

1. **점수·등수·확률이 없다.** 학교가 문제도 점수도 공개하지 않으므로(정본 §6) 어떤 점수도 실전과 대응되지 않고, 대응되지 않는 숫자는 12살에게
   낙인만 남긴다. 부모 화면의 분포 위 점 하나(원장 확정, n≥30)가 유일한 상대 정보다.
2. **"현재 상태"는 좌표다.** 코어 16칸 각각이 `유창 / 굳히는 중 / 다시 만날 칸 / 처음 보는 칸`(내부값 fluent/shaky/hole/unknown) 중 하나이고,
   그 판정의 근거(관측 n회 중 m회)를 항상 같이 적는다. 관측 3회 미만이면 아무 말도 하지 않는다.
3. **"개선·보완점"은 칸 이름 + 다음 행동이다.** "국어가 약해요"가 아니라 "비와 비율 칸을 이번 달 8번 만났고 4번 붙었어요. 다음 달은 백분율
   역산을 종이로 갑니다." 능력 귀인("이해력이 부족")·성향 진단("조건 오독형")·비교("반 평균보다")·예측("이대로면")은 금지어다.
4. **문장의 원천 필드가 없으면 그 문장은 없다.** 리포트의 모든 줄은 §부록 A의 필드 ↔ 문장 표에서 나온다. 기획서 §9-3의 규칙("9/13 첫 저장에
   없으면 10/26에 없다")을 매월 적용한다.
5. **사람이 고칠 수 있는 것은 한 줄뿐이다.** 강사는 `coachNote` 한 줄을 쓰거나 고칠 수 있고, 숫자와 칸 판정은 못 고친다. 숫자를 손으로
   고치는 순간 리포트가 상담 도구로 변질된다.

## 1. 네 층의 주기 — 누가, 언제, 무엇을 받는가

| 층 | 주기 | 수신자 | 원천 | 산출 | 자동/사람 | 파일럿(2027) |
|---|---|---|---|---|---|---|
| **L1 일일** | 매일 카드 끝 | 학생 | `days[]`·`atoms` | 오늘 움직인 칸의 갱신 문구 1~3줄(과정형) | 자동 | 9/21~ |
| **L2 회차** | 회차 다음 날 | 학생 · 강사 · 부모(완주·무응답·분포 점만) | `haru:mock`·`pace` | 회차 리포트(§3) | 자동, 공개 지연 | 10/5 · 10/19 |
| **L3 월간** | 매월 1일 초안 → 5일 발송 | 부모(1장) · 강사(검토 큐) | `weekly[]`·`atoms`·`passages[]`·`mocks[]`·`paper[]` | 월간 학습 리포트(§2) | 서버 초안 → 강사 승인 → 발송 | 10/1 한 번 |
| **L4 국면·분기** | 국면 경계(초5 10월·초6 3월·9월·10/26) + 3·6·9·12월 | 원장 · 강사 · 부모(상담) | 동결 세트 재응시 · L3 누적 | 국면 평가 2장(§4) + 플랜 조정 제안 | 서버 초안 → 원장 상담 | 11/1 16:00 회고 1장 |

L1은 화면이지 리포트가 아니다. L2~L4가 "주기 평가"다. 발송은 전부 기존 발송 승인 워크플로(진로독서 리포트 경로)를 탄다 — 자동 발송은 없다.

### 2-2. 각 줄의 원천과 게이트

| 줄 | 원천 필드 | 게이트 |
|---|---|---|
| 앉은 날 / 누적 분 | `days[d].sat`·`min` 월 합산 | 없음. "목표 n일" 대비 표기 금지(`minTotal` 없음) |
| 지문 세션 / 한 번에 읽은 지문 | `passages[].oneRead`·`rewinds` | 세션 0회면 줄 생략 |
| 붙었어요 (새로) | 월초 대비 `grade()`가 `fluent`로 바뀐 칸 | 관측 8회 미만이면 못 붙는다(정의) |
| 굳히는 중 / 다시 만날 칸 + (n번 만나 m번) | `atoms[id].obs`·`a/b` → 이번 달 관측 수와 정답 수(`weekly[]` 차분) | obs<3 → "처음 보는 칸"으로만 |
| 회차 완주·무응답·넘김 회수 | `mocks[].completed`·`blank`·`skills.passUsedAndRecovered` | 회차 없으면 블록 생략 |
| 분포 위 점 | `haru:dist:<cohort>:<keyId>` | **n<30 → 줄 없음**. 표본·구성·출처를 같은 크기로 |
| 오답의 원인 | `wrong[].cause` 월 집계 | **n<10 → 블록 없음**(목록도 없음 — 부모에게 개별 오답은 안 간다) |
| 다음 달 범위 | `plan.bands`·진도계획 표 | |
| 종이로 가는 칸 | `report.toPaper` (§4-3 규칙) | |
| 선생님 한 줄 | `coachNote` | 금지어 검사(§5) 통과해야 저장 |

## 3. L2 회차 리포트 — 세 뷰

| 뷰 | 시점 | 내용 | 없는 것 |
|---|---|---|---|
| **학생** | 회차 **다음 날** 카드와 함께 | 3교시 타임라인(지문 세트 단위) · 실점 구조를 문항 수·원인으로("3문항: 몰라서 1 · 실수 1 · 조건 1", n<10이면 목록만) · 넘긴 문항 되돌아왔는지 · 다음 7일 처방 · `carryTo` 한 줄 | **점수·정답 개수·과목별 ok** · 등수 · 같은 방 아이들 |
| **강사** | 채점 즉시(보드) | 완주 / 무응답 / 넘김 회수 / 마킹 지연 / 시험 기술 4항목 통과 · 내부값(hole/shaky) · 종이로 넘길 칸 | 점수 열 · 순위 |
| **부모** | 다음 날 | "완주 ○ · 무응답 0" + 분포 위 점(n≥30) | 그 외 전부 |
| **「설명하기」 30초** (채택 2026-09-04) | 학생 뷰 안, 오답 1문항 | ① 처음 찾은 조건(3택) ② 쓴 식·규칙(원자 이름 택) ③ 어디서 막혔나(한 줄). ①②는 `cause` 재판정 입력, ③은 강사만 본다 | 부모에게 가지 않는다 · 문장 채점 없음 · 국면 ①에는 없다 |

시험 기술 4항목(`mocks[].skills`) — 즉시 마킹 / 넘긴 문항 되돌아오기 / 무응답 0 / 쉬는 시간 채점 안 함 — 은 합격 여부와 무관하게 중학교
3년간 유효한 자산이고, "떨어져도 남는 것"의 가장 구체적인 실체다. 회고 1장에도 이 4항목의 첫 회차 → 마지막 회차 변화가 들어간다.

## 4. L4 국면 평가 — 상담용 2장과 플랜 조정

### 4-1. 언제

| 시점 | 무엇을 나란히 놓나 |
|---|---|
| 초5 10월 (코호트 진입) | 출발선 진단(동결 세트 `frozen`) — 기준점 생성. 리포트는 "지금 어디서 시작하는가"만 |
| 초5 3월 · 초6 3월 (학년 경계) | 동결 세트 재응시 vs 출발선 · 코어 완주율 · `bands` 조정 제안 |
| 초6 9월 (파이널 진입) | 3·6·8월 회차 궤적 · 종이로 넘길 칸 확정 · D-14 신규 마감 목록 |
| 시험 후 (11/1 16:00) | 회고 1장 — 결손이 아니라 획득(`carryTo`), 같은 세트 두 번, 시험 기술 변화 |
| 분기(3·6·9·12월) | L3 3개월 누적의 궤적(`weekly[]` top3 변화) |

### 4-2. 2장의 구성

**1장 — 이동**: 동결 세트 25문항 중 맞힌 수(전·후, 이것만은 문항 수를 쓴다 — 같은 세트 두 번은 비교 가능한 유일한 숫자) · 코어 16칸의 상태
전·후(격자 두 개) · `weekly[]` top3의 변화 궤적 · 지문 되감기 추이.
**2장 — 다음 국면**: `bands` 제안(당김/유지/늦춤) · 하루 예산 제안 · 종이로 넘길 칸 목록과 이유 · 3·6·8월 회차 배치 · 부모에게 부탁할 조건 하나
(취침·시작 시각 — 내용이 아니라 조건).

### 4-3. 판정 규칙 — "개선·보완점"을 기계가 어떻게 고르는가 (`report.js` 규칙표)

| 상태 조합 | 판정 | 권고 문장 템플릿 |
|---|---|---|
| `hole` · tier 3 · `cause.gap` ≥ 3 | **종이로** (`toPaper`) | "{칸}은 발상이 필요한 칸이라 종이로 갑니다. {paperSource}" |
| `hole` · tier ≤ 2 · `cause.exec` 우세 | 앱 블록 자동화 | "{칸}은 아는데 손이 틀립니다. 3문항씩 매일 만납니다" |
| `hole` · `cause.confuse` 우세 | 혼동 짝 인터리빙 | "{칸}과 {confuse 칸}을 섞어서 냅니다" |
| `hole` · `cause.misread` 우세 | 발문 표시 훈련 | "조건에 표시하는 연습을 넣습니다" |
| `shaky` · obs ≥ 8 · `ctx` = [block]만 | 혼합 맥락 필요 | "{칸}은 섞어 내도 맞아야 붙습니다" |
| `unknown` 2칸 이상 · 국면 ②·③ | 프로브 우선 | "{칸}은 아직 재지 않았습니다. 다음 달 먼저 만납니다" |
| `passages[].oneRead` 비율 < 0.3 (3개월) | 독해 습관 | "지문을 한 번에 읽는 비율이 낮습니다. 화·목 세션을 소리 내어 읽기로 바꿉니다" |
| 회차 `blank` > 0 두 번 연속 | 시험 기술 | "빈칸으로 낸 문항이 있습니다. [넘김] 후 되돌아오기를 연습합니다" |
| `days` 월 완주율 < 0.5 · 3주 연속 | **조건 조정** (아이 탓 아님) | 부모에게: "시작 시각을 당겨 보시겠어요?" — 3주 연속이면 문구를 멈춘다 |
| 동결 세트 재응시 차이 ≤ 0 | 원장 상담 | 리포트는 숫자만 쓴다. 판단 문장 없음 |

**국면 조정은 코호트 단위**(`plan.bands`·`dailyMin`)이고 학생별 플랜 조정은 없다. 학생별로 다른 것은 `toPaper` 목록과 봉투 내용뿐이다.

## 5. 문구 규칙 — 허용 문형 세 개, 금지어 한 표

**허용 문형** (report.js 템플릿은 이 셋의 조합만 만든다):
1. 관측 서술 — "{칸}을 이번 달 {n}번 만났고 {m}번 맞았어요."
2. 상태 변화 — "{칸}이 붙었어요." / "{칸}은 굳히는 중이에요." (강등은 학생·부모 화면에 쓰지 않는다 — 강사 보드만)
3. 다음 행동 — "다음 달은 {범위}를 엽니다." / "{칸}은 종이로 갑니다." / "{조건}을 바꿔 보시겠어요?"

**금지** (`report.test.cjs`가 출력 문자열을 검사한다):

| 종류 | 예 |
|---|---|
| 능력 귀인 | 이해력 · 집중력 · 머리 · 재능 · 게으르 · 산만 · 성실하지 |
| 성향 진단 | ~형 (조건 오독형 · 실수형) · 성격 · 기질 |
| 비교·서열 | 반 평균 · 또래 · 상위 · 하위 · 등 · 위 · 아래 · 다른 아이 |
| 예측 | 이대로면 · 합격 · 불합격 · 가능성 · 확률 · 될 것 · 안 될 것 |
| 압력 | 아직 · 밀렸 · 남았 · 더 해야 · 부족 · 분발 · 노력이 필요 |
| 결손 명사 | 구멍 · 오답 n회 · 틀린 문제 (학생·부모 화면) |
| 시험 노출 | 삼육 (국면 ①) · 경쟁률 · D-day (국면 ①) |

**좋은 한 줄 / 나쁜 한 줄** (강사 `coachNote` 교육용):
- 좋음: "이번 달은 지문을 한 번에 읽는 날이 늘었습니다. 집에서도 소리 내어 읽는 걸 이어 주세요."
- 나쁨: "집중력이 부족해서 실수가 많습니다. 조금만 더 노력하면 됩니다." (능력 귀인 + 압력 + 예측)

## 6. 강사 워크플로와 시간 예산

```
매월 1일 03:00   서버 크론 → 학생별 초안 haru:review:<코드>:<YYYY-MM> → 강사 보드 [검토] 탭
1일~3일          강사: 초안 읽고 coachNote 한 줄 (학생당 2분). 숫자는 못 고친다. 이상하면 [원장 확인] 플래그
4일              원장: 플래그 건만 확인 · 일괄 승인
5일              기존 발송 승인 워크플로 → 부모(ptoken 링크 또는 인쇄)
```

- 학생 30명 × 2분 = 1시간/월(강사). 원장은 플래그 건만.
- 리포트가 나가지 않는 조건: 그 달 `days` 0일(앉은 날이 없으면 리포트가 없다 — 대신 강사 보드에 idle 표시) · 국면 ⑤ · 발송 승인 거부.
- 부모가 리포트에 답하는 경로는 없다(쓰기 라우트 없음). 질문은 학원 전화·대면으로 — 앱이 상담 창구가 되면 24시간 응대 의무가 생긴다.
