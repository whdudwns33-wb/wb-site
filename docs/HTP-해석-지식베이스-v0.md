# HTP 해석 지식베이스 v0 (AI 엔진 재료)

> 그림검사 AI 해석 웹 · 검사별 지식베이스 초안
> 출처: Perplexity 딥리서치(2026-07-27) 기반, 임상·학술 자료 종합. **전문 심리사 검수 전 초안입니다.**

---

## ⚠️ 먼저 알아야 할 핵심 발견 (설계에 결정적)

리서치 결과, **HTP를 비롯한 투사적 그림검사는 과학적 타당도·신뢰도가 낮게 평가됩니다.**

- 개별 지표 해석의 **근거수준은 대부분 "약~중", "강"은 사실상 없음.**
- 표준화된 해석기준이 부족하고 평가자 주관 개입이 커서 신뢰도 논란(연구별 신뢰도 .60~.97로 편차 큼).
- 같은 지표도 연구 간 의미가 상충(예: 굴뚝 연기 = 따뜻함 vs 갈등).
- 법정·공적 판단에서 증거로 잘 채택되지 않으며, **보조적 도구**로만 제한 사용.

**→ 설계 시사점:** AI 해석 엔진은 **"진단 도구"가 아니라 "가설 생성 보조 도구"**로 위치시켜야 합니다. 이것은 앞서 정한 "AI 자동 해석 중심" 방향에 **전문가 확정 게이트가 선택이 아니라 필수**임을 학술적으로 뒷받침합니다. 단일 지표 자동 결론은 금지하고, 모든 출력에 근거수준·경고를 부착해야 합니다.

## 1. 관찰요소 → 심리 가설 → 근거수준 (집 / 나무 / 사람)

> 근거수준: **강**=경험적 연구 있음 / **중**=임상 통념·일부 연구 / **약**=상징·직관 중심, 연구 간 상충.
> 모든 가설은 "가능성·경향"이며, 다른 검사·면담과 교차검증 필수.

### 🏠 집 (House) — 가정·애착·정서적 안전감 지각

| 관찰요소 | 통상 가설 | 근거수준 |
|---------|----------|:-------:|
| 전체 크기·용지 내 위치 | 작고 구석=위축·자신감 저하 / 크고 중앙·상단=자기중심·안전감 추구 | 약 |
| 지붕(크기·과장) | 크고 과장=공상 의존·현실 회피 / 거의 없음=보호감 부족·현실 중심 | 약 |
| 문(크기·닫힘·손잡이) | 작음·닫힘·손잡이 없음=관계 접근 불안·회피 / 넓고 세부 풍부=개방성 | 중 |
| 창문(수·크기·격자) | 적음·작음=정서 표현 억제 / 많음=접촉 욕구 / 격자·철창=통제·억압감 | 약~중 |
| 굴뚝·연기·울타리·담 | 연기=온기 vs 갈등(상충) / 담 강조=경계·방어·보호 욕구 | 약 |

### 🌳 나무 (Tree) — 무의식적 자아상·생명력·자기통제

| 관찰요소 | 통상 가설 | 근거수준 |
|---------|----------|:-------:|
| 전체 크기·굵기 | 작고 약함=자존감 저하·에너지 부족 / 화면 지배=과잉 자아·불안 보상 | 약~중 |
| 줄기(굵기·손상 표현) | 가늘고 흔들림=자아강도 약화·불안 / 부러짐·구멍=심리적 손상·트라우마 가설 | 중 |
| 뿌리(표현·강조) | 거의 없음=기반·소속감 부족 / 과도=안정감 과잉 추구·불안 보상 | 약 |
| 가지·잎(방향·밀도) | 위로 뻗음·풍부=미래지향·활력 / 늘어짐·잎 없음=우울·위축 | 약 |
| 주변 환경(땅선 등) | 땅선 없음·떠 있음=현실감·지지 기반 부족 / 풍부한 환경=정서적 풍부함 | 약 |

### 🧍 사람 (Person) — 신체 자아상·대인관계·발달 수준

| 관찰요소 | 통상 가설 | 근거수준 |
|---------|----------|:-------:|
| 전체 비율·신체 왜곡 | 머리 과대=사고 과잉집중·신체 자존감 낮음 / 사지 왜곡=신체상 왜곡·충동성 | 중 |
| 얼굴(눈·입·표정) | 눈 강조=타인 평가 민감·사회불안 / 입 과장·생략=감정 표현·억제 / 무표정=정서 둔마 | 중 |
| 손·팔(생략·길이) | 생략·짧음=무력감·대인 회피 / 과대·공격적=충동성 | 중 |
| 의복·역할 묘사 | 정돈=자기통제·규범 지향 / 역할=자기상·소망·동일시 단서 | 약 |
| 신체 부분 생략 | 목=사고·감정 연결 갈등 / 손=행위·접촉 위축 (단, 발달·귀찮음 등 여러 가능성 공존) | 중 |

## 2. 연령별 발달 정상범위 (오분류 방지 필드)

> AI가 어린 아동의 생략·왜곡을 자동으로 병리로 분류하지 않도록 **연령 보정 규칙** 필수.

| 연령대 | 정상 변이 (병리 아님) | 해석 유의 |
|-------|---------------------|----------|
| 만 3–4세 | 막대인형, 손·발·목·세부 생략 매우 흔함 | 대부분 발달적 미숙 |
| 만 5–6세 | 손가락·목·코·귀 등 세부 생략, 뿌리 생략 흔함 | 단일 지표로 문제 추정 금지 |
| 만 7–9세 | 손가락 수 부정확 정상, 손·발 표현 증가 | **반복·일관된 핵심 부위 생략**만 가설 의미 |
| 만 10–12세 | 기본 신체 부분 생략은 드물어짐 | 핵심 부위 반복 생략·극단 왜곡 지속 시에만 가설 |
| 청소년·성인 | — | 6세 미만 정상인 '내부 투시' 표현이 학령기 이후엔 가설 의미(중) |

## 3. 안전 원칙 (엔진 하드코딩)

1. **단일 지표 = 진단 아님.** "팔 없는 사람 → 학대"처럼 단정 금지. 그리기 귀찮음 등 대안 설명 항상 병기.
2. **투사검사 단독 해석 금지.** 표준화 검사(K-WISC, MMPI 등)·발달력·면담과 교차검증.
3. **과잉해석·낙인 위험.** 같은 그림도 개인사·상징체계에 따라 다름. 해석자 이론·경험에 좌우됨.
4. 모든 출력에 **근거수준 메타데이터 + 자동 경고문**("단일 지표로 진단 불가", "타 검사·면담 통합 필요") 기본 부착.
