# 하루 v2 미확인 요강·추천/증빙 후속 검토

2026-10-12. 작업 브랜치 `codex/haru-v2-remaining-guidelines-20261012`. 이전 로컬 인계 이후 최신 main `8456477`을 포함했다. 로컬 검토 전용이며 push·PR 게시·운영 배포는 하지 않는다. 수업 운영값은 전부 미정이다.

## 이번에 반영한 범위

- 아직 상세가 없던 5기관(장흥·진도·백산중·전주예술고·장수)의 2027 공식 선발 공고를 추가 대조했다. 장수는 지원청 이미지 **요약**, 나머지는 상세 첨부까지 읽었다. 요약을 전체 요강 검수로 표시하지 않는다.
- 기존 13기관의 미요약 추천·증빙 조건을 보완했다. 10/11 확보한 첨부의 재대조이므로 원문 확인일은 10/11 유지, 10/12 조건 검토 이력을 새 출처 버전으로 연결했다.
- GED 교육2027·기관유형 전체·소재시도 전남/전북으로 다시 조회했다. 학년·분야·지역교육청 필터 없음. 전남 5행/1페이지, 전북 18행/2페이지를 확인했다. 10/11의 4건/17건 기록은 보존한다. 새 진도 seq25988·전주예술고 seq25991가 추가됐다. GED 밖 장흥·장수·백산중은 자체 공고와 별도 연결했다.
- 전남의 나머지 17지원청은 교육청이 제공한 최신 주소로 이동해 자체 영재교육 게시판 첫 페이지를 각각 확인했다. 해당 범위에서 2027 요강은 미확인이다. **기관 미공고·미모집·미운영으로 확정한 결과가 아니다.**
- KAIST 새 위탁 사이트의 지역별 요강 13건/두 페이지를 확인했다. 전남·전북 제목은 2026 자료다. 별도 IP영재기업인교육원 2027 공고는 교육청 위탁 사이버 모집 요강으로 옮기지 않았다.
- 안내 68개·광주 현재학년/분야 후보 21개 유지. 신규 기관을 더한 작업이 아니라 기존 미확인 항목의 근거·조건 보완이다.
