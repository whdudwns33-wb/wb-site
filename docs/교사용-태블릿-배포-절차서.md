# 교사용 태블릿 배포 절차서

> WB 독해력학원 | Tab A7 15대를 선생님 6명에게 배포하는 실무 절차
> 작성일 2026-08-09 · 기획서 v3.0의 2장을 실행 단계로 푼 문서

---

## 0. 이 문서가 푸는 문제

계획은 "담임 전담 6대 · 공용 거치 7대 · 예비 2대"입니다. 그런데 실제로 배포하려면 **각 태블릿에서 선생님 개인 링크를 한 번 열어야** 하고, 여기서 막힙니다.

| 막히는 지점 | 왜 |
|---|---|
| 개인 링크가 깁니다 | 태블릿 주소창에 손으로 못 칩니다 |
| 클립보드가 기기를 못 넘습니다 | 원장님 폰에서 복사해도 태블릿에 안 붙습니다 |
| 태블릿에 카톡·메일이 없습니다 | 링크를 받을 통로가 없습니다 |

아래는 이 문제를 푸는 방법과, **하면 안 되는 방법**입니다.

---

## 1. ⚠️ 먼저 — 태블릿에서 원장 화면을 열지 마세요

**원장 비밀번호는 그 기기에 그대로 저장됩니다.** (서버로 가지 않고 브라우저 안에만 남습니다)

선생님·학생이 쓰는 태블릿에서 원장 화면을 한 번 열면, **그 태블릿에 원장 비밀번호가 남습니다.** 화면을 잠가도 저장된 값은 지워지지 않습니다.

| | |
|---|---|
| ❌ 하지 마세요 | 태블릿에서 원장 화면 열기 → 직원 관리 → 링크 복사 |
| ⭕ 대신 | 링크는 **원장님 PC나 폰**에서 만들고, 태블릿에는 링크만 전달 |

> 이미 태블릿에서 원장 화면을 여신 적이 있다면, 그 태블릿의 크롬에서 **설정 → 인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터**를 지우고 다시 시작하세요.

## 2. 링크를 태블릿으로 넘기는 방법 3가지

| | 방법 | 준비 | 대당 소요 | 추천 |
|---|---|---|---|---|
| **A** | 태블릿 크롬에 **학원 공용 구글 계정** 로그인 → 원장님 PC 크롬에서 `내 기기로 전송` | 계정 1개 (어차피 세팅 때 넣습니다) | 30초 | ⭐ **먼저 이걸로** |
| **B** | 태블릿에 카톡을 잠깐 로그인해 링크를 받고, 끝나면 로그아웃 | 없음 | 2~3분 | 계정이 곤란할 때 |
| **C** | 앱에 QR 코드 기능을 넣어 화면에 띄우고 태블릿으로 스캔 | 개발 필요 | 5초 | 나중에 (3장) |

### A 방법 — 권장

1. 태블릿 크롬에 학원 공용 구글 계정으로 로그인 (기기 세팅 때 한 번)
2. 원장님 PC 크롬에서 앱을 열고 → **직원 관리** → 해당 선생님 **링크 복사**
3. PC 크롬 주소창에 붙여넣고 **엔터를 누르지 말고**, 주소창 오른쪽 **공유 아이콘 → 내 기기로 전송 → 해당 태블릿** 선택
4. 태블릿에 알림이 뜹니다 → 누르면 앱이 열립니다 → **[이 기기에 연결]**
5. 크롬 메뉴 → **홈 화면에 추가**

> ⚠️ **엔터를 누르지 마세요.** PC에서 링크를 열어버리면 1회용 코드가 그 자리에서 소모되어 태블릿에서는 못 씁니다. 그 경우 링크를 새로 만들면 됩니다.

### B 방법 — 계정이 곤란할 때

1. 원장님이 선생님께 개인 링크를 카톡으로 보냄 (원래 하시던 방식)
2. 태블릿에 **선생님 본인** 카톡 로그인 → 링크 열기 → **[이 기기에 연결]**
3. **카톡 로그아웃** (중요)
4. 홈 화면에 추가

> 카톡 인앱 브라우저에서는 연결이 되지 않습니다. 링크를 **길게 눌러 크롬으로 열어** 주세요. 앱이 안내 문구를 띄웁니다.

## 3. 연결 횟수가 얼마나 되나

| 대상 | 연결 |
|---|---|
| 담임 전담 6대 | 본인만 → **6번** |
| 공용 거치 7대 | 그 자리를 쓰는 선생님만 (전원 아님) → **10~15번** |
| 예비 2대 | 자주 쓰실 분 위주 → **2~4번** |
| **합계** | **20~25번** |

A 방법이면 대당 30초라 **전부 15분 남짓**입니다. 이 정도면 QR을 만들 필요가 없습니다.

**QR을 만들어야 하는 신호** — 아래 중 하나라도 걸리면 그때 개발합니다.

1. A·B 둘 다 현장에서 막힌다 (구글 계정도 카톡도 곤란)
2. 재연결이 자주 생긴다 (기기 초기화·교체가 잦음)
3. 학생·센터 태블릿까지 개인 링크 연결이 필요해진다

## 4. 배포 순서

### 4-1. 준비 (원장님)

- [ ] W0 실사에서 **A7 15대**를 골라 따로 뺍니다
- [ ] 담임 전담 6대에 **이름 라벨** 부착 (김남기 · 최인찬 · 정다원 · 공현정 · 김동현 · 김혜지)
- [ ] 각 기기에 **화면 잠금**(PIN 또는 패턴) 설정
- [ ] 크롬을 최신으로 업데이트
- [ ] 거치대 준비 (담임 6 + 공용 6)

### 4-2. 연결 (기기마다)

- [ ] 2장 A 방법으로 링크 전달
- [ ] 태블릿에서 **[이 기기에 연결]**
- [ ] 크롬 메뉴 → **홈 화면에 추가**
- [ ] 앱을 열어 화면 맨 위에 **"○○ 선생님 · 개인 업무"** 가 뜨는지 확인
- [ ] 기기 탭에서 해당 기기의 **배치=교사, 담당자=본인, 위치** 입력

### 4-3. 안내 (선생님께)

아래 문안을 그대로 카톡으로 보내시면 됩니다.

```
선생님, 업무용 태블릿을 드립니다.

■ 무엇이 달라지나요
지금 폰으로 하시던 출결·단계 체크·메모를 태블릿에서 하시면 됩니다.
수업 중에 바로 남길 수 있어서, 끝나고 몰아서 쓰지 않으셔도 됩니다.

■ 쓰는 법
평소 쓰시던 앱과 똑같습니다. 홈 화면 아이콘을 누르면 바로 열립니다.
화면 맨 위에 선생님 이름이 떠 있으면 제대로 들어오신 겁니다.

■ 알아두실 점
· 태블릿이 바뀌어도 됩니다. 새 기기는 한 번만 연결하면 계속 쓰입니다.
· 공용 태블릿(교실·상담실)도 쓰실 수 있습니다. 한 번 연결해 두세요.
· 여러 선생님이 같은 태블릿을 써도 기록은 섞이지 않습니다.
  다만 화면 위 이름을 꼭 확인하고 본인 것만 써주세요.
· 배터리가 나가면 충전 선반의 예비 태블릿으로 바꿔 쓰시면 됩니다.

■ 안 될 때
링크가 만료됐다고 나오면 원장님께 새 링크를 요청해 주세요.
카톡 안에서 열면 연결이 안 됩니다 — 링크를 길게 눌러 크롬으로 열어주세요.
```

## 6. 배포 후 첫 주에 볼 것

계획이 맞았는지는 **기록이 언제 남는가**로 판단합니다.

| 볼 것 | 판단 |
|---|---|
| 출결·메모가 **수업 중**에 남는가 (몰아서가 아니라) | 이게 이번 도입의 목적입니다 |
| 공용 거치 태블릿을 실제로 쓰는가 | 안 쓰면 거치 위치가 잘못된 것입니다 |
| 예비 태블릿이 실제로 교체에 쓰였는가 | 안 쓰였으면 배터리가 하루를 버틴다는 뜻 |
| 선생님이 새 기기를 스스로 연결했는가 | 되면 원장님 손이 빠집니다 |

**안 되면 되돌리기 쉽습니다.** 태블릿은 회수해서 다른 용도로 돌리면 되고, 앱은 기기 탭에서 배치만 바꾸면 됩니다.
