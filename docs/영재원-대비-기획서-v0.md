## 0. 한 줄 요약

**영재원 시험은 삼육중 시험의 정반대다.** 삼육중은 국·수·영 객관식 필기 한 번으로 결정되고, 앱이 정답률을 올려 줄 수 있다.
영재원은 ① **다니는 학교 교사가 먼저 고르고**(학년 재적 3% 상한), ② KEDI 가 "선행학습·기출유형에 익숙한 학생 선발 지양"을 명시한
**서술형 창의적 문제해결 검사**를 보고, ③ 대학부설은 **면접·수업 관찰·지정 도서**까지 본다. 문제를 많이 풀린 아이가 유리하도록
설계된 시험이 아니다.

그래서 이 트랙은 "영재원 대비반"을 팔지 않는다. **광주에 없는 것 셋**을 판다 —
1. **생각을 끝까지 쓰는 습관**: 60분 서술형에서 답을 "여러 개, 다른 종류로, 이유를 붙여" 쓰는 손. 연습으로 늘고, 기록으로 보인다.
2. **놓치지 않는 달력**: 학교 공고(10월 둘째 주) → GED(10.19~26) → 오류 정정(10.27~28, 담임은 못 고친다) → 추천 확인(11.6) → 검사(12.5).
   해마다 이 중 하나를 놓쳐 1년을 잃는 집이 있다. 앱 부모 화면이 이미 하는 일이다.
3. **3년의 생각 기록**: 붙든 안 붙든 "무엇을 궁금해했고, 무엇을 만들었는지"가 남는다. 학교 교사가 관찰추천을 쓸 때 볼 수 있는 것은
   아이의 실제 수업 태도뿐이다 — 학원이 그 체크리스트를 대신 채워 줄 방법은 없고, 채우려 해서도 안 된다(§3).

## 1. 왜 지금, 왜 우리

- **지금**: 2027학년도 광주 GED 접수가 **10.19~26**, 광주교대 원서가 **10.15~30**이다(사실 조사 §5). 이번 주기의 '선교육 전형'
  입구(과학영재키움 3월·공동 온라인 선교육 6월·체험캠프 여름)는 이미 닫혔다. **이번 가을은 안내만 하고, 상품은 2027년 3월 주기에 맞춘다.**
- **우리**: 이 시험이 실제로 재는 것 — 실생활 맥락을 읽고, 조건을 놓치지 않고, 생각을 문장으로 쓰는 것 — 은 독해력학원의 본업과 겹친다.
  특히 광주교대 **인문융합**은 "지정 도서 기반 지필 + 면접"(비판적·논리적 사고, 질문 생성, 표현력)이다. 진로독서·청크브레인이 이미 하는 일이다.
- **경쟁 구도(추정)**: 광주 초등 수·과 2차는 거점별 약 1.4~3:1(수험번호로 셈, 사실 조사 §2-5). 2차보다 **학교 안 1차(재적 3%)**가 더 좁을 수 있다.
  1차는 학원이 개입할 수 없는 교실 관찰이다. 이 사실이 §3의 금지 목록을 만든다.

## 3. 절대 원칙 — 하지 않을 것

**A. 선발 과정에 손대지 않는다**
1. **자기소개서·지원서·산출물·포트폴리오를 대신 쓰거나 고쳐 주지 않는다.** 학원이 할 수 있는 것은 아이가 스스로 한 활동을 스스로 적게 하는
   질문지까지다. (대학부설은 "사교육 관계자 … 는 추천할 수 없습니다"를 명시한다 — 사실 조사 §4.)
2. **교사관찰추천 체크리스트(KEDI 영재행동특성·창의적인성·리더십)를 겨냥한 '연기' 지도를 하지 않는다.** 학교 교사가 교실에서 보는 것을
   학원이 꾸며 주면, 그것은 교사를 속이는 일이다.
3. **GED 지원서를 학원이 대신 입력하지 않는다.** 가족이 직접 한다. 학원은 날짜와 순서를 알려 준다(정정도 학생·학부모 몫 — 공고 원문).
4. 학교에 추천을 부탁하거나 추천 여부를 묻지 않는다.

**B. 콘텐츠**
5. **기출 복원·검사 문항 원문을 어디에도 넣지 않는다**(앱·KV·저장소·세션). GED 에 공개된 KEDI 예시 문항도 앱에 싣지 않는다 — 링크로 안내만.
6. 대학부설 지정 도서(예: 광주교대 인문융합)의 **본문을 앱에 넣지 않는다.** 아이가 책을 직접 읽고, 앱은 우리가 만든 질문만 낸다.
7. 타 학원 영재원 교재·모의고사를 쓰지 않는다(삼육중 기획서 §4-2와 같다).

**C. 아이와 부모에게**
8. **"영재"를 아이에게 붙이는 말로 쓰지 않는다.** 화면 어디에도 "영재 판정·영재 가능성·영재 지수" 없음. 아이 화면에는 「생각 기록」만.
9. 합격 확률·경쟁률·예상 결과 표시 금지(강사 화면 포함). 경쟁률은 공식 발표가 없다.
10. **웩슬러 지능검사로 넘어가는 동선을 만들지 않는다**(삼육중 기획서 §4-12 계승). 영재교육원 선발은 지능검사를 쓰지 않는다 —
    "영재원 가려면 IQ 검사부터"라는 상담 문구도 금지. 센터의 검사는 별개 서비스이고, 이 트랙에서 권하지 않는다.
11. 연속 학습일·랭킹·반 대전 없음. **누적으로만 센다**(삼육중 §4-7·10).
12. 발표일(12.21·1.11 등) 전후로 학습 독촉 없음. 불합격 다음 날의 "다시 시작하세요"가 이 트랙이 할 수 있는 가장 나쁜 일이다.

**D. 광고·표시**
13. **"영재원 대비반"·"영재원 합격반"·"선행"을 광고에 쓰지 않는다.** KEDI 가 선행학습형 학생을 지양한다고 공식적으로 밝힌 시험이고,
    광주시교육청은 선행학습 유발 광고를 단속해 왔다(삼육중 기획서 §4-15). 카피는 "사고력 · 탐구 · 생각 기록"으로 쓴다. → **원장 확인 D-3**
14. "합격 N명"·"적중"·"출제 경향" 금지. 학교·교육원 로고·이름을 광고에 쓰지 않는다.

## 4. 무엇을 기르는가 — 「생각 기록」 원자 지도

영재성 검사의 공식 설명(사실 조사 §7)에서 거꾸로 세운다. **교과 선행이 아니라, 현재 학년 지식으로 하는 사고**다.

| 갈래 | 원자(예) | 근거(공식 설명) | 앱이 하는 몫 |
|---|---|---|---|
| **G 일반 창의성** | `g-fluency` 많이 떠올리기 · `g-flex` 다른 종류로 바꾸기 · `g-orig` 남과 다른 생각 · `g-elab` 다듬어 구체화 | KEDI 창의사고 영재성 | 「생각 노트」: 개수·범주 수는 기계가 세고, 독창·정교는 강사 루브릭 |
| **M 수학적 사고** | 규칙 발견·일반화(`m-pattern-inverse`) · 빠짐없이 세기(`m-counting`) · 조건 정리·역추론(`m-logic`) · 공간·도형 변환 · 어림과 최적화 | "수학적 사고력, 추론능력, 통찰력을 이용하여 실세계 문제를 창의적으로 해결" | 닫힌 하위 기능은 생성기 + SRS(기존 엔진), 열린 문제는 종이 |
| **S 과학 탐구** | 관찰 → 질문 만들기 · **변인 통제** · 실험 설계 · 자료·그래프 해석 · 근거 있는 설명 | "호기심 … 탐구활동에 활용하여 해결책을 제시하는 실천력" | 변인 고르기·그래프 읽기는 앱, 실험 설계 서술은 종이 |
| **C 컴퓨팅 사고** | 분해 · 규칙(패턴) 찾기 · 절차 설계 · 검증 | AI교육원 Q&A "특정 코딩 언어 … 시험이 아닙니다 … 논리적·절차적 사고" | 절차 따라가기·순서 맞추기 생성기 |
| **W 쓰기·말하기** | 서술형 답 구조(답 → 이유 → 조건) · 60분 시간 배분 · 구술(면접) 2분 말하기 | 광주 2차 "서술형", 대학부설 구술·심층면접 | 종이 답안 + 강사 채점(삼육중 종이 회수 흐름 재사용) |
| **R 인문융합 읽기** | 깊이 읽기 · 질문 만들기 · 다른 관점 세우기 | 광주교대 인문융합 "지정 도서 … 질문 생성" | 진로독서 지문·청크브레인 재사용. 지정 도서는 아이가 종이책으로 읽는다(§3-6) |

- 원자 수: v0 는 G4 · M5 · S5 · C4 · W3 · R3 = **24개**를 목표로 한다. 삼육중 원자와 겹치는 M 3개는 같은 id 를 쓴다(기록이 한 곳에 쌓인다).
- **유창의 정의가 다르다.** 삼육중의 `fluent`(찍기 보정 p ≥ 0.80)는 닫힌 원자에만 쓴다. 열린 원자(G·W)는 정답률이 없다 —
  **"최근 4번의 생각 노트에서 범주 수가 늘었는가"**처럼 자기 자신과의 비교만 쓴다. 남과 비교하는 수치는 만들지 않는다(§3-9).

## 5. 학습 모델 — 삼육중 엔진과 다른 점

| | 삼육중 트랙 | 영재원 트랙 |
|---|---|---|
| 문항 형식 | 4~5지 객관식 | **열린 답이 중심**. 닫힌 하위 기능만 객관식·단답 |
| 채점 | 서버 자동(정답은 `/answer`에만) | 닫힌 것 = 같은 서버 채점. 열린 것 = **기계는 세기만**(개수·범주), 판단은 강사 |
| 화면의 숫자 | 앉은 날·좌표 칸 | 「생각 노트 n장」·「떠올린 생각 n개」(누적만) |
| 회차 | 25문항 40분 OMR | **60분 서술형 종이 회차** — 월 1회, 학원에서. 앱은 시간 알림·제출 확인만 |
| 부모 화면 | 일정·완주·취침 | 일정(학교 공고·GED·정정·추천 확인·검사·발표) + "이번 달 아이가 궁금해한 것" 한 줄(아이가 고른 것만) |

### 5-1. 「생각 노트」 (새 화면 1개)
- 과제 하나(예: "○○을 쓸 수 있는 곳을 될 수 있는 한 많이") → 아이가 한 줄씩 입력 → 끝내면 **"생각 n개, 종류 m가지"**만 보여 준다.
  잘했다·못했다 평가 문구 없음. 범주 분류는 강사가 나중에 붙이거나, 과제마다 미리 정한 범주 사전으로 세운다(외부 AI 로 아이 답을 보내지 않는다).
- 강사 화면: 학생별 개수·범주 추이 + 루브릭(독창 0~2, 정교 0~2) 입력 칸. 학생에게는 루브릭 점수를 보여 주지 않고, 강사가 고른 **한 문장 피드백**만 간다.
- 기술: `haru:state`에 `notes[]`(본문은 학생 기기 → 서버 state, 200자 × 20줄 상한). 서버 정규화·이스케이프 두 겹(CLAUDE.md 규칙 4).

### 5-2. 닫힌 하위 기능 생성기 (자작, 저장소에 둘 수 있음)
- `g-rule-seq` 수·도형 규칙 다음 항 · `m-enum-check` 빠뜨린 경우 찾기 · `s-var-pick` 바꾼 것/같게 둔 것 고르기 · `c-step-trace` 절차 따라가 결과 맞히기.
- 기존 `gen.js` 계약을 따른다: 서버가 seed 로 만들고 seed 로 다시 만들어 채점, 정답은 기기에 내려가지 않는다.

### 5-3. 종이 회차 (월 1회, 60분)
- 자작 서술형 4~5문항 → `sheet-build.mjs` 로 시험지·대응표 → 강사가 4점 루브릭으로 채점 → 종이 회수 화면에 입력.
- 회차 뒤 아이에게는 **점수 없이** "가장 길게 생각한 문제"와 강사 한 문장만. 부모에게는 "60분을 끝까지 썼는가"(완주)만.

## 8. 하루브레인에 얹는 방법 (기술 요약 — 명세는 v1 에서 설계안으로)

- **트랙 = 코호트 플랜의 종류.** `plan:<cohort>`에 `track:'gift'`를 더하고 `examDate` = 그해 12월 첫 토요일. `plan.js`의 달력·잠금·회고 창을
  그대로 쓴다(시험 다음 날 잠금, 발표 뒤 숫자 개방).
- **원자**: `atoms.json`에 `subject:'gift'` 갈래(G·S·C·W·R) 추가, M 은 기존 id 재사용. `atoms-check.js`의 코어 규칙(국6·수6·영4)은
  삼육중 트랙 전용으로 범위를 한정한다.
- **화면**: 학생 홈은 그대로(카드 한 장). 트랙이 `gift`면 슬롯 하나가 「생각 노트」로 바뀐다. 좌표 화면은 갈래별 묶음(이번 디자인 개선의
  과목 묶음을 그대로 쓴다).
- **부모 화면**: 마일스톤에 "학교 추천 공고 확인"·"GED 오류 정정(담임은 못 고칩니다)"·"GED 에서 추천 여부 확인"을 넣는다 —
  이 트랙에서 부모 화면이 하는 가장 큰 일이다.
- **강사 보드**: 같은 보드에 트랙 필터. 열린 원자는 "개수·범주 추이"만, 정렬은 하나(삼육중 §8-3).
- **금지어**: `strings.js`에 트랙 전용 추가 — 학생 `영재`·`IQ`·`지능`·`합격`·`떨어`, 부모 `영재 가능성`·`확률`·`IQ`.
- **개인정보**: 생각 노트 본문은 아이가 쓴 글이다. 외부 AI 로 보내지 않는다. 파기는 기존 4계열(state·mock·paper·parent)에 포함된다.

## 10. KPI — 합격률로 재지 않는다

1. **일정 누락 0가족**: 트랙 가족 중 GED 접수·오류 정정·추천 확인을 놓친 집의 수(부모 화면 체크).
2. 생각 노트의 **범주 수 추이**(아이별, 자기 대비).
3. 60분 종이 회차 **완주율**(끝까지 쓴 비율).
4. 아이 자기보고 한 문항: "생각하는 게 재미있었다"(분기 1회, 강사가 종이로).
- 합격자 수는 KPI 가 아니다. 삼육중 §13 과 같은 이유 — 결과를 KPI 로 두면 §3의 금지가 먼저 무너진다.
