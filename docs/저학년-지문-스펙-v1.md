# 저학년(초1~2) 지문 스펙 — WB 진로독서 L1

> WB 독해력학원 · 웩슬러브레인센터 | 문서 버전 v1 · 2026-09-10
> 현재 앱은 **초3부터** 시작한다(`GRADES` e3~h3). 이 문서는 그 아래 한 칸,
> **초1~2용 L1 레벨**의 지문 규격을 정의한다.
> 규격의 숫자 부분은 `reading/content.test.cjs`가 기계로 검증한다 — 문서와 코드가 갈라지지 않게.

---

## 0. 한 줄 요약

**저학년 지문은 "짧은 L2"가 아니다.** 초1~2는 해독(글자→소리)에 작업기억을 거의 다 쓰기 때문에,
같은 글을 짧게 줄이면 이해가 되는 게 아니라 **읽다 만 글**이 된다.
L1의 목표는 독해 문제 풀이가 아니라 **유창성** — 끝까지, 막힘없이, 소리 내어 읽어 내는 경험이다.

---

## 1. 왜 별도 규격이 필요한가

| 초1~2의 특성 | 규격에 미치는 영향 |
|---|---|
| 해독이 자동화되지 않았다 — 글자를 소리로 바꾸는 데 작업기억을 쓴다 | 문장을 짧게. 한 문장 = 한 정보. 이해는 유창성 다음이다 |
| 안은문장·관형절("~하는 ~은")의 처리 부담이 크다 | 홑문장 위주. 관형절은 문단당 1개 이하 |
| 생략된 주어를 복원하지 못한다 | 주어 생략 금지. 매 문장 주어를 적는다 |
| 지시어(이것·그것·그곳)의 조응 해결이 어렵다 | 지시어 대신 명사를 다시 쓴다 |
| 선지 4개를 다 읽고 비교하는 부담이 크다 | **3지선다**, 문항 2~3개 |
| 추상 명사·한자어가 아직 안 들어온다 | 한자어는 7급 이하만, 지문당 1개 이하 |

> **웩슬러 센터로서의 근거**: 유창성이 확보되기 전의 독해 지도는 작업기억 용량을 초과시킨다.
> L1이 "따라 읽기 → 유창성 → 그다음 이해"의 순서를 갖는 이유다.

---

## 2. 레벨 이름 — 기획서와 코드가 갈라져 있다

발견한 불일치를 먼저 정리한다.

| 문서/코드 | L1의 의미 |
|---|---|
| `진로독서-웹앱-기획서-v1.md` §5.3 | L1 = **초3~4** (5단계: L1 초3~4 / L2 초5~6 / L3 중등 / L4 고등 / L5 고등 심화) |
| 실제 앱 (`reading/index.html`) | L1 **없음**. L2 = 초3~초6("초등 심화") / L3 = 중등 / L4 = 고등 |

앱이 기획서의 L1·L2를 하나(L2)로 합쳐 구현했고, 그 상태로 12편이 발행됐다.
즉 **기획서 §5.3은 이미 구현과 어긋나 있다.**

**결정: 새 저학년 레벨의 이름은 `L1`(초1~2)로 한다.**
코드 네임스페이스에서 `L1 < L2`가 자연스럽고, 기존 12편의 데이터를 건드리지 않는다.
대신 기획서 §5.3의 레벨 표는 구현에 맞춰 한 줄 고쳐야 한다 — **이 문서가 그 기준이다.**

| 레벨 | 학년 | 화면 라벨 |
|---|---|---|
| **L1** (신설) | 초1~2 | 초등 기초 |
| L2 | 초3~6 | 초등 심화 |
| L3 | 중1~3 | 중등 |
| L4 | 고1~3 | 고등 |

## 3. 지문 규격 (기계 검증)

| 항목 | L1 | (참고) L2 |
|---|---|---|
| 총 글자 수 | **120~350자** | 450~750자 |
| 문단 수 | **2~3문단** | 3~5문단 |
| 문단당 문장 수 | **2~4문장** | 제한 없음 |
| 총 문장 수 | **8~14문장** | — |
| 문장 길이 | **평균 15자 / 최대 25자** | — |
| 어휘 주석(`vocab`) | **2~3개** | 4개 |
| 문항(`questions`) | **2~3개, 3지선다** | 4개, 4지선다 |
| 심화 문항(`challenge`) | **없음** | 2개 권장 |
| 영어 대역(`en`) | **없음** | 없음 |
| 예상 읽기 시간(`minutes`) | **2분** | 4분 |

> 글자 수는 문장 규칙에서 나온 값이다 — 하한 120자 = 최소 8문장 × 평균 15자, 상한 350자 = 최대 14문장 × 최대 25자.
> 이 셋(글자 수·문장 수·문장 길이)은 서로 맞물려 있으니 하나를 바꾸면 나머지도 같이 봐야 한다.
> 파일럿 첫 4주 뒤 완독률과 낭독 완주율로 다시 잡는다.

## 4. 문장 규격

**써야 하는 것**
- 홑문장 위주. `주어 + 목적어 + 서술어`.
- 매 문장에 주어를 쓴다. ("개미는 힘이 세다. **개미는** 자기 몸보다 무거운 것을 든다.")
- 시간·순서는 명시적으로. ("먼저", "그다음", "마지막으로")
- 종결은 `~다` 평서형으로 통일.

**쓰지 않는 것**
- 관형절 겹침: ~~"땅속에 굴을 파고 사는 개미가 먹는 먹이는"~~ → "개미는 땅속에 굴을 판다. 개미는 단 것을 먹는다."
- 주어 생략: ~~"그래서 힘이 세다."~~
- 지시어 조응: ~~"그것은 아주 무겁다."~~ → "그 먹이는 아주 무겁다."
- 피동·사동 중첩: ~~"옮겨지게 된다"~~ → "옮긴다"
- 이중 부정, 삽입구, 괄호 설명

## 5. 어휘 규격

| 항목 | 규칙 |
|---|---|
| 주석 낱말 수 | 2~3개 |
| 한자어 | 지문당 **1개 이하**, **한국어문회 7급 이하**만 (`vocab/hanja-grades.js`로 검증) |
| 뜻풀이(`easy`) | **한 문장, 25자 이내.** 뜻풀이에 더 어려운 낱말을 쓰지 않는다 |
| 추상 명사 | 금지 (개연성·타당성·현상 등) |
| 외래어 | 아이가 이미 아는 것만 (로켓·버스 O / 시스템·프로세스 X) |

> 급수 라벨이 여기서 실제로 쓸모가 생긴다. "7급 이하"는 기계가 판정할 수 있는 유일한 한자 난이도 기준이다.
> 다만 **矛盾·葛藤처럼 2급 글자로 된 낱말은 급수가 아예 없다** — 급수로 거를 수 없으니 강사 검수가 최종 게이트다.

## 6. 끊어 읽기 조각 규격

`paragraphs`는 문단마다 **의미 단위 조각의 배열**이다. 저학년에게는 이 조각이 곧 호흡 단위다.

| 항목 | L1 |
|---|---|
| 한 조각 | **3~8자 (1~2어절)** |
| 문장당 조각 수 | **2~3개** |
| 조각 끝 | 공백 포함 (`"개미는 "`), 문장 끝 조각은 마침표까지 (`"힘이 세다. "`) |

```json
["개미는 ", "힘이 세다. ", "개미는 ", "자기 몸보다 ", "무거운 것을 ", "든다. "]
```

> 조각을 더 잘게 쪼개지 말 것. 어절 하나하나로 끊으면 의미 덩어리가 아니라 낱말 나열이 된다.

## 7. 문항 규격

| 항목 | L1 |
|---|---|
| 문항 수 | 2~3개 |
| 선지 수 | **3개** |
| 허용 유형 | `main`(중심 내용), `detail`(세부 내용) **만** |
| 금지 유형 | `infer`, `critical`, `vocab`, `apply` |
| 발문 | 20자 이내, 한 문장 |
| 선지 | 각 15자 이내, 길이를 서로 비슷하게 |
| 해설(`explain`) | 한 문장. "몇 번째 문단에 나와요"까지 |
| 근거 문단(`evidencePara`) | 필수 |

> `infer`를 빼는 이유: 초1~2에게 추론 문항은 독해력이 아니라 **문항 읽기 능력**을 잰다.
> 아이가 틀린 게 아니라 문항이 어려운 것이고, 그러면 지표가 오염된다.

## 8. 앱 동작 — L1에서 달라지는 것

| 기능 | L1 동작 | 이유 |
|---|---|---|
| **따라 읽기(TTS)** | **기본 켜짐**, 속도 "아주 천천히" | L1의 핵심 훈련. 이미 구현됨 |
| 끊어 읽기 표시 | 기본 켜짐 | `S.prefs.chunk`에 `L1:true` 추가 |
| 글꼴 크기 | 기본 1.15배 | 현재 기본 1.0, 조절 범위 0.9~1.3 안 |
| 인출 게이트 문구 | "이 낱말 뜻, 알아요?" / **[몰라요] [알아요]** | 현재 문구는 초3 이상 기준 |
| 완독 후 어휘 체크 | **2문항, 3지선다** | 현재 3문항 4지선다 |
| 자동 읽기 속도 | 기본 "천천히" | — |
| 영어 보기 토글 | 숨김 | L1에 영어 대역 없음 |
| 심화 문제 버튼 | 숨김 | `challenge` 없음 |
| 탐구보고서 | 숨김 | 초1~2 대상 아님 |

## 9. 데이터 스키마

기존 구조 그대로, `levels`에 `L1` 키를 더한다.

```json
{
  "id": "ant-strength",
  "category": "science",
  "careers": ["nat", "bio"],
  "status": "published",
  "sources": [{ "title": "국립생물자원관", "url": "https://www.nibr.go.kr/" }],
  "levels": {
    "L1": {
      "title": "개미는 왜 힘이 셀까",
      "minutes": 2,
      "paragraphs": [
        ["개미는 ", "힘이 세다. ", "개미는 ", "자기 몸보다 ", "무거운 것을 ", "든다. ", "개미는 ", "먹이를 ", "집까지 ", "옮긴다. "],
        ["개미의 ", "다리는 ", "아주 가늘다. ", "그런데 ", "개미는 ", "몸이 작다. ", "작은 몸은 ", "가벼운 힘으로 ", "움직인다. "],
        ["개미는 ", "여럿이 ", "함께 산다. ", "개미들은 ", "힘을 모은다. ", "그래서 ", "큰 먹이도 ", "옮긴다. "]
      ],
      "vocab": [
        { "word": "가늘다", "easy": "굵지 않고 얇다" },
        { "word": "먹이", "easy": "동물이 먹는 것" }
      ],
      "questions": [
        { "type": "main", "q": "이 글은 무엇에 대한 글인가요?",
          "choices": ["개미의 힘", "개미의 색깔", "개미의 집"],
          "answer": 0, "explain": "글 전체가 개미가 힘이 센 까닭을 설명해요.", "evidencePara": 0 },
        { "type": "detail", "q": "개미의 다리는 어떤가요?",
          "choices": ["아주 굵다", "아주 가늘다", "아주 짧다"],
          "answer": 1, "explain": "두 번째 문단에 나와요.", "evidencePara": 1 }
      ]
    },
    "L2": { "…": "기존 그대로" }
  }
}
```

> 위 예시는 실제로 `content.test.cjs`에 통과시켜 본 것이다 — 144자, 3문단, 10문장, 최장 문장 14자, 경고 0건.
> 새 지문을 쓸 때 이 모양을 그대로 복사해서 시작하면 된다.

- `L1`은 **선택 필드**다. 없어도 검증을 통과한다 → 기존 12편을 건드리지 않는다.
- `L1`에는 `challenge` · `en` · `enseg` · `envocab`을 넣지 않는다.

## 11. 아직 없는 것 · 열어 둔 결정

1. **삽화** — 초1~2 지문에 그림이 없는 건 사실상 결함이다. 현재 앱에는 이미지 슬롯 자체가 없다.
   문단당 삽화 1장을 넣으려면 스키마(`illust`)와 렌더러, 저작권 처리가 함께 필요하다. **Phase 2.**
2. **진단 지문** — 온보딩의 `diagnostics`에 L1용 1편이 필요하다(문항 4개, 3지선다).
3. **학년 매핑** — `GRADES`에 `e1`·`e2`를 추가하고 `LEVEL_OF`에 `{e1:'L1', e2:'L1'}`을 넣어야
   저학년이 온보딩을 통과할 수 있다. **지문이 최소 4편 생기기 전에는 열지 않는다** — 열어 두고 읽을 글이 없으면 첫인상을 잃는다.
4. **발음 채점** — 넣지 않는다. 아동 음성 인식률이 낮아 "잘 읽었는데 틀렸다"가 한 번 뜨면 저학년은 그 자리에서 이탈한다.
5. **소재 범위** — 진로 연계(`careers`)를 초1~2에도 붙일지. 붙이되 화면에는 숨기는 쪽을 권한다(데이터는 쌓고 압박은 주지 않기).

## 12. 제작 체크리스트 (강사·집필자용)

지문 1편을 넘기기 전에 이 열 줄을 확인한다.

- [ ] 소리 내어 읽어 봤다. 한 번에 안 읽히는 문장이 없다.
- [ ] 가장 긴 문장이 25자 이하다.
- [ ] 주어를 생략한 문장이 없다.
- [ ] "이것·그것·그곳"이 없다.
- [ ] 관형절이 문단당 1개 이하다.
- [ ] 한자어가 1개 이하이고, 7급 이하다.
- [ ] 뜻풀이에 지문보다 어려운 낱말이 없다.
- [ ] 문항 선지가 3개이고, 길이가 서로 비슷하다.
- [ ] 문항 유형이 `main`·`detail`뿐이다.
- [ ] `node reading/content.test.cjs`가 경고 없이 통과한다.
