## 1. 손대지 말 것 — 먼저 읽는다

### 금고(A.5) 코드는 시작하지 않는다

정본은 `docs/로컬-서버-외부공개-터널.md` **§1.5**(56행부터 200행까지)다. 그 절의 **소제목 일곱 개**
(62·74·81·97·143·173·187행)가 설계 전부이고, 그중 둘이 관문이다. 201행 `### A 를 코드로 강제한다 —
WB_ADMIN_ONLY` 부터는 **§1.5 가 아니다**(결정 A 의 관리 전용 모드이고 금고와 다른 얘기다).

- **「금고가 주는 것과 주지 않는 것」** — 금고는 자료가 *쉬는 곳*(at rest)만 우리 PC 로 옮긴다.
  **전송 경로에서 Cloudflare 를 빼지 못한다**(학생이 열 때마다 팩이 워커를 지난다). 원장이 "아예
  만지지 않는다"를 기대했다면 금고가 아니라 B(전부 이관)다. **이 구분을 원장에게 확인받지 못했다.**
- **「남은 것 (코드 쓰기 전)」** — 원장 확인 4건. 하나도 안 끝났다.

### 운영 KV 의 기존 발문을 지우지 않는다

`GET/POST /api/naesin-ko/admin/scrub`(`reading-server/naesin-ko-api.mjs:506`)가 준비돼 있고
GET 은 세어만 본다. **운영 데이터 삭제는 원장 확인 사항**(`CLAUDE.md` 작업 규칙 7)이라 아직
누르지 않았다. 코덱스도 누르지 않는다.

### 저장소 전체 목록에서 집지 말 것

`코덱스-인수인계-남은작업-2026-10-11.md` 의 **「그 뒤 바뀐 것 — 집기 전에 이것부터 읽는다」**

## 2. 지금 어떻게 돼 있는가

### 접합부 — 금고가 붙을 자리는 한 군데다

```
worker.mjs:255   function naesinKoStore(env) { … }     ← 금고가 갈아 끼울 자리
worker.mjs:794   if (p.startsWith('/api/naesin-ko/'))  ← 유일한 호출자
server.mjs:228   const naesinKoStore = { … }           ← 로컬 서버 쪽 같은 계약
```

`naesin-ko-api.mjs` 가 쓰는 `store.*` 메서드는 **21개**다. 그중 금고로 가는 **라이선스 6칸**:

| 칸 | KV 키 |
|---|---|
| `getPack` / `putPack` | `naesinko:pack:<id>` |
| `getPackIds` / `putPackIds` | `naesinko:packs` |
| `getPending` / `putPending` | `naesinko:pending:<id>` |

나머지는 학생·교사 기록이라 **KV 에 그대로 남는다**. 단 **오버레이 2칸은 미정**이다(§1.5 의
「어느 칸이 금고로 가는가 — 원장 결정 대기」). 오버레이의 `answers[]` 에 문항 정답 문자열이
들어가므로, 정답을 라이선스 자료로 보면 6칸이 아니라 **8칸**이다. 설계 심사는 8칸을 권했다.

### 밟으면 터지는 자리 — 관문과 그 **구멍**

관문을 적을 때는 **무엇을 못 지키는지**까지 적는다. "검사가 있으니 안심"이 가장 비싼 오해다.

**① `store.*` 를 하나 더하면 두 어댑터에 같이** 넣어야 한다 — `override.test.mjs:136~` 가
`naesinKoStore`(워커 `:255` / 로컬 `:228`) **블록 안에서** 찾는다.

> ⚠️ **2026-10-13 에 이 관문을 고쳤다.** 전에는 파일 **전체**에서 `이름:` 문자열을 찾았다. 그런데
> `getPack`·`putPack`·`getPackIds`·`putPackIds` 는 영어 내신·국어·하루 어댑터에 **다 있어서**
> (`worker.mjs` 에 각 3번), 국어 어댑터에서 한 줄을 지워도 영어 쪽 이름이 걸려 **초록이었다.**
> 실측으로 확인했다 — 국어 `getPack:` 을 지우고 돌려도 통과했다. **금고가 갈아 끼울 네 칸이 바로
> 그것들이라, 이 관문이 정작 금고 작업에서 아무것도 지켜 주지 않는 상태였다.** 지금은 블록 안만
> 보고(스프레드 `...withPortalFamilies()` 는 따라간다), 지우면 빨간다.

> ⚠️ **금고 메서드는 `store.이름(...)` 직접 호출로만 쓴다.** 수집기는 그 모양만 센다 —
> **옵셔널 호출(`store.x?.()`)과 구조분해(`const {x} = store`)는 검사를 통째로 피한다.**
> "있으면 쓴다" 식 옵셔널 호출이 금고 어댑터에 자연스러운 모양이라 밟기 쉽다. 그래서
> 2026-10-13 에 **라우터가 그 두 모양을 쓰면 빨간다**는 검사를 같이 넣었다.

**② 워커 import 그래프에 `node:` 모듈을 넣을 수 없다.** 암호는 `crypto.subtle` 로 한다(선례
`admin-auth.mjs:9` · `vocab-api.mjs:481`, 상수시간 비교는 `admin-auth.mjs:12-18` `safeEqual`).
`wrangler.toml` 에 `compatibility_flags` 가 없다(`compatibility_date` 만) — **`nodejs_compat` 이
꺼져 있어** `node:` 모듈은 런타임에 없다.

> ⚠️ **`override.test.mjs` 는 `from 'node:…'` 모양만 잡는다. 세 갈래가 피해 간다** —
> ⒜ 동적 `await import('node:crypto')` ⒝ `from` 없는 부수효과 `import 'node:crypto';`
> ⒞ **브라우저 공용 순수 로직 모듈 안의 `require('node:crypto')`**(`:109` 가 `typeof module`
> 가드가 있는 파일을 면제한다 — 그래프 안에 그런 파일이 14개 있다: `naesin/pack-check.js`·
> `hanja/book-check.js`·`haru/*` 9개·`chunk/sched.js`·`letter/letter.js`).
>
> 피해 가면 어떻게 되는가 — **"배포 성공 + 운영만 500" 이 아니다.**
> `deploy-reading.yml:197-204` 의 「번들에 Node 전용 모듈이 없는지」 grep 이 `wrangler deploy`
> **앞**에 있어 **배포 잡이 빨갛게 멈춘다**. 결과는 **운영이 옛 코드에 그대로 머무는 것**이고,

### ① `/admin/scrub` 에 관리 웹 버튼 (S)

#441 이 라우트만 만들었고 화면이 없다. 지금은 원장이 PIN 으로 직접 호출해야 쓸 수 있다.
"먼저 GET 으로 규모를 보고 POST 로 지운다"는 흐름이라 **버튼 두 개짜리 카드**가 맞다.

- 자리: `reading-server/public/naesin-ko-admin.html` (카드 추가)
- 라우트: `GET /api/naesin-ko/admin/scrub` → `{dryRun:true, records, touched, labels}` ·
  `POST` → `{dryRun:false, …}`
- 지우기는 **되돌릴 수 없다.** 버튼에 그 사실과 "먼저 세어 보기"를 화면에 적는다.
  GET 결과를 보여 준 뒤에만 POST 버튼이 열리게 하는 쪽이 안전하다.

**밟기 쉬운 함정 넷** — 이 넷을 모르면 코덱스가 바로 걸린다.

1. **관리 관문은 `naesin-ko-api.mjs:253` 의 한 줄**(`if (!who.admin) return j(403, …)`)이고
   **학생 라우트 전부를 지난 뒤**에 있다. 새 라우트를 그 줄 **위**에 쓰면 학생 토큰으로 남의
   기록을 지울 수 있다. scrub 라우트는 이미 그 줄 아래(`:506`)에 있으니 화면만 만들면 된다.
2. 그 관문은 **403** 을 돌려주는데 관리 웹의 `api()`(`naesin-ko-admin.html:121-130`)는
   **401 만** 자동 처리한다(토큰 폐기·재로그인). 403 은 `throw` 로만 보이므로 카드가 직접
   잡아 문구를 띄워야 한다.
3. `api()` 가 경로 앞에 **`/api` 를 붙인다** — 호출은 `api('/naesin-ko/admin/scrub')` 이다.
4. ⚠️ **이 파일은 `naesin-ko/app.test.cjs:106-118` 의 정적 검사를 받는다.** `:115` 가
   `$('#btnRbSave').onclick` 부터 **1400자 창**을 잘라 그 안에서 `confirm(` 이 `a.click()` 보다
   앞인지 본다. 새 코드를 그 블록 **안이나 사이**에 끼우면 `a.click()` 이 창 밖으로 밀려
   **scrub 와 무관한 루브릭 내려받기 검사가 빨간다**. 새 카드는 그 블록 **밖**에 붙인다.
   그리고 `:114` 가 파일에 「금고」 문구를 요구하므로 지우지 않는다.

### ② 지문 보드 카드 + 렌더러 모듈 분리 (M)

저장소 전체 목록의 국어브레인 2건 중 하나다. 그 목록의 항목 본문에 자리가 적혀 있지만 **행번호가

꺼낼 것은 `naesin-ko/index.html` 안에 인라인인 넷이다 — `markUp`(`:808`) ·

## 4. 막힌 것 — 원장 결정이 선행

§1.5 「남은 것」과 같은 내용이다. 코덱스가 풀 수 없다.

| | 무엇을 정해야 하는가 | 안 정하면 |
|---|---|---|
| 1 | 금고는 **at rest 한정**이다 — 그것이 의도인가 | 금고를 다 만든 뒤 "이게 아니었다"가 될 수 있다 |
| 2 | **오버레이 2칸**을 금고로 보낼 것인가(6칸 ↔ 8칸) | 나중에 계약이 "원내 디스크에만"을 요구하면 처음부터 다시 한다 |
| 3 | 집·학원 PC 를 **동시에 켜 둘 시간대**가 실제로 있는가 | §1.5 ③의 '쓰기 1대 + 지연 복제'가 선택이 아니라 전제가 된다 |
| 4 | **운영 KV 기존 발문 청소** 승인 | 어제까지 쌓인 발문이 KV 에 남는다(야간 백업은 10일이면 밀려 나간다) |

§1.5 「남은 것」의 나머지 셋은 **성격이 다르다 — 셋 다 '원장 결정 선행'이 아니다.**

| | 무엇 | 언제 할 수 있는가 |
|---|---|---|
| 2번 | 관리 웹(`/admin/*`)에도 Access | **금고 호스트 결정이 선행**(§1.5 ①) |
| 3번 | 학생 기기 청소 수단 | **지금 바로** — 위 §3④ 로 올려 두었다 |
| 4번 | 국어 `state` 화이트리스트 | 2026-10-14 구현: 실제 앱 생성 필드를 대조한 `state`·별도 `summary` 허용 목록은 `naesin-ko/README.md` 「서버 API」에 있다. 쓰기 전 형식·UTF-8 예산 검사, 조회 복사만 필터. 깨진 서버 백업은 저장·기기 청소를 보류해 양쪽 원본을 보존한다. 금고·기존 운영 기록 청소는 별개다 |

그리고 §1.5 자체가 밀린 행번호를 갖고 있었다 — 2026-10-13 에 둘을 고쳤다
(`worker.mjs:1135`→`1151`, 오버레이 `naesin-ko-api.mjs:390-394`→`415-424`). **그 문서의 다른
행번호도 그대로 믿지 말고 `grep -n` 으로 다시 찾는다.**

## 5. 작업 방식 — 이 줄기에서 지킨 것

루트 `CLAUDE.md` 규칙에 더해, 이 줄기에서 쓴 방식이다. 이어받을 때 같이 지키면 좋다.

- **테스트가 실제로 깨지는지 확인한다.** 새 검사를 넣은 뒤 **일부러 되돌려 빨간 것을 보고** 다시
  돌려놓는다. `naesin-ko/app.test.cjs` 8개와 `override.test.mjs` 의 몸통 상한 검사는 그렇게 확인했다.
- **손으로 눌러서는 못 만나는 결함은 코드 모양으로 못 박는다.** 배경 재시도가 공부 도중 팩을
  갈아 끼우는 결함은 몇 분 뒤에 일어나 손으로는 재현되지 않는다 — `app.test.cjs` 가 "팩은
  `applyPack` 한 곳에서만 끼운다"를 정적으로 검사한다.
- **운영 주소로 확인한다.** 배포 뒤 `https://wb-reading.whdudwns33.workers.dev` 에서
  ① 새 코드가 실제로 서는지 ② 인증 없이 아무것도 안 나가는지(`401`) ③ 형제 앱 8개가 멀쩡한지를
  본다. 토큰이 필요한 판정(배정된/안 배정된 학생)은 운영에서 밖에서 확인할 수 없으므로 로컬에
  같은 코드를 띄워 학생 둘로 밟는다.
- **자체 창작 데이터만 쓴다.** 검증에 쓴 것은 `naesin-ko/pack-sample.json` 복제본뿐이다
  (절대규칙 1).
