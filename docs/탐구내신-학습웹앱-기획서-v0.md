# 탐구브레인 — 사회·과학 내신 시험대비 앱 기획서 v0

> 2026-11-12 초안. 원장 질문 라운드 1·2(Q1~Q14)에서 정해진 것을 옮겼다. 정해지지 않은 것은 §7.4 에 따로 적었다.
> 내신브레인(영어)·국어브레인(국어)의 **형제 앱**이다. 같은 서버, 같은 학생 토큰을 쓴다.

## 1. 한 줄 요약

족보닷컴에서 구매한 사회·과학 시험대비 자료를 **지면 그대로** 앱에 넣고, 재원생이 화면에서 풀면 앱이 채점·오답·시험 계획을 맡는 **원내 전용** 학습 웹앱이다. 영어·국어와 같은 계정에서 시험 준비를 한곳에 모으려고 만든다.

## 3. 배경

- 지금 사회·과학 자료는 인쇄해서 나눠 주고 끝난다. 누가 얼마나 풀었고 무엇을 틀렸는지 남지 않는다.
- 족보닷컴 문제은행에도 배포·채점·오답 기능이 있다. 그래도 따로 만드는 이유는 영어·국어와 **같은 앱·같은 계정·같은 시험 계획**에 모으기 위해서다(Q1).
- 족보닷컴 자료(2026-11-12 사이트 확인): 과학은 출판사 구분 없이 ‘공통’ 한 벌, 사회는 ‘사회①’·‘역사①’처럼 과목으로 나뉜다. 과목마다 4단계 틀이 같다 — 개념학습(요점정리·암기노트·대표유형) → 단원별 학습(기본·발전, 회당 25문제) → 실전대비(최다빈출 공략) → 직전대비(요약노트·꼭 나오는 문제·파이널 모의고사).
- 사용 범위: **원내에서만 쓴다**(원장, 2026-11-12). 족보닷컴 약관(2026-05-17판 제18조)은 승낙 없는 제3자 제공을 금지한다.

## 4. 목표

시험 범위의 족보닷컴 문제지를 학생이 앱에서 끝까지 풀고, 틀린 문제를 시험 전에 다시 맞히게 한다.

핵심 결과(첫 시험철, 수치는 가정 — §7.4):
1. 배정한 문제지의 80% 이상이 제출된다.
2. 틀린 문제의 70% 이상이 시험 전날까지 다시 풀려 지워진다.
3. 강사가 문제지 한 회를 올려 학생에게 여는 데 5분이 넘지 않는다.

## 5. 누구를 위한 것인가

- **학생(중등 재원생)**: 시험 범위 문제를 풀고, 무엇을 틀렸는지 알고, 시험 전에 다시 풀어야 한다.
- **강사·원장**: 범위에 맞는 자료를 나눠 주고, 누가 얼마나 했는지 보고, 틀린 곳을 수업에서 다뤄야 한다.

제약: 자료를 고치지 않는다. 인증한 재원생에게만 보인다. 자료는 저장소에 넣지 않는다.

## 6. 무엇이 좋아지는가

**학생**
- 왜: 시험 범위를 빠짐없이 풀고 틀린 것을 다시 맞히고 싶다.
- 지금: 인쇄물을 풀고 스스로 채점한다. 틀린 문제가 종이 더미에 묻힌다.
- 어떻게: 지면을 화면에서 보고 답안 칸에 답을 넣는다. 제출하면 채점되고 틀린 문제의 해설 쪽이 열린다.
- 그 뒤: 오답이 한 목록에 모이고, 다른 날 다시 맞히면 지워진다. 시험일까지 오늘 할 일이 보인다.
- 대안: 인쇄물, 족보닷컴 앱. 우리 앱은 영어·국어와 같은 곳에서 학원이 정한 범위·순서대로 한다.

**강사·원장**
- 왜: 반 전체의 진도와 약한 단원을 알고 수업을 맞추고 싶다.
- 지금: 채점한 종이를 걷어 봐야 안다.
- 어떻게: 관리 웹에서 자료 올리기 → 정답 확인 → 시험·과제 배정 → 제출·정답률·오답 보기.
- 그 뒤: 수업 전에 많이 틀린 번호를 안다.
- 대안: 족보닷컴 문제은행의 관리 기능. 우리 것은 영어·국어와 한 화면에서 본다.

한 문장: **인쇄해서 나눠 주던 족보닷컴 사회·과학 자료를, 고치지 않고 그대로, 채점과 오답과 시험 계획이 붙은 화면으로 옮긴다.**

## 7. 해법

### 7.1 흐름

- 학생 탭 다섯 개(Q13): **오늘**(할 일) · **개념**(요점정리·암기노트·요약노트) · **문제**(단계별 문제지) · **오답** · **성취도**.
- 풀이 화면(Q8): 왼쪽에 원본 쪽, 오른쪽에 답안 칸(①~⑤, 단답, 서술). 태블릿·PC 가 기본이고 휴대폰은 지면을 확대해서 본다.

### 7.2 첫 판에 꼭 넣는 것

1. **지면 그대로 보기**(Q2): 자료 PDF 의 쪽을 그림으로 보여 준다. 글자로 다시 쓰지 않는다.
   2026-11-13 원장 지시로 바뀜: 국어브레인처럼 **한 문제씩** 푼다 — 쪽 그림에서 그 문항 영역만 잘라 보여 주되 순서는 지면 그대로, 섞지 않는다. 영역을 못 잡은 문제지는 쪽 화면.
2. **정답표**(Q9): 올릴 때 파일의 정답 쪽에서 읽어 오고, 강사가 확인해야 학생에게 열린다. 읽히지 않으면 번호별로 직접 넣는다.
3. **제출 뒤 채점**(Q10): 한 회를 다 풀고 제출하면 채점한다. 틀린 문제의 해설 쪽을 원본 그대로 보여 준다. 제출 전에는 정답·해설 쪽을 서버가 내려 주지 않는다.
4. **서술형**(Q11): 학생이 쓰고 제출 → 모범답안 보기 → 스스로 표시 → 강사가 확정. AI 채점 없음.
5. **오답 다시 풀기**(Q12): 틀린 번호를 모으고, 다른 날 그 쪽을 열어 해당 번호만 다시 답한다. 맞히면 지워진다.
6. **시험 계획**: 학교·시험일·범위 단원을 등록하면 4단계 순서와 강사 과제로 ‘오늘’을 채운다.
7. **관리 웹**: 자료 올리기 · 정답 확인 · 시험 등록 · 과제 배정 · 제출과 정답률 보기.

### 7.3 기술

- 자리(Q6): `wb-site/` 안의 새 폴더와 `reading-server/` 의 새 라우트 파일 하나. 국어브레인 파일은 고치지 않는다.
- 자료는 관리 웹 업로드 → 서버 저장소로만 들어간다. 저장소(public)에는 직접 만든 가상 문제지만 둔다.
- PDF → 쪽 그림 변환과 정답 읽기는 로컬 오프라인 도구로 한다. 구매 자료를 외부 AI API 로 보내지 않는다(국어 기획서 §1.5 원칙).
- 화면은 국어브레인의 색·글자·부품을 그대로 따른다.

### 7.4 가정과 아직 모르는 것

- **무료 견본으로 확인한 것(2026-11-12)**: 자료는 A4 PDF 이고 문제지는 2단, 한 쪽에 4~5문제다. 복사 금지 플래그가 있지만 글자층은 읽힌다. 정답·해설은 같은 파일 뒤쪽에 “1) 정답 ① 해설 …” 꼴로 있다. **그런데 정답의 동그라미 숫자(①)가 글자층에서 빠진다**(pdftotext 실측). 그래서 Q9 의 기본은 **강사가 번호별로 넣기**(25문제 한 회에 1~2분)로 두고, 자동 읽기는 실제 자료에서 PyMuPDF 로 한 번 더 시험해 되면 붙인다.
- 2단 지면은 휴대폰에서 작다. 한 단씩 확대해 보여 주는 보기를 넣는다(지면을 고치지 않고 보는 범위만 바꾼다).
- 실제 문제지(‘편집’형)는 **지금 계정에 내려받기 권한이 없어** 받아 보지 못했다. 견본과 틀이 같은지는 이용권이 생긴 뒤 확인한다.
- 쪽 그림의 용량과 서버 저장 한도(국어 팩은 4MB 제한) — 실제 파일로 재 봐야 한다.
- §4 의 수치(80% · 70% · 5분)는 가정이다. 원장이 고친다.
- 이용권이 끝나면 올린 자료를 지우는 절차 — 국어 기획서 §13-1 과 같이 정한다.
- 앱 이름 ‘탐구브레인’(Q14)은 바꿀 수 있다.

## 8. 내놓는 순서

- **첫 판**: 중2 과학 2학기 기말 범위(7 전기와 자기 · 8 별과 우주)(Q4). 위 7.2 의 일곱 가지.
- **다음**: 사회, 다른 학년. 역사·도덕은 같은 틀에 자료만 올린다(Q3).
- **하지 않는 것**: 문항 자동 생성, 문항 순서 섞기, AI 채점, 자료 문구 고치기, 원외 배포, 자동 문자·카톡 발송.
- 걸리는 시간(눈대중): 파일 형식 확인 뒤 가상 문제지로 첫 판을 만들고, 실제 자료 한 단원으로 강사가 써 본 다음 범위를 넓힌다.
