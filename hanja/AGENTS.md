# hanja/ — 어휘브레인 작업 인수인계 (Codex · Claude Code 공용)

> **저장 경로는 유지한다.** 표시 이름은 어휘브레인(2026-09), 자리는 `hanja/` 그대로다 — 폴더·주소 `/hanja/`·
> KV 키 `hanja:*`·기기 키 `wbhj.v1`·API `/api/hanja/*` 는 건드리지 않는다. 바꾸면 QR·배정·학생 기기 기록이 끊긴다.

한글 어휘가 약한 학생이 **추천 교재 한 권(단어장)을 단원 순서대로 시험 보고, 부족한 낱말을 배우고, 다시 확인하는 앱**.
한자는 어휘 이해를 돕는 선택 기능이며, 급수 교재는 별도의 한자 트랙이다. 영어는 다루지 않는다.
구매 교재 본문은 **저장소에 없다** — 관리 웹 업로드로 KV 에만 산다.

**이 앱의 1차 목표는 교재 공부를 단원 시험으로 확인하는 것이다.** 센터에서 종이 교재(어휘가 독해다)로 공부하라고
보낸 학생의 공부가 붙었는지 확인하고, 앱의 낱말 학습·복습으로 부족한 어휘를 보충한다. 이 순서를 뒤집지 않는다.

**읽는 순서**: 저장소 루트 `AGENTS.md`(= `CLAUDE.md`, 최상위 규칙) → `hanja/README.md`(이 앱의 정본 문서 —
파일별 역할·단어장 스키마·API·화면 동작이 전부 여기 있다) → 이 문서(지금 상태와 조용히 깨지는 자리) → 고칠 파일.

## 2. 승인 순서와 남은 일 (2026-09-22)

**1~4번은 구현 완료·검증 중이며, 배포 완료와는 구별한다. 5번 예문 확장은 검수 자료가 없어 미실행이다.**

1. **점수 정확성과 어휘 출제** — 어휘 시험에 한자 표기·조립 문항이 섞이지 않게 하고, 보조 한자 시험이 어휘 점수를
   덮지 않게 한다. 실제 출제 범위·힌트 사용을 표시하고 일부 표본 정답을 단원 전체 숙달로 부르지 않는다.
   당일 즉시 반복만으로 장기 기억 단계가 올라가지 않게 한다.
2. **어휘 중심 홈·내 교재·낱말 카드** — 추천 교재와 단원을 먼저 보여 준다. 학생 경로는 학원 QR 연동 → 내 교재 →
   선생님 추천 또는 보유 교재 선택 → 단원 → 시험·낱말 학습. 카드는 낱말·뜻·예문을 먼저, 한자 설명은 선택으로 둔다.
   **초등 3학년을 교재 3단계로 자동 치환하지 않는다.** 교재·단원 배정은 선생님이 정한다.
3. **오답 학습 → 재확인** — 시험에서 틀린 낱말을 바로 배우고 그 낱말만 다시 확인한다. 이전에 답한 낱말이라는 이유로
   보충 학습에서 빠지지 않게 하고, 재확인 결과가 원래 단원 시험 점수를 덮지 않게 한다.
4. **교사 현황** — 미시작·단원 시험 결과·보충 학습을 구별한다. 재배정 전 점수를 새 과제의 결과로 읽지 않고,
   실제 적용되는 학생·반·전체 과제 우선순위를 진도표에도 적용한다.
5. **검수된 예문** — 예문이 없으면 문맥 빈칸 문항은 열리지 않는다. 출처·이용 범위를 확인하고 원장이 검수한 예문을
   교재 어휘에 추가한다. 구매 교재 원문은 KV 에만 둔다.

위 학습 흐름을 먼저 완성한 뒤 교과 어휘 중등 확장, 급수 6·5·4급, 급수 모의고사(문항 유형·세션·리포트),
한자 교재의 뜻 없는 예시 낱말 보충, 실제 쓰기 파일럿의 `trace.js` 문턱 조정, 획순 변이체 검수를 진행한다.
급수 자료는 글자마다 훈음·획수·예시 낱말 두 개를 검수하고, 없는 획순을 비슷한 글자로 대신하지 않는다(§3-4).

**완료한 자료 검증 / 운영 반영은 별도** — 2026-09-22 한국어문회 공식 「배정한자 7급」 HWP와 대조해
`books/geupsu-7.json` 추가 100자의 누락·초과·중복 0을 확인했다(8급 50자와 합쳐 누적 150자, 7급II 포함).
출처는 `README.md` 자체 단어장 절. 百의 예시 백지장→백만, 8급 一의 일요일→일주일도 고쳤다.
`books.test.cjs`가 정확한 목록과 재검사 왕복을 지킨다. **두 JSON을 검증 후 같은 id로 재업로드하고 되읽기 확인하는 일은 남아 있다.**

## 3. 조용히 깨지는 자리

1. **뜻 없는 낱말을 넣지 않는다.** 검사기가 막는다(`뜻(meaning)이 없어요`) — 막는 것이 맞다. 교재에 뜻이 없으면
   **지어내지 말고** 글자의 `words`(예시 낱말 목록)로 넣는다. 지어낸 뜻은 교재 단어장이 아니고, 학생이 그것을 외운다.
2. **호환 한자(U+F900~)를 정규화한다.** 廉·不·力 같은 글자는 겉모습이 같아도 코드가 다른 판본이 있다. 그대로 두면
   획순 사전이 안 붙고 기억 기록(`c:<글자>`)이 글자마다 갈린다. EBS 엑셀에 22자가 섞여 있었다. 새 자료를 넣을 때
   한자 칸은 NFKC 로 모은다.
3. **목록(`hanja:books`)은 한 키에 여러 항목이 든 캐시다.** 고치는 자리는 모두 `editIndex` 하나를 지난다. KV 의 함정이 둘이다.
   - **읽기가 옛 값일 수 있다**(지역마다 최대 60초). 바꾼 직후 목록이 옛 값을 보여 줄 수 있고 잠시 뒤 새로 고치면 맞다.
   - **그 옛 값 위에 쓰면 진짜로 잃는다.** 12권을 한 권씩 연달아 바꾸다 실제로 겪었다(성공 응답 12번, 남은 것 2건).
   그래서 여러 권은 **한 번의 쓰기로** 고친다(`POST /admin/scope {ids, scope}`). 되읽기는 확인(`applied`)까지만 하고
   **되쓰지 않는다** — 확인이 늦은 것을 고치려다 남의 변경을 지운다. `applied:false` 는 「틀렸다」가 아니라 「아직 확인 못 했다」다.
4. **획순 데이터가 없는 글자의 획순을 채점하지 않는다.** 없는 데이터로 틀렸다고 하면 **맞게 쓴 획순도 틀렸다**고 하게 된다.
   사전에 없는 글자는 모양 모드(안내 글자 덮음률)로만 쓴다. 비슷한 변이체(眞→真)로 바꿔 넣지 않는다 — 글자 모양이 다르다.
5. **낱말 id 는 내용 기반(`낱말|한자`)이다.** 순번(w001…)으로 바꾸면 교재를 고쳐 다시 올릴 때 뒤의 id 가 전부 밀려
   학생 기억 기록이 다른 낱말을 가리킨다. 바뀐 id 는 서버가 옛 단어장과 대조해 `hanja:remap:<id>` 로 잇고
   학생 앱이 `GET /book` 의 `remap` 으로 옮긴다.
6. **서버 라우트는 두 곳에 배선한다** — `reading-server/worker.mjs`(운영)와 `server.mjs`(로컬). 한쪽만 고치면
   로컬에서 되는 것만 확인하고 배포해 운영에서 다르게 돈다. `override.test.mjs` 가 짝을 검사한다.
7. **응답은 래핑 계약을 따른다** — `/books` → `{books, updatedAt}` · `/book` → `{book, updatedAt, remap}` ·
   `/task` → `{task, scope}` · `/strokes` → `{strokes, updatedAt}`. 클라이언트와 같이 고친다.
8. **검사 규칙은 `book-check.js` 하나다.** 관리 업로드 관문·미리보기·CLI(`book-validate.mjs`)가 모두 이것을 부른다.
   규칙을 다른 곳에 베끼면 "CLI 는 통과인데 업로드가 막히는" 불일치가 생긴다.
9. **`book-check.js`·`srs.js`·`quiz.js`·`trace.js`·`bridge.js` 는 브라우저와 Node 가 같이 쓴다.**
   `'use strict'` + IIFE + `module.exports` 가드. `fs`·`process` 를 넣으면 학생 화면이 통째로 죽는다.
10. **AI 연상은 자체 단어장(`source:'own'`)에서만.** 화면 버튼과 호출 직전 두 곳에서 `aiAllowed` 를 본다. 한 곳만 고치면
    교재 뜻 문장이 외부 AI 로 나간다. 체험 단어장·진로독서 어휘장이 자체, 올린 문제집은 교재가 기본이다.
11. **학생이 올린 값은 두 겹으로 막는다** — 서버가 화이트리스트로 정규화하고 화면이 다시 이스케이프한다.
    강사 화면은 학생 기기가 올린 값을 그리는 자리다.
12. **덤프·퇴원**: 백업 덤프(`dumpHanja`)에 단어장 본문을 싣지 않는다(라이선스). 퇴원은 `state`·`summary`·`assign`·`push`
    네 키만 지운다 — 단어장은 남는다.
13. **검사기는 자기 산출물을 다시 검사받는다.** 앱은 서버에서 받은 단어장(이미 검사를 거친 것)을 **열 때마다**
    `checkBook` 을 한 번 더 돌린다. 그래서 `checkBook(checkBook(x))` 가 성립해야 한다 — 오늘 이 자리가 두 번 깨졌다:
    ① 정규화가 `derived` 표시를 안 옮겨 참고 글자가 단원 항목으로 올라섰다(1강이 8문항 대신 17문항, 진도표와 어긋남).
    ② 훈음 없는 끌어낸 글자를 오류로 막아 **중학·수능 교재가 학생 화면에서 통째로 사라졌다**(재검사 오류 587·627건 →
    `installBook` 이 null). 새 필드를 결과로 안 옮기거나 새 필수 검사를 더할 때 **이 왕복을 먼저 생각한다.**
    `book-check.test.cjs` 의 왕복 테스트 둘이 지킨다.
14. **단원 시험(`mode:'check'`)에 「심은 것만」 거름을 다시 걸지 않는다.** `trainItems` 에서 시험·재확인 분기는 그 거름을 건너뛴다.
    되돌리면 **종이 교재로 공부하고 온 학생은 시험 볼 길이 없어진다**(앱에서 낱말 학습을 먼저 해야만 문제가 나온다) —
    이 앱이 존재하는 이유가 막히는 자리다. `hanja/app.test.cjs`와 `hanja/flow.test.cjs`가 화면·학습 흐름을 검사한다.
    점검 점수는 단원마다 마지막 한 건(`checks`, 40단원 상한)이다. 기록 본문은 400KB 상한이라 이력을 쌓지 않는다.
15. **어휘 시험·보조 한자·오답 재확인의 목적을 섞지 않는다.** 어휘 시험의 허용 문항 종류는 생성 실패 시의 대체 문항에도
    적용한다. 보조 한자와 오답 재확인은 대표 단원 시험 점수를 덮지 않는다. 최대 20문항만 확인한 결과를 전체 통과로 표시하지 않는다.
    시험·만기 전 즉시 반복 정답으로 간격 반복 단계를 올리지 않는다.
16. **획순 수업은 실제 쓰기만 센다.** 시범이 끝나기 전에는 쓰기·단계 넘김을 막고, 취소한 시범의 늦은 콜백은 버린다.
    잘못된 순서·역방향 획은 되돌려 다시 쓰게 한다. 자료 없는 글자의 모양 연습과 획순 확인은 구별하며, 강제 넘김은 성공으로 저장하지 않는다.
    `trace-flow.test.cjs`가 단계·재시도·취소·회차 중복 기록을 검사한다. 어휘 문제로 돌아와도 이미 제출한 답은 다시 채점하지 않는다.

## 4. 자료를 새로 넣을 때

- **자리와 이름**: `docs/자료-폴더-표준.md`. 드라이브 `WB 학습자료/hanja/<단어장 id>/`. 폴더 이름이 곧 단어장 id다.
- **텍스트 교재** → `node hanja/extract/draft.mjs <텍스트.txt> <출력 디렉터리>` — 붙여넣기 형식 초안 + `review/`.
  못 뽑은 줄은 조용히 넘기지 않고 줄 번호·이유와 함께 내린다.
- **엑셀 교재**(EBS 가 이 경우였다) — 저장소에 변환기를 두지 않았다. 표 모양이 교재마다 달라 일회성 스크립트가 낫다.
  저장소 밖에서 만들고, 반드시 `node hanja/book-validate.mjs <단어장.json>` 을 통과시킨 뒤 올린다.
  **올린 단어장은 관리 웹 목록의 [JSON] 으로 언제든 다시 내려받을 수 있다** — 원본 스크립트가 없어도 손볼 수 있다.
- **획순 사전** → `node hanja/strokes-convert.mjs <graphics.txt> <출력.json> --book <단어장.json>`.
  공개 데이터(Make Me a Hanzi 계열, Arphic Public License)는 **원본도 산출물도 저장소에 넣지 않는다**.
  단어장 획수와 데이터 획 수가 다른 글자는 `.review.txt` 로 내려온다 — 원장이 검수한 뒤 관리 웹에 올린다.
- **업로드**: 관리 웹 → 단어장 올리기 → JSON 파일 → 미리보기 → 올리기. 같은 id 는 덮어쓴다(공개 범위·배정 유지).

## 5. 고치기 전에 돌리는 것

```
node scripts/check.mjs --only hanja     # 순수 로직 6 + 도구 2 + 서버 1
node scripts/check.mjs                  # 저장소 전체 (고친 뒤엔 이것까지)
node hanja/book-validate.mjs hanja/book-sample.json    # 체험 단어장은 늘 통과해야 한다
node hanja/books.test.cjs                              # books/ 의 자체 단어장 6권 (오류뿐 아니라 경고도 0)
node hanja/book-validate.mjs hanja/books/geupsu-7.json # 급수 단어장 하나만 볼 때
```

`books/` 의 자체 단어장은 **경고도 0** 이어야 한다. 예문에 낱말이 없으면 문맥 빈칸 문항이, 훈음이 비면
한자 조립 문항이 조용히 빠진 채 학생에게 간다 — 우리가 쓴 자료에서는 그것을 허용하지 않는다.

`hanja/app.test.cjs` 는 화면을 정적으로 본다 — 부르는 스크립트가 있는지, 서비스 워커 셸에 들어 있는지,
부르는 `/api/hanja/*` 가 서버 라우터에 있는지, 낱말·뜻을 `esc()` 로 그리는지, 관리·인쇄 화면이 noindex 인지.
이 넷은 배포 뒤 학생 화면에서 처음 터지는 종류라 여기서 막는다.

## 6. 사람에게 물어야 하는 것

- **누구에게 어느 단어장·단원을 줄지** — 학습 판단이다. 에이전트가 정하지 않는다.
- **획순 사전 업로드** — 검수 없이 올린 획순은 맞는 획순을 틀렸다고 채점한다.
- **공개 범위를 `all` 로 넓히는 것** — 구매 교재를 산 학생 밖으로 여는 일이다.
- **학생 기록 삭제·퇴원** — 운영 데이터다.
- **단어장 삭제** — 학생 기록은 남지만 목록에서 사라진다.
