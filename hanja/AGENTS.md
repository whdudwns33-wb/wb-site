# hanja/ — 한자브레인 작업 인수인계 (Codex · Claude Code 공용)

한글 어휘가 약한 학생이 **문제집 한 권(단어장)을 단원 순서대로** 익히는 앱. 영어는 다루지 않고, 한자는
캔버스에 손가락으로 쓴다. 단어장 본문은 구매 교재라 **저장소에 없다** — 관리 웹 업로드로 KV 에만 산다.

**읽는 순서**: 저장소 루트 `AGENTS.md`(= `CLAUDE.md`, 최상위 규칙) → `hanja/README.md`(이 앱의 정본 문서 —
파일별 역할·단어장 스키마·API·화면 동작이 전부 여기 있다) → 이 문서(지금 상태와 조용히 깨지는 자리) → 고칠 파일.

## 2. 다음 할 일

1. **학생 배정** — 누구에게 어느 단계를 줄지는 원장이 정한다. 관리 웹 「학생에게 단어장 배정」 또는
   `POST /api/hanja/admin/assign {codes, bookIds, action:'add'}`. 배정 없이는 `assigned` 단어장이 아무에게도 안 보인다.
2. **이번 주 단원 지정** — 반 이름이나 학생 코드로. 학생 오늘 화면 맨 위 카드가 된다.
3. **파일럿 한 주** — 실제 손가락으로 쓴 결과를 보고 `trace.js` 의 문턱(덮음률·새어 나간 잉크·잉크 과다)을 조정한다.
   지금 값은 추정치다. 진도표와 현황을 일주일 보고 고친다.
4. **초등 한자 교재의 낱말 뜻 472개** — 교재 본책에만 있어 넣지 못했다. 지금은 글자의 예시 낱말 목록으로만 들어가 있다
   (`一` → 일등·일주·일생·일주일). 뜻이 생기면 낱말 항목으로 올라가고 문항이 늘어난다.
5. **예문** — 엑셀에 없어 문맥 빈칸 문항이 안 나온다. 교재 어휘카드에서 채우면 열린다.

## 3. 조용히 깨지는 자리

1. **뜻 없는 낱말을 넣지 않는다.** 검사기가 막는다(`뜻(meaning)이 없어요`) — 막는 것이 맞다. 교재에 뜻이 없으면
   **지어내지 말고** 글자의 `words`(예시 낱말 목록)로 넣는다. 지어낸 뜻은 교재 단어장이 아니고, 학생이 그것을 외운다.
2. **호환 한자(U+F900~)를 정규화한다.** 廉·不·力 같은 글자는 겉모습이 같아도 코드가 다른 판본이 있다. 그대로 두면
   획순 사전이 안 붙고 기억 기록(`c:<글자>`)이 글자마다 갈린다. EBS 엑셀에 22자가 섞여 있었다. 새 자료를 넣을 때
   한자 칸은 NFKC 로 모은다.
3. **목록(`hanja:books`)은 한 키에 여러 항목이 든 캐시다.** 고치는 자리는 모두 `editIndex` 하나를 지난다. KV 의 함정이 둘이다.
   - **읽기가 옛 값일 수 있다**(지역마다 최대 60초). 바꾼 직후 목록이 옛 값을 보여 줄 수 있고 잠시 뒤 새로 고치면 맞다.
   - **그 옛 값 위에 쓰면 진짜로 잃는다.** 12권을 한 권씩 연달아 바꾸다 실제로 겪었다(성공 응답 12번, 남은 것 2건).
   그래서 여러 권은 **한 번의 쓰기로** 고친다(`POST /admin/scope {ids, scope}`). 되읽기는 확인(`applied`)까지만 하고
   **되쓰지 않는다** — 확인이 늦은 것을 고치려다 남의 변경을 지운다. `applied:false` 는 「틀렸다」가 아니라 「아직 확인 못 했다」다.
4. **획순 데이터가 없는 글자의 획순을 채점하지 않는다.** 없는 데이터로 틀렸다고 하면 **맞게 쓴 획순도 틀렸다**고 하게 된다.
   사전에 없는 글자는 모양 모드(안내 글자 덮음률)로만 쓴다. 비슷한 변이체(眞→真)로 바꿔 넣지 않는다 — 글자 모양이 다르다.
5. **낱말 id 는 내용 기반(`낱말|한자`)이다.** 순번(w001…)으로 바꾸면 교재를 고쳐 다시 올릴 때 뒤의 id 가 전부 밀려
   학생 기억 기록이 다른 낱말을 가리킨다. 바뀐 id 는 서버가 옛 단어장과 대조해 `hanja:remap:<id>` 로 잇고
   학생 앱이 `GET /book` 의 `remap` 으로 옮긴다.
6. **서버 라우트는 두 곳에 배선한다** — `reading-server/worker.mjs`(운영)와 `server.mjs`(로컬). 한쪽만 고치면
   로컬에서 되는 것만 확인하고 배포해 운영에서 다르게 돈다. `override.test.mjs` 가 짝을 검사한다.
7. **응답은 래핑 계약을 따른다** — `/books` → `{books, updatedAt}` · `/book` → `{book, updatedAt, remap}` ·
   `/task` → `{task, scope}` · `/strokes` → `{strokes, updatedAt}`. 클라이언트와 같이 고친다.
8. **검사 규칙은 `book-check.js` 하나다.** 관리 업로드 관문·미리보기·CLI(`book-validate.mjs`)가 모두 이것을 부른다.
   규칙을 다른 곳에 베끼면 "CLI 는 통과인데 업로드가 막히는" 불일치가 생긴다.
9. **`book-check.js`·`srs.js`·`quiz.js`·`trace.js`·`bridge.js` 는 브라우저와 Node 가 같이 쓴다.**
   `'use strict'` + IIFE + `module.exports` 가드. `fs`·`process` 를 넣으면 학생 화면이 통째로 죽는다.
10. **AI 연상은 자체 단어장(`source:'own'`)에서만.** 화면 버튼과 호출 직전 두 곳에서 `aiAllowed` 를 본다. 한 곳만 고치면
    교재 뜻 문장이 외부 AI 로 나간다. 체험 단어장·진로독서 어휘장이 자체, 올린 문제집은 교재가 기본이다.
11. **학생이 올린 값은 두 겹으로 막는다** — 서버가 화이트리스트로 정규화하고 화면이 다시 이스케이프한다.
    강사 화면은 학생 기기가 올린 값을 그리는 자리다.
12. **덤프·퇴원**: 백업 덤프(`dumpHanja`)에 단어장 본문을 싣지 않는다(라이선스). 퇴원은 `state`·`summary`·`assign`·`push`
    네 키만 지운다 — 단어장은 남는다.

## 4. 자료를 새로 넣을 때

- **자리와 이름**: `docs/자료-폴더-표준.md`. 드라이브 `WB 학습자료/hanja/<단어장 id>/`. 폴더 이름이 곧 단어장 id다.
- **텍스트 교재** → `node hanja/extract/draft.mjs <텍스트.txt> <출력 디렉터리>` — 붙여넣기 형식 초안 + `review/`.
  못 뽑은 줄은 조용히 넘기지 않고 줄 번호·이유와 함께 내린다.
- **엑셀 교재**(EBS 가 이 경우였다) — 저장소에 변환기를 두지 않았다. 표 모양이 교재마다 달라 일회성 스크립트가 낫다.
  저장소 밖에서 만들고, 반드시 `node hanja/book-validate.mjs <단어장.json>` 을 통과시킨 뒤 올린다.
  **올린 단어장은 관리 웹 목록의 [JSON] 으로 언제든 다시 내려받을 수 있다** — 원본 스크립트가 없어도 손볼 수 있다.
- **획순 사전** → `node hanja/strokes-convert.mjs <graphics.txt> <출력.json> --book <단어장.json>`.
  공개 데이터(Make Me a Hanzi 계열, Arphic Public License)는 **원본도 산출물도 저장소에 넣지 않는다**.
  단어장 획수와 데이터 획 수가 다른 글자는 `.review.txt` 로 내려온다 — 원장이 검수한 뒤 관리 웹에 올린다.
- **업로드**: 관리 웹 → 단어장 올리기 → JSON 파일 → 미리보기 → 올리기. 같은 id 는 덮어쓴다(공개 범위·배정 유지).

## 5. 고치기 전에 돌리는 것

```
node scripts/check.mjs --only hanja     # 순수 로직 6 + 도구 2 + 서버 1
node scripts/check.mjs                  # 저장소 전체 (고친 뒤엔 이것까지)
node hanja/book-validate.mjs hanja/book-sample.json    # 체험 단어장은 늘 통과해야 한다
```

`hanja/app.test.cjs` 는 화면을 정적으로 본다 — 부르는 스크립트가 있는지, 서비스 워커 셸에 들어 있는지,
부르는 `/api/hanja/*` 가 서버 라우터에 있는지, 낱말·뜻을 `esc()` 로 그리는지, 관리·인쇄 화면이 noindex 인지.
이 넷은 배포 뒤 학생 화면에서 처음 터지는 종류라 여기서 막는다.

## 6. 사람에게 물어야 하는 것

- **누구에게 어느 단어장·단원을 줄지** — 학습 판단이다. 에이전트가 정하지 않는다.
- **획순 사전 업로드** — 검수 없이 올린 획순은 맞는 획순을 틀렸다고 채점한다.
- **공개 범위를 `all` 로 넓히는 것** — 구매 교재를 산 학생 밖으로 여는 일이다.
- **학생 기록 삭제·퇴원** — 운영 데이터다.
- **단어장 삭제** — 학생 기록은 남지만 목록에서 사라진다.
