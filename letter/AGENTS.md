# letter/ — 브레인레터 작업 인수인계 (Codex · Claude Code 공용)

유치~중등 다섯 학년대 **주간 뉴스레터**. 신문 한 면 짜임이고, 한 호를 7일에 나눠 하루 한 장씩 읽는다.
지금은 **파일럿**으로 돈다 — 가정은 링크 하나(`/letter/`)를 열고, 로그인도 학생 연동도 없다.

**읽는 순서**: 저장소 루트 `AGENTS.md`(= `CLAUDE.md`, 최상위 규칙) → `letter/README.md`(이 앱의 정본 문서 —
파일별 역할·호 스키마·운영 절차가 전부 여기 있다) → 이 문서(조용히 깨지는 자리와 지금 상태) → 고칠 파일.

## 3. 새 호 내기 — 가장 잦은 작업

```
1) letter/issues/<주차>.json 을 쓴다        예: 2026-W42.json (id·week 는 "2026-W42", publishAt 은 그 주 월요일)
2) letter/issues.json 에 한 줄 더한다        file·id·week·title·theme·publishAt·status 를 본문과 똑같이
3) node letter/issue-validate.mjs           오류 0 이어야 한다(경고는 허용)
4) node scripts/check.mjs --only letter     테스트
5) 작업 브랜치 → PR → checks.yml 초록 → 스쿼시 머지
```

**발행일이 되면 앱이 저절로 그 호로 넘어간다.** 오늘 합쳐도 다음 주 호는 다음 주에 열린다 — 날짜 맞춰
파일을 갈아 끼우러 다시 오지 않는다. 지난 호는 [지난 호] 목록에 남는다.

한 호의 구성(제40·41호가 그 예다. 26섹션):

- 읽을거리 5 — 학년대마다 하나(`tiers: ["K"]` …). 글자 수 권장 K 50~300 · E1 160~480 · E2 380~820 · E3 560~1150 · M 800~1600.
- 낱말 가족 1(한자, E2·E3·M) · 시 1 · 가족 대화 카드 1 · 한 문장 쓰기 4(E1~M) · 책 1(3~4권, 학년대 고르게).
- 두뇌 놀이 5 — 학년대마다 하나. **지표는 그 주 순환값을 쓴다**: `node -e "console.log(require('./letter/letter.js').rotationFor('2026-W42'))"`.
- 미션(checklist) 1 · 칼럼 1 · 학년대별 코치 5 · 교육·입시 이슈 1(3~5건).

글은 **전부 자체 창작**이어야 한다(루트 절대 규칙 1). 교재·기사·시험 문제를 옮기지 않는다.
이슈 코너의 링크는 **실제로 열리는 기사**만 — 쓰기 전에 `curl` 로 확인하고, 제목이 실제 기사와 맞는지 본다.

## 4. 조용히 깨지는 자리

1. **검증기는 하나다(`letter.js` 의 `checkIssue`).** 관리 웹 [검증]·서버 저장·CLI·CI 가 모두 이것을 부른다.
   규칙을 다른 곳에 베끼면 "CLI 는 통과인데 업로드가 막히는" 판정 불일치가 생긴다.
2. **놀이·도형의 정답을 손으로 쓰지 않는다.** `drill`·`figure` 는 `{kind, seed}` 만 싣고 답은 생성기가 낸다.
   `answer` 를 적으면 학년대마다 난이도가 달라 어긋나고, 아이가 맞히고도 틀렸다는 소리를 듣는다. **비워 두는 것이 정답이다.**
3. **`letter.js` 는 브라우저와 Node 가 같이 쓴다.** `'use strict'` + IIFE + `module.exports` 가드. 여기에 `fs`·`process`
   같은 Node 전용 API 를 넣으면 학생 화면이 통째로 죽는다. 파일을 읽는 일은 `issue-validate.mjs` 쪽에서 한다.
4. **날짜는 KST 다.** 오늘을 구할 때 `L.kstDate()` 를 쓴다. `new Date().toISOString().slice(0,10)` 은 한국 새벽에 하루 밀린다.
   호를 고르는 규칙은 순수 함수 `pickPilot(list, today)` 하나이고 `letter.test.cjs` 가 지킨다 — 화면에 같은 판단을 다시 쓰지 않는다.
5. **운영 CSP 는 로컬보다 좁다.** `img-src 'self' data:` 라 `blob:` URL 로 만든 이미지는 **운영에서만** 안 뜬다
   (사진 올리기가 이 이유로 한동안 죽어 있었다). 브라우저 검증을 할 때는 `reading/_headers` 의 CSP 를 그대로 씌우고 본다.
6. **서버 라우트는 두 곳에 배선한다** — `reading-server/worker.mjs`(운영)와 `server.mjs`(로컬). 한쪽만 고치면
   로컬에서 되는 것을 확인하고 배포했는데 운영에서만 다르게 돈다. `override.test.mjs` 가 짝을 검사한다.
7. **응답은 래핑 계약을 따른다** — `/issue` → `{issue, tier, updatedAt}` · `/issues` → `{issues, tier}` ·
   `/parent` → `{parent, issue, issues}`. 클라이언트와 같이 고친다.
8. **KV 쓰기는 예산이다.** 학생 기록 `PUT /state` 는 하루 10회 상한이고 앱은 20초 디바운스로 올린다.
   저장을 자주 부르도록 고치면 네임스페이스 전체(다른 앱 포함) 쓰기 예산을 태운다.
9. **가족 링크는 진로독서 학부모 토큰(`parent:<t>`)을 그대로 쓴다.** 가정마다 링크가 하나여야 하므로 새 토큰 체계를 만들지 않는다.
10. **사진**: `alt`·`credit` 이 없으면 저장되지 않는다. 올린 사진은 `{id}`, 저장소 삽화는 `{file}`. **SVG 업로드는 막혀 있다**
    (스크립트가 들어갈 수 있다) — 저장소의 `img/*.svg` 는 자체 제작본이라 예외다.
11. **배포 자산**: `letter/` 에 새 파일을 더하면 `build-dist.mjs` 의 `LETTER_FILES` 에 넣고 `dist-cache.test.mjs` 에 한 줄 더한다.
    넣지 않으면 로컬에서만 되고 운영에서 404 다. 서비스 워커 `VERSION` 은 조립이 내용 해시로 스탬프한다 — **손으로 만지지 않는다.**
12. **AI 키가 없어도 앱은 그대로 돌아야 한다.** 초안·삽화는 키가 없으면 `{ok:false, reason:'no-key'}` 로 안내만 하고,
    나머지 기능은 영향을 받지 않는다. 이 성질을 깨는 변경(키 없으면 화면이 죽는 식)은 되돌린다.
13. **관리 화면의 인라인 스크립트는 한 줄이 길다.** 코드 줄 끝에 `//` 주석을 붙이면 뒤가 통째로 주석이 된다.
    고친 뒤 `new Function(<인라인 스크립트>)` 로 파싱만이라도 확인한다.
14. **이벤트 위임 선택자를 넓게 쓰지 않는다.** `[data-day]` 로 걸면 그 속성을 가진 기사 전체가 잡혀 안쪽 버튼이 죽는다
    (`button[data-day]` 처럼 좁힌다).
15. **학생에게는 자기 학년대 섹션만 나간다**(`forTier`). 관리 미리보기에서 전체가 보인다고 학생도 본다고 착각하지 않는다.
16. **파일럿 기간에는 호가 서버(KV)에 없다.** 가족 링크(`?t=`)로 들어오면 앱이 서버에 호를 물어보는데, 서버는 링크가 멀쩡해도
    "호 없음" 이라고 답한다. 그대로 두면 가족은 빈 화면을 보고 링크가 고장 난 줄 안다 — 그래서 `loadPilot` 으로 넘어가
    배포본 호를 연다(`letter/app-boot.test.cjs` 가 이 배선을 지킨다). 링크 세 갈래가 모두 열려야 한다:
    순수 링크는 기기에 기록 · 유효한 가족 링크는 명부 학년대 + 서버에 기록 · 잘못된 링크는 체험 모드로 내려와 기기에 기록.

## 5. 고치기 전에 돌리는 것

```
node scripts/check.mjs --only letter                     # 이 앱 몫 테스트(호 검증·화면 배선 포함)
node letter/issue-validate.mjs                           # 저장소의 호 전부 + 목록 대조
node reading-server/build-dist.mjs && node reading-server/dist-cache.test.mjs   # 배포본 배선
node scripts/check.mjs                                   # 합치기 전 전체
```

로컬에서 눈으로 보려면:

```
PORT=8890 ADMIN_PIN=<임의의 긴 문자열> DATA_DIR=<빈 폴더> node reading-server/server.mjs
  → http://localhost:8890/letter/   ·   /admin/letter-admin.html
```

배포본 그대로(파일럿 경로)를 보려면 `reading-server/dist` 를 정적 서버로 띄운다.
발행일 전/후를 보려면 브라우저에서 `Date` 를 고정한다 — 그렇게 제41호 전환을 확인했다.

`main` 푸시가 곧 배포다. 테스트가 빨간 채로 머지하면 가정 화면이 바로 그 상태가 된다.

## 6. 사람에게 물어야 하는 것

- 시크릿 교체, 운영 데이터(KV) 삭제.
- 남의 글·그림·기사 사진을 쓰는 것처럼 보이는 모든 판단. 애매하면 싣지 않는다.
